제품맵 화면 고도화 — 구현 중 주요 기능

작성일 2026-11-19작성 제품맵 개발팀배포 주소 moonkj.github.io/lse-product

디자이너 5인 합의안(P0 9건·P1 전체)과 새 기능 2개(전기 흐름 애니메이션·실시간 전력수급)를 7개 담당이 병렬로 구현하고 있습니다. 리더 통합·테스트 후 배포할 예정입니다.

1배경

  • 사용자 지적: 메뉴와 화면이 조잡하다. 사이드바에 범례·버튼이 쌓이고, 타일 테두리와 선 종류가 많아 읽기 어렵다.
  • UX/UI 디자이너 5인이 2라운드 토론으로 합의안을 냈습니다(정보구조·비주얼·계통도·모바일·접근성). 쟁점 2건은 시안을 비교해 사용자가 정했습니다.
  • 이미 배포된 기능: 제품 사진 192개 카탈로그 실사진 교체, 기기 설명 74종, 전체 계통도 A4 인쇄, 상세 창 폭 조절.

2주요 기능 (구현 중)

구분기능바뀌는 점 (지금 → 바뀌면)기대 효과
P0헤더·도구줄 제품/Gap 토글·텍스트 버튼, 시작 안내 띠 + 도구줄 2단→로고·서비스명·"계통도 · 공백 표" 메뉴·검색·아이콘 2개. 도구줄 한 줄, 맨 왼쪽 "보기 [전체｜공백만]" 계통도 세로 약 56px 확보
P0사이드바·범례·미니맵 사이드바에 범례·버튼이 쌓임, 1280×720에서 범례 잘림, 미니맵이 타일과 겹침→사이드바는 계층 목록과 "10/13 ●3"(보유/전체·공백 수)만. 범례는 계통도 왼쪽 아래 카드, 미니맵은 오른쪽 위·기본 접힘 잘림·겹침 해소, 계층별 보유 현황을 숫자로 바로 확인
P0타일·연결선 커버리지 색 테두리 + 배지 이중 표시, 선 6종→테두리 회색 1px, 미보유만 빨강 2px + ✕, 일부 보유 황색 1.5px, 선택은 바깥 블루 링. 점선은 신호선만, 청록 택1 폐지 → 선 4종 미보유·일부 보유가 먼저 눈에 띔
P0상세 패널·공백 보기 기기를 고르기 전에도 빈 패널 360px, 공백 보기에서 글자가 흐려짐→빈 패널은 접힌 레일("‹ 상세"), 기기를 고르면 마지막 폭으로 열림. 공백 보기 글자 대비 4.5:1 유지 계통도 폭 확보, 흐린 상태에서도 읽힘
P1계층 밴드·타일 표현 밴드 9색, 축소해도 사진·글자 그대로→흰/연회색 2톤 + 감시·신재생 옅은 블루. 이름표 "L4 수전설비 · 22.9kV · 10/13". 60% 미만 축소에서만 점 + 약칭 색 소음 감소, 전체 구조 파악 쉬움
P1패널 순서·공통 부품·모바일 설명이 길어 제품 목록이 아래, 버튼·배지 모양 제각각→이름·상태 → 버튼 줄 → 자사 제품 → 설명. 버튼 3종·배지 4종, 최소 글자 12px, "✓ 담김 n/4". 공백 표 행·열을 누르면 계통도로 이동. 모바일 하단 시트 3단 스크롤 없이 제품 확인, 화면 간 일관성
신규전기 흐름 애니메이션 없음→도구줄 [⚡ 흐름] 토글(기본 꺼짐). 고른 기기의 상류·하류 전력선에 블루 대시가 이동, 신호선 제외. 태양광 역방향·ESS 양방향 표시. 주소(?flow=1)로 공유. 공백 보기·움직임 줄이기 설정에서는 정지 기기 간 전력 경로를 화면에서 바로 설명
신규실시간 전력수급 없음→도구줄 오른쪽 알약 "예비율 12.3% · 정상 · 14:20". 누르면 수요·공급능력·공급예비력·오늘 수요 추이. 공공데이터(전력거래소) 20분 주기 수집, 40분 넘게 갱신 없으면 "지연" 표시 계통 수급 상황을 제품맵 안에서 확인

수급 경보 단계 기준값(준비 5.5 ~ 심각 1.5 GW)은 전력거래소 공식 기준과 대조한 뒤 확정합니다.

3사용자 결정 사항

일부 보유 표시 — A안
타일 테두리 황색 1.5px. (B안: 배지만 표시 — 미채택)
수급 위젯 위치 — A안
계통도 도구줄 오른쪽 알약. 모바일은 칩 줄 끝. (밴드 이름표 옆·헤더 칩 — 미채택)

4일정·상태 구현 중

  • 7개 담당 병렬 구현 중: 헤더·도구줄 / 사이드바·범례·미니맵 / 상세 패널 / 타일·선·밴드 / 공통 부품 / 전기 흐름 / 실시간 수급.
  • 각 담당은 타입 검사·단위 테스트까지 확인. 이후 리더가 통합하고 빌드·화면 자동 테스트를 거쳐 배포할 예정입니다.

5다음 단계

  • 전력시장 연계 기능 P0 3개(전력시장 전문가 10인 토론): ① 기기 상세 '시장 동향' 카드(입찰 공고·뉴스·구매 방식) ② 공식 계획 물량 레이어 + 보유 현황 겹쳐 보기 ③ 수요처 유형 프리셋(데이터센터·팹 등) + 미보유 경고.
