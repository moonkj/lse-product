# E1 남지후 — 계통도 색 체계 (Round 1)

> 측정: tokens.css 값을 OKLCH(명도 L)로 변환, 적록 색각(Machado 2009) 모의.

## 진단

1. **밴드 9색은 색조만 돌고 명도는 평평** — L1~L7 명도 0.922~0.943(폭 0.02), 채도 0.026으로 같음. 01·10 전체 보기에서 L2/L3, L4/L5 경계가 거의 안 보이고 전압 높낮이가 색으로 안 읽힘. 적록 색각 모의 시 L1~L3, L5~L7·신재생이 각각 한 색으로 합쳐짐.
2. **커버리지 6색 중 적록 3색이 한 색으로 무너짐** — 모의 시 보유·일부·미보유가 모두 올리브(L 0.57~0.62), 패널 구성품 보라는 파랑이 되어 계열사·선택색과 겹침. 01·06에서 배지가 8px 안팎이라 기호(✓✕◐)로도 보완 안 됨.
3. **파랑 한 색조에 뜻이 4개** — 선택 링·흐름 펄스(둘 다 #0068b7), 계열사 ◆, 활성 칩이 같은 색조. 04에서 ACB 선택 링과 모선 위 펄스가 같은 색이라 '고른 기기'와 '경로'의 위계가 없음.
4. **흐름 트랙이 청색 밴드에서 사라짐** — 트랙 #b9d6f0 대 L2 밴드 #dee6f8 대비 1.20:1.
5. **다크: 선택과 흐름이 거의 같은 색** — 08에서 VCB 선택 #7fb2ff(L 0.76)와 펄스 #8cc4f0(L 0.80)의 명도 차이 0.04.
6. **공백 모드 사이드바 활성이 빨강 계열**(07 L4) — 선택에 미보유 색을 씀.

## 제안

- **P0-1 밴드 명도 램프** (`--band-l1~l7`, `.dband--*`·미니맵 공통) — 색조 9색 유지, 명도를 L1 0.885 → L7 0.965로 계층당 0.013씩 단조 증가, 채도 0.034 통일. 고압일수록 진함. 다크는 L1 0.335 → L7 0.257. 값은 아래 표.
- **P0-2 흐름 트랙 바탕선** — `--flow-casing` 라이트 `rgb(255 255 255 / 0.9)`, 다크 `rgb(15 18 23 / 0.9)`. flow.css `.dflow__track` 밑에 10px(모선 12px) 선 추가, `--flow-track` 라이트 #b9d6f0 → **#8fbbe3**. 다크 유지.
- **P0-3 선택과 흐름 분리** — `--color-selected` 라이트 #0068b7 → **#00337f**(CI 네이비, 링 3px 유지), 다크 #7fb2ff → **#f2f4f7**(무채색 흰 링). 흐름은 #0068b7 / #8cc4f0 유지. 위계: 선택(네이비) > 흐름(블루) > 선(검정) > 밴드.
- **P1-4 패널 구성품을 자홍으로** — `--cov-sourced` #6d3aa8 → **#8e3a9e**(흰 글자 6.5:1), 다크 #cf9bff → **#e08ad6**, `-bg` #f6e6f4 / #33192f. 색각 이상에서도 계열사 파랑과 갈림.
- **P1-5 미보유·일부 명도 차이 벌리기** — `--cov-missing` #d93a3a → **#c62d1f**(L 0.54, 흰 글자 5.5:1), `--cov-partial` #a67c00 → **#b58300**(L 0.64). 색이 같아 보여도 진하기로 갈림. 다크 #ff6b5e / #f2c230.
- **P1-6 해당 없음은 속 빈 배지로** — 채움 대신 흰 바탕 + `--cov-na` 1.5px 테두리 + 회색 −.
- **P1-7 배지 최소 크기** — 화면 기준 12px 아래로 줄면(전체 보기) 배지 대신 미보유 타일만 2px 빨강 테두리 + 배경 `--cov-missing-bg`를 남김.
- **P2-8 공백 모드 사이드바 활성** — 빨강 대신 해당 계층 `--band-accent-*`로 통일(일반 모드와 같은 규칙).
- **P2-9 IEC 60445/KS 판단: 채택 안 함** — 60445는 도체 식별색(L1 갈색·L2 검정·L3 회색·N 파랑·PE 녹황)이지 전압 등급 색이 아님. 검정·회색은 선·'해당 없음'과 충돌하고, SCADA 전압색도 회사마다 다름. "고압일수록 진하게" 원칙만 P0-1로 따름.

## 다른 디자이너와 부딪힐 쟁점

1. **밴드를 더 진하게 할지, 더 비울지** — 명도 램프는 L1을 지금보다 한 단계 진하게 만듦. 밴드 최소화를 원하는 레이아웃·위계 담당과 충돌. 양보선은 L1 0.885.
2. **선택색을 네이비로 바꿀지** — 눈에 보이는 변화라 사용자 확인 필요. CI 블루 단일색을 지키자는 브랜드 쪽과 부딪힘.
