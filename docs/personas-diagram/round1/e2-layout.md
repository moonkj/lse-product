## 진단 (실측)
- 캔버스 2320×4398, 가로:세로 = **0.53**. 주 계층 L1~L7 폭 1740(75%), 오른쪽 열 MON·REN 551(x 1769~2320), 사이 여백 29.

- 전체 보기 배율: 1440 = min(1156/2320, 764/4398) = **17%**, 그림 폭 403px / 캔버스 약 1188px = **34%만 씀**. 1920 = **21%**, 498px / 약 1668px = **30%**. 높이가 배율을 정함 → 화면이 넓어져도 양옆만 빔(shots/01·10).
- 밀도: 타일 72개 면적 ≈ 1.0M px² / 10.2M px² = **9.8%**. L5는 540 높이에 타일 2개(위·아래 여백 각 270), L3 아래 여백 198, L2 아래 144.
- 같은 열 세로 간격 최소: L4 153, L2·L6 162, L1 180(타일 116 + 최소 30 = 146이 하한) → **세로를 고르게 줄일 여유는 거의 없음**, 줄일 곳은 밴드 위·아래 여백뿐.
- 가로 간격 최소: L6 159, L7 174, L4 204 → 타일 사이 39~84px. 가로로 펼칠 여유는 충분(줄어드는 방향이 아님).
- MON·REN: 열이 x 1914·2175 두 개(REN만 2044 하나 더). REN 아래 1608px 비어 있음.
- 연결선 89개 중 22개가 points(직접 그린 꺾은선) 보유 → 좌표 옮길 때 함께 변환해야 함.

## 쟁점
1. **두 단 접기(L1~L3 | L4~L7 나란히)?** 1920 전체 보기 배율은 21%→31%로 크게 오르지만, 위→아래 전력 흐름 읽기가 깨지고 L3→L4 연결선이 화면을 가로지름. 나는 반대 — 흐름 순서가 제품맵의 뼈대. 폭 맞춤 + 세로 스크롤로 해결.
2. **첫 화면을 "폭 맞춤"으로 바꿔도 되는가?** 지금 첫 화면(L4 중심)과 "전체 보기 (76종)" 버튼 모양이 바뀌는 화면 변경이라 사용자 확인 필요. 대안: 버튼은 그대로 두고 "폭 맞춤" 버튼만 옆에 추가.
