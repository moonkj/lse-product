# E3 류하은 — Round 4 (타일·배지·심볼)

## ① 다크·모바일
- **다크(after3/08·08b): 양호.** 밝은 판 위 사진·심볼이 선명하고, 흰 선택 링(#f2f4f7)과 흐름 블루가 분리된다.
  - 문제는 배지 바깥 링이 `--node-bg` #171b22라는 점이다. 밝은 판(#E9EDF2) 위에 **검은 테두리**로 떠 보인다(VCB·LBS ✓). 판 색 링이 다크에서 더 시급하다.
  - 패널 구성품 자홍 □(#e08ad6)은 LA·MOF·CT/PT에서 잘 구분된다.
- **모바일(after3/09·09b): 대체로 양호.** 75% 배율에서 타일은 90px로 터치에 충분하다.
  - 부제는 12×0.75 = **9px**라 읽기 한계다. 모바일에서는 부제를 13px로 둔다(화면 기준 약 10px).
  - 화면 양끝에서 타일이 반쯤 잘린다. '계층 바로가기' 때 가로 중앙 정렬 기준을 선택 계층의 **타일 묶음 중심**으로 잡는다.

## ② 미반영 우선순위
1. **P0 배지 바깥 링을 판 색으로.** `box-shadow: 0 0 0 1.5px var(--photo-plate-bg)` 한 줄이면 되고, 라이트·다크 모두 개선된다.
2. **P0 참조 ↗ 칩 20px.** after3/02(64%)에서 L2 MTR 참조 표시가 여전히 보이지 않는다. 바로 옆 비활성 밴드의 흐린 타일과 구분이 안 된다.
3. **P1 ✓14 / ✕◐18.**
4. **P1 미보유 타일 앞 흐름 끊기 6px.** after3/04 SC/APFC 위쪽에 파란 선이 빨강 테두리에 닿는다.
5. **P2 모선 #1f3a66.** 지금은 흐름이 켜진 상태라 모선이 블루 트랙에 덮여 충돌이 덜하다. 그래서 순위를 낮춘다.

## ③ 남은 문제 수치
- **중간 단계 역전.** 37% 폭 맞춤(after3/11)에서 제목 18px은 화면 기준 **약 6.7px**다. 그보다 축소된 32%(after3/12 개요)의 약칭은 **약 12px**라, 더 축소한 쪽이 더 잘 읽힌다.
  - 제목을 `calc(12px × var(--label-k))`(상한 32px)로 해서 화면 기준 10~12px를 보장한다.
  - 또는 개요 경계를 35%에서 **42%**로 올린다.
- **이름표.** 개요(after3/08b, 16%)에서 밴드 이름표가 화면 기준 약 6px다. 이름표 최소를 화면 기준 **12px**로 둔다.
