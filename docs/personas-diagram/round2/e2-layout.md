# E2 문가람 — 2라운드 (레이아웃)

## 현재 상태 (F1 구현 뒤 실측)
- 3010×4398, 주 계층 2262 + 감시·신재생 700(x 2310). 높이는 그대로라 **전체 보기는 여전히 1440 17%·1920 21%** (그림 폭이 캔버스의 34%→44%, 30%→39%로 늘어난 정도).
- 폭 맞춤: 1440 37%, 1920 53%. 첫 화면은 아직 `INITIAL_DESKTOP {x:863, y:1620, 900×540}`(L4를 100%로 확대).

## ① 동의 3 · 반대/수정 2
- **동의 E3 쟁점1**: 타일은 키우지 말고 간격(x)으로 푼다. ×1.3으로 타일 사이가 최소 87px가 되어 E3의 108×60 가로형 판을 넣을 자리가 생겼다.
- **동의 E5 P0 도면 시트**: 빈 양옆이 '책상'으로 읽힌다. 시트 아래 여백 72px 요청도 받는다.
- **동의 E4 #3 성능**: 흐름이 처음부터 켜지면 필수가 된다(③).
- **수정 E5 #2 범례 위치**: "시트 왼쪽 아래 16px"는 폭 맞춤일 때 시트 아래쪽이 화면 밖이라 안 보인다. → **캔버스 화면(viewport) 왼쪽 아래 16px에 고정**하고 폭은 min(시트의 화면상 폭, 캔버스−32). 미니맵도 같은 기준으로 오른쪽 위.
- **수정 E4 #4·E5 #8 선 굵기**: 3010폭에서는 37~53% 배율이 기본이라 1.5px 선이 화면에서 0.6~0.8px로 사라진다. 굵기 단계는 E4 절충안인 3단(3/2/1.5)으로 하되, `vector-effect: non-scaling-stroke` 또는 배율 보정으로 **화면상 최소 1px**을 보장하자.

## ③ "흐름 처음부터 켜기"의 영향
- 17% 전체 보기에서 전체 흐름을 켜면 펄스가 화면 크기로 고정돼(대시÷배율) 머리카락 같은 선 위에 점선만 빽빽해진다. 소음이 크고 E4가 말한 끊김 위험도 있다. → **첫 화면이 폭 맞춤(37~53%)이어야 흐름 기본 켜기가 성립한다.** 두 지시는 묶어서 적용해야 한다.
- 맨 위에서 시작하면 발전기(G)에서 아래로 흐르는 방향이 첫 화면에서 바로 읽힌다. L4에서 시작하면 흐름이 화면 위쪽 밖에서 들어온다.
- 전체 보기(17%)로 축소하면 흐름은 '정지 트랙만'으로 바꾸고 펄스는 35% 이상에서만 켜자(개요 경계와 같은 값).
- 범례에 흐름 항목(켜짐 표시, E4 ▲공급▼부하 채택 시 2줄)이 기본으로 붙어 범례가 1줄 길어진다. 1440에서 범례 폭이 넘치면 '선 종류'를 접힘으로.
