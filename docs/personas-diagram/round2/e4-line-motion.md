# E4 백승우 — 선·모션 (round2)

## ① 다른 의견서에 대해
**동의**
- **E1 P0-2 바탕선(casing)과 트랙 #8fbbe3**: 밴드 대비 1.2:1 문제를 가장 싸게 푼다. 다크 트랙은 #1e3a5f를 유지하지 말고 **#2f5f8f**로 올리자(shots/08에서는 트랙이 보이지 않는다).
- **E1 P0-3 선택(네이비)·흐름(블루) 분리**: 위계 "선택 > 흐름 > 선"에 찬성한다.
- **E3 P0-4 점선은 공백 후보와 신호선 전용**: 선의 뜻이 하나로 정리된다.

**반대·수정**
- **E5 P2-8 선 3단(모선 3 / 전력 1.5 / 신호 1px)에 반대한다.** 전체 보기 17~21%에서 1.5px는 화면에서 0.3px가 되어 사라진다. 리더 안 2.5 / 2 / 1.5 + 모선 5px를 지지한다.
- **E5 P1-4 "흐름 켜짐 = #0068B7 채움 버튼"은 수정이 필요하다.** 흐름이 기본으로 켜지면 버튼이 늘 파랗게 채워져 도구줄에서 가장 강한 요소가 된다. 켜짐은 1px #0068B7 테두리와 아이콘 색만 바꾸는 지금 방식을 유지하자.

## ② 리더 처리안
- **상·하류 색 구분 보류를 받아들인다.** 대안은 같은 색에서 **대시 패턴만** 바꾸는 것이다. 상류는 긴 펄스 18/22, 하류는 짧은 점 펄스 6/14. 흑백 인쇄와 색각 이상에도 통한다.
- **흰 바탕선과 트랙 #8fbbe3에 찬성한다.** 굵기 규칙은 트랙 = 선 굵기 +4, 바탕선 = 트랙 +4로 묶는다(2.5px 선이면 트랙 6.5, 바탕선 10.5).
- **굵기 2.5 / 2 / 1.5에 찬성한다.** `--line-w-hv/lv/feed` 토큰 3개와 엣지 `data-tier`로 구현한다.
- **모선 네이비 5px**: 흐름이 꺼져 있을 때 선택 엣지(네이비 2.5px)와 같은 색이다. 굵기 차이 2배로 구분되니 허용한다. 대신 선택 엣지는 **3px**로 올린다.

## ③ 새 지시 "처음부터 전체 전력선 흐름"
| 항목 | 전체 흐름(기본) | 기기 선택 |
|---|---|---|
| 속도 | **32px/s**(차분하게) | 44px/s |
| 펄스 | 대시 **10 / 30**(성기게) | 18/22 · 하류 6/14 |
| 트랙·바탕선 | **없음**. 펄스는 선 위에 선 굵기+1px | 트랙 #8fbbe3 + 바탕선 |
| 불투명도 | 펄스 0.7 | 1 |
| 빛 번짐 | **끔** | 경로 그룹 하나에만 3px |

- **이유**: 89개 선 전부에 트랙을 깔면 계통도 전체가 파래져 위계와 선택 강조가 사라진다. 전체 흐름은 "살아 있다"는 배경 신호로만 쓴다.
- **성능**: 실제로 흐르는 전력선은 약 70개다. 경로마다 걸린 filter를 없애면 stroke-dashoffset 애니메이션 70개는 합성 비용이 낮다. 패닝 중·탭 숨김 정지는 유지하고, 확대 중 다시 그리기는 지금처럼 0.05 단위로 묶는다. 배율이 0.25 미만이면 duration을 2배로 늘려 깜빡임을 줄인다.
- **선택 전환**: 전체 펄스를 **200ms** 동안 opacity 0으로 줄이고, 선택 경로의 트랙·바탕선을 **250ms** 동안 페이드인한 뒤 펄스를 시작한다. 선택을 풀면 거꾸로 되돌린다. reduced-motion이면 전체 흐름은 표시하지 않고, 선택 경로에만 ▸를 둔다(89개 화살표는 소음).
- **주소 규칙**: 기본(파라미터 없음) = 전체, `?flow=0` = 끔. flow.ts의 parseFlow와 useFlowAll 뜻을 바꿔야 한다. 화면이 바뀌는 변경이므로 리더가 사용자 지시와 맞는지 확인해 주기 바란다.
