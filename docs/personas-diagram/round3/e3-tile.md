# E3 류하은 — Round 3 (구현 화면 검토 · 타일)

## ① 잘 된 점
1. **'제품 카드'가 됐다.** 108×60 판, 판 안쪽 배지, 모서리 8이 들어갔다(after/04·08 대 shots/04). 미보유 타일은 판이 옅은 빨강이라 '빈 자리'로 읽히고, 밴드 경계를 넘는 배지도 사라졌다(after/02 L2 MTR).
2. **심볼과 선택이 정리됐다.** MOF(함체+CT·PT)와 CT/PT가 이제 구분된다(after/03·08). 선택 타일은 네이비 링에 들림까지 더해져 흐름 블루와 분리된다(after/04).

## ② 아직 문제
1. **중간 배율 글자.** 첫 화면 51%, 폭 맞춤 37%에서 제목은 화면 기준 약 7px/5px이고, 부제는 읽을 수 없다(after/02·03·11). 해결안은 **중간 단계 줌(35~60%)** 추가다. 부제를 숨기고, 제목을 `max(14px, 11px×--label-k)`로 키워 화면 기준 10px 이상을 확보한다.
2. **약어 없는 긴 제목의 줄바꿈.** "송전선로·전력케이블"이 "…케이/블"로 끊긴다(after/02·11). `.dnode--nocap .dnode__title`에 `word-break: keep-all; font-size: 13px`를 준다.
3. **참조 타일과 비활성 밴드.** ↗ 칩이 화면 기준 4px 수준이라 보이지 않고, 비활성 밴드의 흐린 타일(after/02 L2 전체)과 겉모양이 같다. 칩을 **20px, 아이콘 13px**로 키운다. 비활성 밴드 흐림은 사진 opacity **0.85**까지만 한다.
4. **개요 이름표·칩.** 17~21%에서 밴드 이름표가 화면 기준 약 6px다(after/01·10). 모선 라벨과 택1 칩도 51%에서 약 6~7px다(after/03). 개요에서는 이름표에 `--label-k`를 적용하되 **화면 기준 최소 12px**로 하고, 모선 라벨·택1 칩에도 같은 보정을 적용한다.
5. **보유 ✓가 여전히 많다.** 51% 배율에서 녹색 점 59개가 공백 ✕ 9개와 같은 크기로 보인다(after/05). ✓는 **14px**, ✕·◐는 **18px**로 차이를 4px로 벌린다.
