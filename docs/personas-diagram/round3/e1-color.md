# E1 남지후 — Round 3 (구현 화면 검토 · 색)

## ① 잘 된 점
1. **선택과 흐름이 갈림** — after/08 다크에서 VCB 흰 링(#f2f4f7)과 하늘색 펄스(#8cc4f0)가 한눈에 구분됨(shots/08은 명도 차 0.04). after/04 라이트에서도 ACB 네이비 링이 모선 #2b4a7a와 섞이지 않음.
2. **밴드 명도 램프와 자홍** — after/01·10에서 L1 보라부터 L7 살구까지 위에서 아래로 진함→옅음이 읽힘. after/03 패널 구성품 □가 자홍으로 바뀌어 계열사 파랑과 겹치지 않음.

## ② 아직 문제인 점
1. **전체 흐름이 거의 안 보임**(after/01·02·03·05). 흐름 버튼은 켜져 있는데 선 위에 펄스가 보이지 않음. 반투명 블루(0.6)를 검은 2px 선 바로 위에 겹치면 합성색이 약 #084879가 되어 선과 같아 보이기 때문. 수정: 투명도 대신 **선보다 밝은 불투명 색**을 씀. `--flow-pulse-idle` 라이트 **#6fb1ea**, 다크 **#2f7fd0**(밝은 선 #dfe4ea 위에서는 진한 색), opacity 1, 2px, 대시 6/30. 속도는 아직 56px/s(flow.ts)라서 전체 상태는 **24px/s**로 낮춤.
2. **일부 보유 #b58300이 그대로**(tokens.css 98행). 2라운드에서 철회한 값임. after/05 M 타일 황색 테두리가 L7 살구 밴드 위에서 3.0:1로 약함. **#a67c00**(3.3:1)으로 되돌림.
3. **L1과 L2가 같은 라벤더로 보임**(after/11 37%, 02). 색조 차이가 26°뿐이라 명도 0.015 차이에 묻힘. L1을 H 300·C 0.040(**#dcd2f0**)으로 더 보라 쪽에 두고, L2는 그대로.
4. **공백 모드 사이드바 활성이 여전히 빨강**(after/07 L4). `--band-accent-l4` 띠·글자로 통일(P2-8).
5. **다크 주 버튼이 연파랑 바탕에 검은 글자**(after/08 '기기 상세 페이지'). 라이트(진한 바탕·흰 글자)와 인상이 뒤집힘. #2563eb 바탕 + 흰 글자로.

## ③ 꼭 넣어야 할 2라운드 미반영 의견
- **E4: 흐름 버튼 켜짐 = 테두리만.** 흐름이 기본으로 켜지면서 after/01·10 도구줄에서 #0068b7로 채운 버튼이 가장 강한 요소가 됨. 1px 테두리와 아이콘 색만 바꾸는 방식으로 되돌려야 함. 색 위계(선택 > 흐름 > 선)를 도구줄에서도 지키는 조치임.
- **E3: 배지 바깥 링을 판 색 #F3F5F8로.** after/02·03에서 배지가 판 위에 흰 테를 두르고 있음. 적록 색각에서는 배지 모양이 구분을 맡으므로 이 테가 모양을 흐리지 않게 해야 함.
