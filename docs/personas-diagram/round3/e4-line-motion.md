# E4 백승우 — 선·모션 (round3, 구현 화면 검토)

## ① 잘 된 점
1. **선택 경로가 또렷하다.** after/04에서 흰 바탕선, 트랙, 펄스가 380V 모선까지 하나의 경로로 읽힌다. 모선 5px도 트랙에 덮여 끊김이 없다. shots/04보다 위계가 분명하다.
2. **다크 트랙이 살아났다.** after/08의 22.9kV 모선과 VCB 상류는 shots/08에서 점선만 떠 있던 상태였는데, 이제 띠로 보인다. 신호선 1.25px 점선(DPM, CT/PT)도 선택 중에 사라지지 않는다.

## ② 아직 문제
1. **(P0) 첫 화면에서 흐름이 안 보인다.** 사용자 지시는 "처음부터 전체 흐름"인데, 화면이 그렇지 않다.
   - 정지 기준(35% 미만)이 첫 화면 배율에 걸린다. 01은 17%, 10은 21%이고, 11 폭 맞춤도 37%라 기준에 아슬하다. 1280 폭에서는 폭 맞춤도 35% 아래로 내려가 처음부터 정지한다.
   - **수정안**: 정지 기준을 **15%**로 낮춘다. 대신 35% 미만에서는 펄스를 6/30에서 **4/24**로, 속도를 24에서 **16px/s**로 낮춘다.
2. **(P0) 전체 흐름 펄스가 너무 옅다.** 11(37%)에서 2px·불투명도 0.6의 블루 펄스가 검정 2.5px 선 위에 올라가 거의 구분되지 않는다. 처음 사용자 피드백 "자세히 봐야 보임"이 다시 나올 것이다.
   - **수정안**: 불투명도 0.6 → **0.85**, 펄스 굵기 = **선 굵기 +1px**(2.5px 선이면 3.5px). 다크는 #8cc4f0 그대로 두고 0.8.
3. **(P1) 선택 펄스 56px/s가 빠르다.** 0.64초 주기라 펄스가 깜빡이는 것처럼 보인다. **44px/s**, 대시 18/22(주기 0.9초)로 바꾼다.
4. **(P1) 전압별 굵기 차이가 보이지 않는다.** 10(21%)에서 2.5px와 2px가 화면에서 각각 0.5px와 0.4px가 되어 똑같아 보인다. 35% 미만에서는 `vector-effect: non-scaling-stroke`로 화면 기준 **1.5 / 1.2 / 1px**로 고정한다. 모선은 화면 기준 **2px** 이상으로 둔다.
5. **(P2) 다크 모선 #2b4a7a가 밴드에 묻힌다.** 08의 L4 다크 밴드와 명도가 비슷하다. 다크 모선을 **#6f93c6**으로 올린다.

## ③ round2 미반영 중 꼭 넣을 것
- **상·하류 대시 구분(색은 같게)**: 상류 18/22, 하류 **6/14**. 04에서는 TR→ACB(공급)와 모선→ATS(부하)가 똑같다. 색 충돌 없이 방향 의미를 더하는 유일한 방법이다.

- **움직임 줄이기**: 전체 흐름은 표시하지 않고 선택 경로에만 ▸를 둔다(89개 화살표 방지).
