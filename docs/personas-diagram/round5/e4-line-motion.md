# E4 백승우 — 선·모션 (round5, 최종)

## 안건 1: 사이드바를 '계층 축 레일'로
**진단**: after4/01·02에서 목록 9줄이 위쪽 360px에 몰려 있고, 그 아래 약 450px가 비어 있다. 계통도를 스크롤해도 사이드바는 L4 줄 하나에 색만 바뀐다. 지금 어디를 보고 있는지(범위)를 알 수 없다.

```
┌ 사이드바 224 ────────────┐
│ ┃ L1 초고압     4/9  ●4  │  줄 높이 = 밴드 높이 비율(최소 44·최대 120px)
│ ┃ L2 송변전     4/4      │
│ ┃ L3 특고압     2/5  ●2  │
│ ┣━┓ L4 수전    10/13 ●3  │ ← 화면 범위 괄호(지금 보이는 y 구간)
│ ┃ ┃                      │
│ ┣━┛ L5 변압     2/2      │
│ ┃ L6 저압      9/12  ●3  │
│ ┃ L7 분전·부하 15/18 ●2  │
│ ── 열 계층 ──            │
│   감시·제어 6/6 · 신재생 7/7 │
└──────────────────────────┘
```
- **축 선**: 왼쪽 12px 지점에 2px 세로선 `--color-line-power`. 줄 높이는 밴드 높이에 비례한다(diagram.json layers.height 기준). 빈 공간이 계통도의 축소판이 된다. 감시·신재생은 세로 열이라 축 밖 아래 묶음에 둔다.
- **범위 괄호**: 3px `--color-selected` 괄호가 계통도 화면의 y 시작~끝을 따라간다. useView에서 transform만 바꾸고 전환 시간 없이 직접 따라간다(pan과 같은 프레임). 괄호를 끌면 계통도가 세로로 이동한다.
- **흐름 연동(P2)**: 기기를 고르면 그 경로가 지나는 계층 구간만 축 선이 트랙 #8fbbe3 4px로 바뀌고, 선택 기기 계층에 6px 점을 찍는다. 전체 흐름 때 축 선 펄스는 넣지 않는다(움직이는 곳이 둘이면 산만하다).
- **전환 모션**: 줄 클릭 → 계통도 이동 **360ms** `cubic-bezier(.2,.7,.2,1)`. 줄 위에 마우스를 올리면 해당 밴드에 1px 테두리 페이드 **120ms**. 움직임 줄이기 설정이면 즉시 이동한다.
- **위험**: 화면이 낮을 때(높이 700 미만) 최소 44px × 7줄이 넘치면 비례를 끄고 지금 목록 방식으로 돌아간다. 기존 화면 요소를 바꾸는 일이라 사용자 확인이 필요하다.

## 안건 2: 최종 우선순위
- **P0(이번 반영)**
  - 사이드바 계층 축 + 범위 괄호 + 마우스 올림 연동
  - 선택 펄스 44px/s·18/22
  - 다크 모선 #6f93c6
  - 다크 전체 펄스 #7cbcf5
  - 공백 모드 사이드바 빨강 잔존 버그
  - 흐름 버튼은 **채움으로 양보한다**. 사용자 요청이 '초기 활성화'라서 켜짐 상태가 분명히 보이는 쪽이 맞다.
- **P1**
  - 상·하류 대시(상류 18/22, 하류 6/14)
  - 사진/이름 전환 45%
  - 범례 시트 왼쪽 아래 16px 정렬
  - 모바일 도구줄 1줄
  - 배지·참조 칩 크기
- **P2**
  - 선택 전환 페이드(200/250ms)
  - 축소 시 화면 기준 최소 선 굵기
  - 사이드바 흐름 연동
  - 모바일 시트 열림 시 자동 이동
  - 다크 밴드 8색 조정
- **사용자 확인 필요**: 사이드바 축 레일 형태, 밴드 여백 깎기, 첫 화면 '폭 맞춤 + 맨 위'
