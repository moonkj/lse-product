# E2 문가람 — 5라운드 (사이드바 재설계 · 최종 우선순위)

## 안건 1 — 사이드바를 '계층 축'으로
**진단(after4/01·02, 1440×900)**: 사이드바는 폭 224, 높이 약 828이다. 그중 목록이 쓰는 건 위쪽 약 360px(9줄 × 약 35)뿐이고, **아래 약 470px(57%)가 빈다**. 줄 높이가 모두 같아서 L4(밴드 864)와 L5(540)가 같은 크기로 보인다. 계통도와 모양이 연결되지 않는다. 'L1 초고압 765/345kV'는 두 줄로 꺾인다.

**제안: 계통도 밴드 높이에 비례하는 세로 축**
```
┌ 계층 · 보유/전체 ●공백 ┐ 제목 32
│▌L1 초고압              │ ← 높이 = 밴드 높이 비례
│▌  765/345kV     4/9 ●4│   (L1 540 → 83px)
│▌  ████░░░░░            │   보유율 막대 6px(공백분 빨강)
├────────────────────────┤
│ L2 송변전 154kV   4/4  │ 83
│ ██████████             │
│ ...                    │
│ L4 수전설비      10/13 │ 133 (밴드 864)
│ ...                    │
│ L7 분전반·부하   15/18 │ 128 (밴드 834)
├─ 측면 열 ──────────────┤
│ 감시·제어         6/6  │ 44
│ 신재생·저장       7/7  │ 44
├────────────────────────┤
│ 공백 표 →  (공백 9종)  │ 40
└────────────────────────┘
 ▌= 지금 화면에 보이는 세로 범위 표시(왼쪽 3px, 계층 고유색)
```
- **수치**: 행 높이 = max(44, (밴드 높이 / 4398) × 남는 높이(약 680)). 900 높이에서 L1·L2·L3·L5·L6은 83, L4는 133, L7은 128이다. 720 높이(1280)에서는 하한 44로 줄어든다. 이름은 15px/700 한 줄, 전압은 12px muted 둘째 줄, 숫자 고정 열은 그대로 둔다.
- **보이는 범위 표시**: 계통도 화면의 y 범위를 축에 비례해서 왼쪽 3px 띠로 그린다. 폭 맞춤으로 세로 스크롤할 때 '지금 어디쯤'을 알려 준다. 미니맵 세로판 역할이다. 값은 CSS 변수로 넘기고 rAF로 갱신해서 다시 그리는 일을 막는다.
- **폭은 224를 유지한다**(캔버스 폭을 줄이지 않는다). 1920(≥1600)만 256으로 넓힌다.
- **변경 범위**: LayerNav.tsx·LayerNav.css·AppLayout.css의 사이드바 구역만 바꾼다. 데이터는 그대로이고 model.layers의 height를 쓴다. 모바일 칩 줄은 바꾸지 않는다. testid는 유지한다.
- **위험**: 낮음~중간. 보이는 범위 표시만 view 구독이 필요하다. 기존 화면 요소의 모양이 바뀌므로 **사용자 확인이 필요하다**. 공백 모드 사이드바 빨강 버그도 이때 같이 고친다.
- 내가 반대하는 안: 계통도 왼쪽에 붙는 레일. 캔버스 폭을 먹고 끌기와 부딪힌다.

## 안건 2 — 최종 우선순위 (레이아웃 관점)
- **P0 이번 반영**: 사이드바 계층 축(사용자 확인 뒤), 사진/이름 전환 35→45%, 범례를 시트 왼쪽 아래 16px에 맞춤, 모바일 도구줄 1줄, 공백 모드 사이드바 빨강 버그.
- **P1**: 밴드 여백 깎기와 신재생 재배치. 사용자 확인 뒤 한 번에 묶어서 하고, 효과는 전체 보기 16→18%, 세로 스크롤 −9%다. 첫 화면 '폭 맞춤+맨 위'는 사용자 결정에 따른다. E4 펄스 수치, E3 배지 수치, E1 다크 밴드도 P1이다. 흐름 버튼은 켜짐=채움, 꺼짐=테두리로 한다(초기 활성화라 켜짐 상태가 분명해야 한다).
- **P2**: 칩 모서리 토큰, 1920 사이드바 256. 타일 크기 변경과 두 단 접기는 하지 않는다.
