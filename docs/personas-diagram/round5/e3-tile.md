## 안건 1 — 계층 바로가기 → '계층 레일 카드'
**진단(after4/01·03).**
- 35px 줄 9개뿐이라 화면 아래 55%가 빈다.
- "10/13 ●3"이 타일 배지의 색 언어와 이어지지 않는다.
- L1 이름이 두 줄로 꺾인다.

| 부품 | 모양·px·토큰 |
|---|---|
| 카드 | 높이 **min 56 / max 88**(`flex:1`로 세로를 채움), 모서리 8, 왼쪽 띠 4px `--band-accent-*` |
| 코드 칩 | **28×28**, 모서리 6, 바탕 `--band-l*`, 글자 13/700. 감시 ▣ · 신재생 ☀ 16px |
| 이름 | 14/600 한 줄, 전압은 2행 12px muted |
| 막대 | 폭 100% × **4px**, 커버리지 비례 구간, 색은 `--cov-*` 그대로 |
| 숫자 | "10/13" 13px tabular, 공백은 **알약 20px** "공백 3" (`--cov-missing-bg`/`-text`) |
| 축 | L1~L7 칩을 잇는 2px 세로선. 감시·신재생은 구분선 아래 '연계' 묶음 |
| 보이는 범위 | 해당 카드 왼쪽에 3px 네이비 대괄호 |
| 하단 요약 | 96px: 전체 보유 + 8px 막대. 기기를 선택하면 썸네일 40 미니카드 |

```
┌ 계층 · 76종 ──── 248px ┐
│┃[L1] 초고압  4/9 (공백4)│
│┃ │ 765/345kV ▆▆▆▆░▓▓    │
│▌[L4] 수전설비  10/13     │ ← 선택
│── 연계 ─────────────────│
│ [▣] 감시·제어     6/6    │
│┌ 보유 59/76 · 공백 9 ──┐│
│└ ▆▆▆▆▆▆▆▆▆▆░▓        ┘│

```

- **범위:** LayerNav.tsx·.css, AppLayout.css(폭 224→**248**).
- **위험:** 768px 높이에서는 카드가 56px로 줄어 스크롤이 생기므로 하단 요약을 접는다. 보이는 화면 변경이라 사용자 확인이 필요하다.
- **단계:** P0 = 카드·막대·알약·높이 채움. P1 = 축·하단 요약. P2 = 대괄호.
