# E1 남지후 — Round 5 (최종 · 색)

## 안건 1: 사이드바 색 재설계
진단(after4/01·02·03): 9줄이 모두 흰 바탕·검정 글자라 계통도 밴드 색과 연결되지 않음. 지금 계층(L4)만 색이 있어서 나머지는 색인 역할을 못 함. 1920 화면에서는 아래 60%가 빈 흰 면임.

```
┌ 계층 ────────── 224px ┐
│▌L1 초고압 765/345kV ●4│ ▌= 4px 계층 강조색 (항상 표시)
│▌████████░░░░░░  4/9   │ 보유율 막대 6px (커버리지 색 누적)
│▌L2 송변전 154kV       │ 화면에 보이는 계층 = 줄 바탕 --band-lX
│▌████████████████ 4/4  │ 지금 계층 = 띠 6px + 굵은 글자
│ …                     │
├───────────────────────┤
│ 전체 59/76 ███████░░  │ 하단 요약 (같은 막대 문법)
└───────────────────────┘
```
| 요소 | 라이트 | 다크 |
|---|---|---|
| 줄 왼쪽 띠 4px(지금 계층 6px) | `--band-accent-lX` | `--band-accent-lX`(다크값) |
| 보이는 범위 줄 바탕 | `--band-lX` | 4라운드의 채도 낮춘 다크 밴드 |
| 막대 바탕 | #eef1f5 | #2c333f |
| 막대 구간 | 보유 #1b8f44 · 일부 #a67c00 · 계열사 #2f6fd6 · 패널 #8e3a9e · 미보유 #c62d1f (구간 사이 1px 바탕색 틈) | #3cc16a · #f2c230 · #5a93f0 · #e08ad6 · #ff6b5e |
| 공백 수 알약 "●4" | 바탕 #fbe4e4, 글자 #c62d1f (4.6:1) | 바탕 #3a1a1a, 글자 #ff9b9b (7.8:1) |

- **원칙**: 계층 정체성은 **띠(계층색)**가, 보유 상태는 **막대(커버리지색)**가 맡음. 막대를 계층색으로 칠하면 L5 민트·신재생 연두가 '보유 초록'과 섞이므로 금지.
- 색각 이상 대응: 막대 구간 순서를 범례 순서와 같게 고정해, 색이 아니라 위치로도 읽히게 함.
- 위험: 낮음(LayerNav.css, 토큰만 사용). 줄 높이·축 비율은 E2 안을 따름.

## 안건 2: 최종 우선순위(색 관점)
**흐름 버튼 = 옅은 채움 + 테두리(절충)**. 사용자는 '처음부터 켜짐'이 분명히 보이기를 원함. 진한 채움은 도구줄에서 가장 강해져 선택 위계를 깨므로, 켜짐 = 바탕 #e6f0fa + 1px #0068b7 + 글자·⚡ #0068b7(4.97:1)로 함. 다크는 바탕 #1a2740 + 테두리·글자 #7cbcf5(7.4:1). 꺼짐은 지금 회색 버튼.

- **P0**: 흐름 버튼 위 절충안 · 공백 모드 사이드바 빨강 버그 · 다크 밴드 8색과 감시 열 #dfe6f0 · 다크 전체 펄스는 **#2f7fd0 유지**(E4 #7cbcf5는 밝은 선 #dfe4ea 위에서 1.58:1이라 안 보임. #2f7fd0은 선 대비 3.2, 밴드 대비 3.3). 다크 모선 #6f93c6을 채택하면 모선 위 펄스만 #dbeafc로.
- **P1**: 사이드바 재설계(안건 1) · 배지 바깥 링 판색 · 상·하류 대시(18/22·6/14, 색은 하나).
- **P2**: 칩 모서리 토큰, '해제' 외곽선 알약.
- **사용자 확인**: 사이드바 막대·띠(보이는 변화), 첫 화면 '폭 맞춤 + 맨 위'.
