접근성 전문가

철회 "스크롤하면 헤더 숨기기": 헤더가 키보드 포커스를 가릴 위험이 있습니다. 하향 로빙 tabindex는 P1로: 포커스 이동만 고쳐도 Tab 51회가 0회가 됩니다.

기술영업 과장

철회 "발표 보기에서만 내부 메모 숨김": 보기 모드마다 내용이 달라지면 안 된다는 데 동의했습니다. 발표 보기는 사이드바와 빈 패널을 접는 기능으로만 남깁니다.

신입사원

철회 별도 범례 필터: Gap 모드와 겹칩니다. 변경 Gap 모드에서 공백 계층으로 자동 이동하던 안을 안내 링크로 바꿨습니다.

현장 엔지니어

하향 오프라인 캐시는 P2로: 사양 갱신이 늦게 반영될 위험이 있습니다. 한글 오류 안내와 재시도만 먼저 합니다.

시니어 디자이너

확대 "사이드바는 계통도 화면에만"에서 기본·압축·발표 3단계 밀도 규칙으로 넓혔습니다.

쟁점별 결론

쟁점결론지지
화면 확보하나의 압축 화면 규칙을 둡니다. 낮은 화면(높이 600px 이하)·200% 확대·모바일 가로에서는 자동으로 켜고, 발표 보기 토글로 손으로도 켤 수 있습니다. 사이드바(범례)는 계통도 화면에만 둡니다. 데스크톱 기본값은 지금처럼 펼친 상태를 유지합니다.
상세 패널 운영 정보판정 근거·재확인 기한은 요약 1줄만 보이고 기본으로 접습니다. 위치는 학습 포인트 뒤로 옮깁니다. 데이터는 그대로입니다.
Gap 모드흐림 대신 회색 채움을 쓰고 글자 대비 4.5:1을 지킵니다. 공백 타일 강조는 그대로입니다. 공백이 없는 계층에서는 "공백 있는 계층 보기" 링크를 보여 주고 자동으로 이동하지 않습니다. 범례 클릭은 Gap 강조로 합칩니다.
첫 방문 시작 카드주소에 파라미터가 없는 첫 방문에서 한 번만 보여 줍니다. 닫으면 다시 뜨지 않습니다. 모바일에서는 1줄 배너로 줄입니다.
제품 자료 바로가기순서는 그대로 둡니다. 기존 "자료 N건" 칩을 [옵션별 사양][카탈로그 n][매뉴얼 n] 바로가기 칩으로 바꾸고, 새 버튼은 추가하지 않습니다.
비교 링크 공유비교 화면에 링크 복사 버튼을 두고, "차이만 보기" 상태도 주소에 저장합니다.

하지 말 것

  • Gap 모드에 들어갈 때 다른 계층으로 자동 이동 (5명 전원)
  • 스크롤하면 헤더 숨기기 (포커스를 가림)
  • 발표 보기 전용 콘텐츠, 보기 모드별로 다른 내용
  • 자동 팬을 고치기 전에 비교 바·미니맵 키우기
  • 이번 라운드에 서비스워커 전체 캐시 적용
  • 데스크톱에서 범례를 기본으로 접기

리더 판정

U1 바로 진행 버그 B1~B10, "차이만 보기" 상태 주소 저장, 용어집 4개 추가(택1·참조 타일·공백 후보/확정·패널 구성품), 터치 대상 44px.

U2 사용자 확인 후 기존 화면 요소를 바꾸는 항목입니다.

  1. 압축 화면 규칙 + 발표 보기 토글 + 사이드바를 계통도 화면에만
  2. 상세 패널 운영 정보 요약 1줄 + 기본 접힘
  3. Gap 모드 회색 채움 + 안내 링크 + 범례 클릭으로 강조
  4. 첫 방문 시작 카드
  5. 제품 페이지 자료 바로가기 칩
  6. 비교 화면 링크 복사 버튼

보류 계통도 로빙 tabindex(P1), 다크 모드 컬러 로고, 다크 모드 사진 대비, 미니맵 가림, 오프라인 캐시(P2), 비교 정원 확대.
