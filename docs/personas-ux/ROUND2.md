# UX 토론 2라운드 — 교차 반박

1라운드 보고서 5개: `round1/{sales,designer,a11y,newbie,field}.md`. 모두 읽은 뒤 아래 쟁점에 대해 **찬성·반대·절충**을 근거(직접 조작·측정값)와 함께 밝힌다.
사용자 결정(CONTEXT.md)은 재논의하지 않는다. 기존 화면 요소를 바꾸는 안은 "사용자 확인 필요"로 표시한다.

## 합의 후보 (반대 의견만 적어도 됨)
- A1. 버그: 제품 상세 문서 넘침(헤더 사라짐, 디자이너) · 모바일 제품 페이지 1,168px 폭 → 비교 바 화면 밖(현장) — 같은 원인일 가능성
- A2. 위치 동기화: 검색·선택 시 지도 이동, 계층 표시 오류(L1→L2), 자동 팬은 패널·미니맵 뺀 "보이는 영역" 기준(디자이너·접근성)
- A3. 포커스 관리: 선택 → 패널 제목, Esc → 타일 복귀(접근성)
- A4. 뒤로가기: 기기 선택을 기록에 남김(현장)
- A5. 문구 통일: "4종/4개", L7 이름, 개발 메모 숨김(디자이너·신입)
- A6. 패널 구성품 vs "공백 확정" 표시 불일치(신입)
- A7. 형식명·옵션명 검색(TS250·ABN 0건, 현장)

## 쟁점 (반드시 입장 표명)
- I1. **화면 확보 방식**: 영업 "발표 보기 토글(사이드바·패널 접기)" vs 접근성 "낮은 화면·확대 시 헤더 자동 접기" vs 현장 "모바일 스크롤 시 헤더 접기·가로는 사이드 패널" vs 디자이너 "사이드바는 계통도 화면에만". 하나의 규칙으로 묶을 수 있는가?
- I2. **상세 패널의 운영 정보**(판정 근거·재확인 기한·회의 기록): 접기 기본값? 발표 보기에서만 숨김? 순서만 뒤로?
- I3. **Gap 모드 표현**: 접근성 "opacity 대신 회색 채움 + 4.5:1" vs 공백을 강하게 드러내야 하는 영업. 신입 "공백 0개 계층에 머무를 때 안내 링크" — 자동 이동 vs 안내.
- I4. **첫 방문 시작 카드**(신입): 영업·현장에게 방해인가? 1회·닫기 영구로 충분한가?
- I5. **범례 클릭 필터 + 용어집 연결**(신입): Gap 모드와 기능 중복을 어떻게 정리?
- I6. **계통도 키보드 로빙 tabindex**(접근성): 데스크톱 마우스 사용자·기존 동작에 영향? 
- I7. **제품 페이지 자료 바로가기**(현장 "자료 n건" 칩 → 매뉴얼 앵커, 신입 "카탈로그 PDF" 버튼): 영업은 사진·설명 먼저 원함 — 순서 유지 + 바로가기로 충분?
- I8. **오프라인 캐시·한글 오류 안내**(현장): 범위·비용 대비 가치? 데이터 갱신 지연 위험?
- I9. **우선순위**: 위 전체에서 당신이 꼽는 "다음 라운드에 반드시 할 것" 5개(P0)와 "하지 말 것" 1개 이상.
