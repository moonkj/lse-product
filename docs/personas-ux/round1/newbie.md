## 1. 나는 누구 · 쓰는 상황 · 기기
- 전기공학과를 졸업했고 입사 1주차. 단선결선도는 학교에서 본 적이 있지만 자사 제품명(Susol, Metasol 등)은 모름.
- 선배가 "이거 한번 봐 둬" 하며 주소만 줬음. 안내 없이 노트북(1440×900)으로 `/`부터 열었고, 이동 중에 휴대폰(390×844)으로 잠깐 봄.
- 바라는 것: 기기 이름과 역할 익히기, 우리 회사가 무엇을 팔고 무엇이 없는지 알기, 카탈로그 찾기.

## 3. 좋은 점
- 검색: 한글("기중", "차단기")과 영문("susol", "ACB") 모두 기기와 제품이 함께 나오고, Enter를 누르면 바로 계통도 위치로 감 (s4 결과).
- 상세 패널의 "신입 학습 포인트" 2줄과 "계통에서 연결된 기기"(↑MOF ↓TR …) 칩 덕분에 계통 흐름을 따라 이동하며 배우기 좋음 (04-vcb-panel.png).
- 참조 타일 패널에 "같은 기기가 계통에 다시 나오는 자리 · 원래 위치로 이동 →"가 있어 개념이 바로 이해됨 (24-ref-tile.png).
- 투어 단계 설명이 짧고, 단락 하나에 "이 계층에서 무엇이 무엇을 한다"가 다 들어 있음. 핵심 기기 카드를 누르면 계통도로 이어짐 (21-tour-L4.png).
- 비교 바(2/4, "1개 더 담으면 비교")가 다음 행동을 알려 줌 (15-after-add-mccb.png).

## 4. UX/UI 문제

**높음**
1. **첫 화면에서 할 일이 안 보임**: `/`로 열면 아무 설명 없이 L4에 확대된 상태로 시작함. 오른쪽 패널은 "기기를 누르면…"이라는 안내 한 줄과 키보드 안내뿐임. "교육" 탭이 우측 상단 작은 세그먼트에 있어 처음 쓰는 사람이 투어를 발견하기 어려움 (01-first.png).
2. **패널 구성품과 공백 판정이 서로 다르게 보임**: LA 타일 배지는 "패널 구성품(타사 조달)"인데, 패널을 열면 "공백 판정: 공백 확정"이 나옴. Gap 모드 규칙은 "패널 구성품 — 보통"이라 강조하지 않음. 신입은 이게 공백인지 아닌지 판단할 수 없음 (23-la-panel.png, 17-gap-mode.png).
3. **Gap 모드에 들어가도 공백이 안 보임**: 현재 계층(L4, 공백 0)에 그대로 머물러서 빨간 강조가 화면에 없음. 미니맵의 빨간 점이 유일한 단서임 (17-gap-mode.png).

**중간**
4. 범례 항목(미보유 9 등)을 눌러도 아무 일이 없음. 숫자가 있으니 누르면 목록이나 필터가 나올 거라 기대함.
5. 용어집에 앱 고유 용어(택1, 참조 타일, 공백 후보·확정, 패널 구성품)가 없음. 계통도의 "택1" 배지에 마우스를 올려도 설명이 안 나옴.
6. 패널 정보가 너무 많고 순서도 신입에게 맞지 않음: LA 패널에서 메모 → 공백 판정·판정 근거·재확인 기한·"회의 2026-11-18 사용자 확정 지시…" 같은 운영 기록이 학습 포인트보다 위에 있음 (23-la-panel.png).
7. 내부·개발 문구가 노출됨: "HTTP Range", "docs.json"(제품 상세), "콘텐츠 상태: draft"(교육).
8. 제품 상세에서 카탈로그 PDF 위치가 너무 아래에 있음 (T5).

**낮음**
9. 계층 이름이 화면마다 다름: 사이드바 "L7 분전반·부하", 계통도 "L7 분전반 및 부하", 검색·공백 표 "L7 분전반 및 하단".
10. "전체 보기"(18%)를 눌러도 상단 라벨은 "L4 수전설비"로 남고 사이드바도 L4가 강조된 상태임. 18% 배율에서는 타일 글자를 읽을 수 없음 (06-fullview.png).
11. 미니맵과 비교 바가 계통도 하단 타일을 가림 (15-after-add-mccb.png).
12. 모바일 첫 화면 텍스트에 범례·커버리지가 없어 색과 기호의 뜻을 알 수 없음 (26-mobile-first.png).
13. "Gap"만 영문이라 신입은 "공백"과 같은 말인지 잠깐 헷갈림.

## 6. 다른 페르소나와 충돌할 지점
- S1 시작 카드는 매일 쓰는 영업·숙련 사용자에게 방해가 됨 → 최초 1회만, 닫으면 다시 안 뜨게 해야 함.
- S5 패널 순서 변경과 운영 기록 접기는 판정 근거를 보는 관리자·기획 페르소나와 충돌함 → 접기만 하고 삭제하지 않음.
- S3 Gap 모드 자동 이동은 "현재 위치 유지"를 원하는 사용자와 충돌함 → 자동 이동 대신 안내 링크 방식이 안전함.
- S4 범례 클릭 필터는 Gap 모드 강조와 기능이 겹침 → 설계를 통합해야 함.

## 7. 성공 지표
- 첫 방문자가 30초 안에 첫 타일을 클릭하거나 투어를 시작하는 비율(현재는 첫 화면에 투어 입구 노출이 약함).
- 안내 없는 사용성 테스트에서 "패널 구성품이 공백인가?" 질문에 맞게 답한 비율 80% 이상.
