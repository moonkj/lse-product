## 3. 좋은 점
- **상태 시스템이 탄탄함**: 6상태가 색+기호(✓◐◆⊡✕–)로 이중 부호화되어 계통도·사이드바·공백 표·Gap 모드에서 일관됨 (`light-gap.png`, `dark-gapmode2.png`).
- Gap 모드는 "강조/보통/흐리게" 규칙을 범례에 그대로 써 놓아 시각 규칙이 학습 가능 (`dark-gapmode2.png`). 미니맵에 공백 점까지 표시.
- 빈 상태 품질 좋음: 검색 결과 없음에 추천 칩 제공(`search-none.png`), 없는 제품/페이지 메시지 + 돌아가기(`light-bad.png`).
- 제품 상세의 사양 출처 `p.18` 링크와 "카탈로그 추출값·검수 전" 배지 — B2B 신뢰 디자인의 모범 (`light-product.png`).
- 다크 모드 표 배지·공백 칩의 채도 조정이 잘 되어 있음 (`dark-gap.png`).

## 4. UX/UI 문제
### 높음
1. **제품 상세 이중 스크롤 / 빈 여백** — `/#/product/P00206` 휠 스크롤 시 `documentElement.scrollHeight=1810`(본문 900)이 되어 창 전체가 스크롤, 헤더 소실·하단 400px 공백. 옵션 사양 표 내부 `visually-hidden`·sticky TH가 문서 밖으로 새는 것으로 보임 (`light-product-scroll2.png`).
2. **현재 위치 표시 불일치** — (a) 검색·딥링크로 다른 계층 기기 선택 시 지도 미이동·줌 유지, 사이드바/툴바 위치 갱신 안 됨 (T1). (b) L1 클릭 후 L2 표시 (T2). 지도형 IA의 핵심 "나는 지금 어디" 신호가 틀림.
3. **다크 모드 로고 무채색화** — 라이트는 LS 블루+레드 액센트, 다크는 회색 단색으로 브랜드 색이 사라짐 (`light-logo.png` vs `dark-logo.png`). 관리자 다크 헤더도 동일.

### 중간
4. **전역 사이드바가 모든 화면에 고정** — 제품 상세·비교·공백 표·교육에서도 계층 바로가기+계통도 범례(전력선/모선/택1…)가 노출. 공백 표 화면에 "공백 표 보기" 버튼이 또 있음 (`light-gap.png`). 맥락 없는 정보 + 가로 200px 손실.
5. **헤더 내비 라벨/활성 상태** — 계통도 탭 이름이 "제품"인데, 정작 제품·기기·비교 화면에선 어떤 탭도 활성 아님 (`light-product.png`, `light-cmpprod.png`).
6. **되돌아가기 패턴 3종 혼재** — 기기/제품/비교: 브레드크럼, 공백 표: "← 계통도로 돌아가기", 교육: "투어 끝내기".
7. **마이크로카피 불일치** — 제품 수: 패널 "제품 4종" / 기기 상세 "자사 제품 4개" / 비교 "4개 — 목록 보기". L7 명칭: 사이드바 "분전반·부하" / 공백 표 "분전반 및 하단". 행 순서: 사이드바 감시→신재생, 공백 표 신재생→감시.
8. **다크 모드 제품 사진 대비** — 짙은 MCCB·WHM 사진이 어두운 카드 배경에 묻힘 (`dark-cmpprod.png`, `dark-main.png` WHM 타일). 비교표 썸네일도 너무 작음(약 60px).
9. **"+" 아이콘 단독 버튼** — 패널·기기 상세의 자사 제품 "+"가 "비교에 담기"인지 알기 어려움(텍스트 버튼 "+ 비교에 담기"와 병존). 기기 상세 자사 제품 4장이 같은 사진이라 구분이 안 됨 (`light-equip.png`).
10. **공백 패널의 운영 메타데이터 과다** — 발전기 패널에 판정 근거·재확인 기한·회의 메모가 학습 포인트보다 위에 나옴 (`panel-gap.png`). 신입/영업에겐 위계가 거꾸로.

### 낮음
11. 미니맵이 캔버스 우하단 타일을 가리고, 태블릿에선 비교 바와 겹침 (`tablet-main.png`). 전체 보기(18%)에선 미니맵이 무의미.
12. 테마 수동 전환 수단 없음(OS 따라감) — 발표 화면에서 라이트 고정 불가.
13. 우측 패널 빈 상태("상세 정보" 안내문)가 넓은 공간을 비워 둠 — 계층 요약이나 최근 본 기기로 활용 가능.

| C. 다크 전용 로고(흰 워드마크+브랜드 레드 액센트 또는 공식 리버스 로고) | 브랜드 일관성 | S | P1 | 작음(로고) |

## 6. 다른 페르소나와 충돌할 지점
- **영업/현장 페르소나**: 사이드바 범례 상시 노출을 "한눈에 보여서 좋다"고 볼 수 있음 → D는 접힘 기본값 대신 "기억되는 토글"로 절충 가능.
- **교육 담당/신입**: 공백 판정 메타(G)를 접으면 학습 맥락이 줄어든다고 볼 수 있음; 반대로 **운영 담당**은 판정 근거를 맨 위에 두길 원할 것.
- **접근성/개발 페르소나**: B의 자동 팬·줌은 모션 민감 사용자(prefers-reduced-motion) 고려 필요, 구현 노력 M 이상.
- 탭 라벨 "제품"→"계통도"는 기존 사용자 학습과 충돌 가능 — 메모리 규칙상 사용자 확인 후 진행.
