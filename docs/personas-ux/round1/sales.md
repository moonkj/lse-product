스크린샷 폴더: `/private/tmp/claude-501/-Users-kjmoon-LSE-News/37bcf7f5-4ef4-4874-8316-789fc9001612/scratchpad/ux-sales/` (아래에는 파일 이름만 적음, 접두어 tab=1024×768 터치 / lap=1280×800)

## 1. 나는 누구 · 사용 상황 · 기기
- 기술영업 과장. 고객사(설계사무소, 플랜트, 건물 전기 담당) 미팅에서 화면을 **고객 쪽으로 돌려서** 설명함. 대부분 태블릿(1024×768 가로, 손가락 조작), 회의실 TV에 연결할 때는 노트북(1280×800).
- 필요한 것: ① 계통도로 "우리가 어디까지 공급하나"를 보여 주기 ② 질문이 나오면 바로 옵션별 정격 비교 띄우기 ③ 미팅이 끝난 뒤 비교 링크를 메일로 보내기. 고객 앞에서 관리자 화면이나 내부 메모가 보이면 안 됨.

## 3. 좋은 점 (화면 근거)
- **관리자 노출 없음**: 메인 DOM에 admin/관리자 링크 0건, 편집 버튼 없음. 발표하다 실수로 들어갈 길이 없음.
- **검색이 빠름**: 'ACB', 'GIPAM' 입력 즉시 기기와 제품이 함께 나오고, Enter를 누르면 해당 타일로 이동함(`?node=n-acb`).
- **URL로 상태 공유**: 선택 기기, Gap 모드, 비교 목록이 모두 주소에 들어가 있어 링크만 보내면 같은 화면이 열림. 화면 전환 0.5~0.7초로 빠름.
- **비교 표 머리 고정 + 차이만 보기**: 스크롤해도 제품 이름 줄이 위에 고정됨(tab-24). '값이 모두 같은 12개 행을 숨겼습니다'라는 안내가 명확함.
- **카탈로그 쪽수 출처(p.18)**: 고객이 "근거가 뭐냐"고 물으면 바로 원문을 열 수 있음.
- 200%까지 확대하면 타일·택1 라벨이 TV에서도 또렷함(lap-41-maxzoom).

## 4. UX/UI 문제
**높음**
- H1. 태블릿 1024에서 계통도 폭 약 465px. 아무것도 선택하지 않아도 우측 360px '상세 정보' 빈 패널이 늘 자리를 차지하고, 좌측 사이드바(범례·커버리지)도 접을 수 없음. 그래서 설명용 배율(80% 이상)에서는 타일이 2~3개밖에 안 보임. (tab-01-main, tab-03)
- H2. 공백 타일 패널의 **내부 작업 메모**(찾지 못함·확인 필요·재확인 기한·회의 지시)와 범례의 **'패널 구성품(타사 조달)'** 문구가 고객 앞에서 그대로 보임. 공개/사내판 분리는 하지 않기로 했으므로, 화면 표현을 접어 두는 방식이 필요함. (tab-30-rc)
- H3. 비교 화면에 링크 복사 버튼이 없음. 안내 문구('주소를 복사하면…')만 있음. (tab-16)

**중간**
- M1. 비교 첫 화면에서 정격 행이 스크롤해야 나옴. 같은 값 행이 많은데 `차이만 보기`가 꺼진 상태로 시작함.
- M2. 계층 바로가기를 눌러도 해당 띠 전체가 맞춰지지 않음(L4가 아래로 잘림). '이 계층 전체'를 한 번에 보여 줄 수 없음.
- M3. 사이드바 커버리지의 '미보유(공백) 9'와 상단 Gap 탭이 모든 화면에 늘 보여서, 고객이 먼저 "9개는 없는 거냐"고 물을 수 있음.
- M4. 시리즈 단위 VCB 비교는 셀이 10줄 이상 늘어나 멀리서 비교가 안 됨. 같은 사진 3장도 구분에 도움이 안 됨.

**낮음**
- L1. 미니맵이 1024에서 계통도 오른쪽 아래 약 100×170px를 덮고, 비교 바가 뜨면 함께 겹쳐서 하단 타일이 가려짐. (tab-22)
- L2. '카탈로그 추출값 · 검수 전' 배지가 비교 머리 오른쪽에 노란색으로 눈에 띄어 고객에게 "검수 안 된 숫자"라는 인상을 줌(문구 자체는 필요).
- L3. Esc를 누르면 선택이 풀리고 주소가 `#/`로 돌아감. 발표 중 실수로 누르면 설명하던 위치를 잃음(뒤로가기로 복구 가능).

## 6. 다른 페르소나와 충돌할 지점
- **기획·공백 관리 담당**: 공백 메모·판정 근거를 늘 펼쳐 두기를 원함 → 발표 보기에서만 접는 것으로 절충(기본 화면은 지금과 같음).
- **신입 교육 담당**: 좌측 범례와 커버리지를 항상 보여 주기를 원함 → 사이드바 접기는 토글로 하고 기본값은 펼침으로 유지.
- **데이터 정확성 담당**: '검수 전' 배지를 흐리게 하는 데 반대할 수 있음 → 문구는 유지하고 위치나 크기만 조정하는 선에서 논의.
- 사용자 결정(공개판 분리 안 함)과 부딪히지 않도록, S2는 데이터를 숨기거나 분리하지 않고 **표시 방식만** 바꾸는 제안으로 한정함.

## 7. 성공 지표
- 1024 태블릿에서 'L4 수전설비 구성 설명'을 타일 라벨을 읽을 수 있는 배율로 **2탭 이내**(현재: 띠 전체를 판독 가능하게 보는 방법 없음).
- 'ACB 프레임 비교 → 링크 복사'까지 **7탭 → 5탭 이하**, 비교 첫 화면에 정격 행이 보일 것.
