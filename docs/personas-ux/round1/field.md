## 3. 좋은 점 (화면 근거)
- **검색이 첫 화면 맨 위**에 있고, 「GIPAM1000」「gipam1000」「GIPAM 1000」 모두 1위로 찾음. 결과 줄 높이 55px로 장갑 낀 손으로도 누를 만함 (t1-1-search).
- PDF 링크가 카탈로그 **해당 쪽(#page=12)으로 바로** 열려 정격 근거를 확인하기 좋음. 매뉴얼·카탈로그를 나눠 표시하고 날짜도 보여 줌 (t1-5-docs).
- 옵션 표의 「사양」 열이 고정돼 가로로 스크롤해도 행 이름이 보임 (t2-5-compare1).
- 지도 핀치 확대가 실제로 작동(75→200%). 시트를 펼치면 Susol VCB 매뉴얼 링크가 시트 안에 바로 있어 VCB 매뉴얼은 탭 2번이면 열림 (t6-2-conn).
- 첫 로딩이 가벼움: 압축 전송 기준 약 424~459KB, 썸네일 1장 35KB 이하.

## 4. UX/UI 문제
**높음**
1. **모델·옵션명 검색 0건** — TS250/ABN/TD100 등 명판에 적힌 형식명으로는 찾을 수 없음. 현장 사용 흐름이 첫 단계에서 끊김. 재현: 검색창에 `TS250` 입력.
2. **제품 페이지 비교 바가 보이지 않음 (T4)** — 담아도 아무 반응이 없는 것처럼 보임. 재현: `/#/product/P01900` → 옵션 2개 담기. GIPAM1000 페이지도 innerWidth가 450px로 늘어남.
3. **가로 모드에서 지도 0px** — 844×390에서 헤더·계층칩·툴바가 위쪽 약 200px를 차지하고 나머지는 시트가 다 덮어 계통도가 전혀 보이지 않음 (t9-3-land).
4. **뒤로가기 맥락 손실** — 연결 기기를 따라간 뒤 뒤로가기를 누르면 첫 화면으로 감. 제품 페이지에서 돌아와도 시트가 접히고 스크롤 위치도 사라짐.
5. **오프라인·끊김 시 영문 오류** — 지하에서 제품 페이지를 열면 「이 화면을 표시하는 중 오류」 + 영문 스택 메시지가 뜸.

**중간**
6. 세로 화면을 상단 고정 영역(헤더 139 + 계층칩 47 + 줌 툴바 ≈ 240px, 화면의 28%)이 차지하고, 시트까지 열리면 **보이는 지도는 약 217px(390×844), 약 160px(360×740)**. 비교 바가 지도 위에 뜨면 약 150px로 줄어듦 (t3-1-vcb, t9-1-360).
7. **시트 핸들을 끌어도 펼쳐지지 않음** — 손잡이 모양만 있음. 「위로 올려 전체 정보 보기」라는 문구와 실제 동작(탭)도 맞지 않음. 펼친 뒤 「시트 줄이기」 버튼(y 784)이 목록 줄(y 785)을 가림.
8. 시트 위에서 핀치하면 **브라우저 전체가 5배 확대된 채로 남음**(viewport에 확대 제한 없음). 한 손으로는 되돌리기 어려움 (t5-1b-pinch-sheet).
9. 제품 페이지의 매뉴얼 섹션까지 3화면 넘게 스크롤해야 함. 「자료 N건」 칩은 눌러도 반응이 없음.

**낮음 (터치 대상 44px 미만)**
10. 계층칩 40~42×30, 줌 ± 36×34, 연결 기기 칩 높이 30, 시트 안 PDF 링크 높이 22, 정격표 「p.12」 링크 22×15, 빵부스러기 높이 16, 제품 줄의 「+」 36×43.
11. 다크 모드에서 검은 제품 사진(MCCB 등)이 남색 타일 배경에 묻힘 (t9-5-dark). GIPAM1000 대표 사진에 "XGIPAM" 표기가 보여 확인이 필요함 (t1-2-result).

## 6. 다른 페르소나와 충돌할 지점
- **P5 헤더 접기·가로 모드 사이드 패널**: 데스크톱·교육 페르소나는 L1~L7 계층칩과 Gap 탭이 항상 보이기를 원함. 모바일에서만 접는 방향으로 조정 필요(눈에 띄는 변화라 사용자 확인 대상).
- **P1 옵션까지 검색**: 신입·교육 관점에서는 결과가 길어져 기기(개념) 결과가 뒤로 밀림. 정확히 일치하는 항목만 위로 올리고 기기는 항상 1줄 보장하는 식으로 절충.
- **P3 자료 우선 배치**: 영업 페르소나는 사진·설명·계통 위치를 먼저 보고 싶어 함 → 순서는 유지하고 앵커만 추가하는 선에서 절충.
- **P6 오프라인 캐시**: 관리자/데이터 담당은 사양 갱신이 늦게 반영되는 문제(캐시 무효화)를 걱정할 수 있음.

- 390×844 세로 화면에서 시트가 열린 상태로 **보이는 지도 높이 400px 이상**, 가로 모드 **200px 이상** (현재 217px / 0px).
