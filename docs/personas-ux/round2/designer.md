# 2라운드 — 시니어 UX/UI 디자이너 (교차 반박)

근거: 1라운드 5개 보고서와 내 1라운드 스크린샷(`scratchpad/ux-designer/`). 코드·데이터 수정 없음.

## 합의 후보 — 반대·보완 의견만
- **A1 찬성 + 보완**: 내가 본 데스크톱 문서 넘침(제품 상세 `scrollHeight 1810`)과 현장의 모바일 1,168px 폭은 같은 원인으로 봄. 둘 다 제품 옵션 표 안 `visually-hidden` 절대배치 요소가 원인으로 의심됨. 수정한 뒤 1440·390 두 폭에서 "문서 높이 = 창 높이, 문서 폭 = 창 폭"을 회귀 테스트로 고정할 것.
- **A2 찬성 + 보완**: 계층 표시는 "화면 중심"이 아니라 **선택된 기기 기준**이 우선이고, 선택이 없을 때만 화면 중심 기준. 전체 보기(18%)에서는 "전체 74종"으로 표시(신입 #10과 같은 현상).
- **A5 보완**: 단일 용어 소스(계층 이름·순서, 수량 단위 "개")를 정하고 사이드바·공백 표·검색·교육이 함께 참조. 문구만 고치면 다시 어긋남.
- A3·A4·A6·A7: 이견 없음.

## 쟁점별 입장

**I1. 화면 확보 — 하나의 규칙으로 묶을 수 있음 (입장 변경: "계통도 화면에서만 사이드바" → 아래 규칙으로 확장)**
"**크롬(chrome) 밀도 3단계**"를 하나의 레이아웃 상태로 정의하자.
1. 기본: 지금과 같음.
2. 압축: 사이드바는 아이콘 레일(약 48px), 빈 상세 패널은 숨기고 선택 시 오버레이로 표시, 헤더는 검색만 남김.
3. 발표: 압축 + 범례·커버리지 숨김.

진입 조건만 다르게 둔다.
- 자동: 창 높이 600px 이하, 200% 확대, 모바일 세로 스크롤, 가로 모드는 사이드 패널.
- 수동: 영업의 "발표 보기" 토글(`&present=1`).
- 화면별: 상세·비교·표·교육 화면은 범례를 기본으로 접음.

이렇게 하면 접근성(P4)·현장(P5)·영업(S1)·디자이너 안이 같은 컴포넌트 상태를 공유해 구현을 1벌로 끝낼 수 있음. 1024 기준 계통도 폭은 465px에서 약 930px 이상(영업 측정 기준). 기존 화면 요소를 바꾸므로 **사용자 확인 필요**.

**I2. 운영 정보 — 순서는 뒤로, 기본은 접기, 발표 보기에서는 접힘 강제**
"요약 1줄(예: 공백 확정 · 재확인 2027-05)"만 남기고 판정 근거·기한·회의 기록은 "판정 상세 ▸"로 접는다. 지금 발전기 패널은 메타 정보 7줄이 학습 포인트보다 위에 있음(`panel-gap.png`). 발표 보기에서만 숨기면 기본 화면에서는 신입이 계속 혼란스러움. 데이터는 그대로 두고 표시만 바꾸므로 공개판 분리 결정과 충돌하지 않음. 패널 순서가 바뀌므로 **사용자 확인 필요**.

**I3. Gap 모드 — 접근성 안에 찬성, 자동 이동은 반대하고 안내로**
opacity 0.3(글자 대비 1.9:1)은 디자인적으로도 "흐린 게 아니라 깨진" 인상을 줌. 보유 타일은 회색 채움·테두리 연하게·글자 4.5:1로 처리하고, 공백 타일에 빨간 테두리와 채움을 더하면 강조 대비는 오히려 커짐(배경과 상태색의 차이로 강조). 공백이 0개인 계층은 Gap 배너에 "이 계층 공백 없음 · 공백 4: L1 / L6 →" 링크로 안내. 자동 이동은 A2(위치 신뢰)와 충돌함.

**I4. 시작 카드 — 찬성 (조건부)**
조건: 첫 방문 1회, 닫으면 영구 미표시, 공유 링크(`?node=`, `?mode=`, compare)로 들어왔을 때는 미표시, 계통도 위 비모달 카드(포커스 가두지 않음). 영업·현장은 대부분 링크나 재방문으로 들어오므로 방해가 거의 없음. 기존 요소를 바꾸지 않는 추가안이지만 보이는 변화이므로 확인을 받을 것.

**I5. 범례 필터 — Gap 모드로 통합, 별도 필터는 반대**
범례 항목 클릭은 새 필터가 아니라 "그 상태만 강조"하는 **Gap 모드의 일반화**로 정의한다. 미보유를 누르면 `?mode=gap&focus=missing`. 강조 규칙과 시각 언어를 하나로 유지해야 화면 상태 수가 늘지 않음. 용어 연결은 범례 옆 ⓘ에서 용어집 항목으로 연결(동작 분리: 라벨=필터, ⓘ=정의). 범례 동작이 바뀌므로 **사용자 확인 필요**.

**I6. 로빙 tabindex — 찬성**
마우스 사용자는 시각 변화가 없고 영향도 없음. 조작 안내 문구("Tab으로 기기 이동")만 갱신하면 됨. Tab 74회를 1회로 줄이는 효과는 큼. 기존 E2E 테스트 수정은 비용이지 반대 사유가 아님. 단, 포커스 링 스타일은 지금 것(2~3px 파랑)을 유지할 것.

**I7. 자료 바로가기 — 순서 유지 + 바로가기로 충분**
기존 "자료 6건" 칩(지금은 SPAN이라 눌리지 않음)을 앵커 버튼으로 바꾸면 버튼을 새로 늘리지 않아도 됨. 상단 버튼이 이미 4개(위치·공식 페이지·자료실·비교)라 "카탈로그 PDF"를 더하면 5개가 되어 위계가 무너짐. 대신 "자료실에서 전체 자료 보기 ↗"를 칩 앵커 안으로 흡수하는 정리를 제안.

**I8. 오프라인 캐시 — 한글 오류 안내만 P1, 서비스워커는 P2**
청크 로드 실패 시 영문 스택이 보이는 것은 품질 결함이므로 S 노력으로 즉시 고칠 것("연결이 끊겼습니다 · 다시 시도"). 서비스워커 전체 캐시는 데이터 갱신 지연·무효화 설계 비용이 커서, 실제 지하 사용 빈도를 확인한 뒤 진행. 앱 셸·청크 사전 로드(prefetch)만으로도 대부분 해결될 수 있음.

## I9. 다음 라운드 반드시 할 것 (P0 5개)
1. **A1 문서 넘침 버그**(데스크톱 헤더 소실 + 모바일 비교 바 실종) 수정과 회귀 테스트.
2. **A2+A3 위치·포커스 동기화**: 선택한 기기로 "보이는 영역" 기준 팬, 계층 표시는 선택 기준(L1→L2 오류 포함), 포커스는 패널 제목으로, Esc로 타일 복귀.
3. **A7 옵션·형식명 검색**(TS250 0건): 현장의 첫 단계가 끊기는 문제.
4. **I2 운영 정보 접기 + A6 패널 구성품/공백 판정 표현 통일 + A5 용어 단일 소스**: 문구·순서 정리 묶음(사용자 확인 후).
5. **비교 화면 링크 복사 버튼**(영업 S3): 작은 노력으로 공유 흐름 완성. Gap 모드의 컴포넌트를 재사용해 일관성도 확보.

다음(P1): I1 크롬 밀도 3단계(확인 후), I3 Gap 대비, I6 로빙, 다크 모드 로고와 제품 사진 받침, I8 한글 오류.

## 하지 말 것
- **Gap 모드에서 공백 계층으로 자동 이동**: 위치 신뢰를 깨뜨림. 안내 링크로 대체.
- **화면마다 따로 만드는 레이아웃 토글**(발표 보기·모바일 접기·확대 접기를 각각 구현): 상태가 폭증해 일관성이 무너짐. I1의 단일 상태 모델로만.
- **범례 클릭을 Gap 모드와 별개의 필터로 구현**: 같은 의미의 강조가 두 벌이 됨.
- 상단 버튼 줄에 버튼을 더 추가하는 방식의 자료 바로가기(I7).
