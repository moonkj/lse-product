## 쟁점별 입장

**I1. 화면 확보 방식 — 절충. 하나의 규칙으로 묶을 수 있다.**
- 규칙: "계통도 화면에서만 사이드바(범례 포함)를 보인다"(디자이너 안)를 기본으로 한다. 그다음 "화면이 좁거나 낮을 때(높이 600px 이하·200% 확대·모바일 가로)만 헤더를 자동으로 접는다"(접근성·현장 안)를 더한다. 영업의 "발표 보기"는 같은 접기 동작을 수동 토글로 켜는 것으로 정리한다. 이렇게 하면 레이아웃 상태가 펼침/접힘 두 가지뿐이다.
- 조건: 데스크톱 계통도 화면의 기본값은 범례 펼침으로 유지해야 한다. 나는 1라운드에서 범례를 보면서 6상태와 선 종류를 해석했다(01-first.png). 처음부터 접혀 있었다면 색의 뜻을 알 길이 없었다.
- 기존 화면 요소를 바꾸는 안이므로 **사용자 확인 필요**.

**I2. 상세 패널의 운영 정보 — 기본값을 접기로 한다(발표 보기에서만 숨기는 데 반대).**
- 근거: LA 패널에서 판정 근거·재확인 기한·"회의 2026-11-18 사용자 확정 지시"가 학습 포인트보다 위에 있었다(23-la-panel.png). 신입은 발표 보기를 켤 이유가 없으므로, 발표 보기에서만 숨기면 신입에게는 아무것도 바뀌지 않는다.
- 제안: 순서를 "설명 → 학습 포인트 → 자사 제품 → 자료 → 공백 판정 요약 1줄 → 판정 상세 ▸(접힘)"으로 바꾼다. 요약 1줄은 늘 보이므로 기획 담당 정보가 사라지지 않는다. 디자이너 G안, 영업 S2안과 같은 방향이다.
- **사용자 확인 필요**.

**I3. Gap 모드 표현 — 접근성 안(회색 채움 + 글자 대비 4.5:1)에 찬성. 공백 0 계층에서는 자동 이동이 아니라 안내로 한다.**
- 근거: 흐리게 처리된 타일은 이름을 읽을 수 없다(r2-03). 공백이 무엇 옆에 있는지 읽혀야 배울 수 있다. 반면 빨간 공백 타일은 49%에서도 충분히 강하다. 그래서 대비를 올려도 영업이 원하는 강조는 유지된다고 본다.
- 공백 0 계층 처리: 1라운드에서는 자동 이동도 대안으로 적었지만 **입장을 바꿔 안내만 지지한다.** Gap 모드에 들어갈 때 현재 계층의 공백이 0이면 배너에 "이 계층은 공백 없음 · 공백 있는 계층: L1(4) L3(2) L6(4) L7(2)" 링크를 보여 준다. 자동 이동은 A2(위치 동기화) 버그와 섞이면 신입이 더 헷갈린다.

**I4. 첫 방문 시작 카드 — 1회 표시, 닫으면 영구, 계통도 위에 겹치는 작은 카드로 충분하다.**
- 근거: 첫 화면은 L4가 확대된 채 열리고 빈 "상세 정보" 패널만 보인다. 교육 탭은 오른쪽 위 세그먼트라서 나는 투어를 늦게 발견했다(01-first.png).
- 영업·현장과의 관계: 영업은 고객 앞에서 매번 새 기기로 여는 게 아니고, 현장은 딥링크나 검색으로 들어온다. 그래서 **파라미터 없이 `/`로 들어온 첫 방문일 때만** 보이면 방해가 거의 없다. URL에 node, mode 등이 있으면 표시하지 않는다.

**I5. 범례 클릭 필터 + 용어집 연결 — 범위를 줄인다. 필터는 빼고 용어 설명 연결만 P1로 한다.**

- 꼭 필요한 것: 용어집에 택1·참조 타일·공백 후보/확정·패널 구성품을 추가한다(현재 36개에 없음). 범례 용어 옆 ⓘ이나 툴팁으로 설명을 보여 준다. 계통도 "택1" 배지에 마우스를 올려도 설명이 없다는 점도 같이 해결한다.

**I6. 계통도 키보드 로빙 tabindex — 찬성. 단, P0보다 낮게(P1).**
- 마우스로 클릭하고 드래그하는 동작은 바뀌지 않는다. 기존 E2E 테스트와 화살표 키 화면 이동만 영향을 받는다.

**I7. 제품 페이지 자료 바로가기 — 찬성. 순서는 유지하고 바로가기만 추가하면 충분하다.**

**I8. 오프라인 캐시·한글 오류 안내 — 한글 오류 안내는 P1, 서비스워커 캐시는 P2.**
