## 3. 하지 말 것 (2명 이상 명시)

- 발표 보기 전용 콘텐츠 세트 / 보기 모드별로 다른 내용

- 데스크톱에서 범례 기본 접기

**U2 (기존 화면 요소를 바꿈 — 사용자 확인 후)**:
- C1 압축 화면 규칙 + 발표 보기 토글 + 사이드바 계통도 화면 한정 (5/5)
- C2 상세 패널 운영 정보 요약 1줄 + 기본 접힘 (5/5)
- C3 Gap 회색 채움 + 공백 0 계층 안내 링크 + 범례 클릭 = Gap 강조 (5/5)
- C4 첫 방문 시작 카드 (4/5 조건부)
- C5 제품 페이지 자료 바로가기 칩 (4/5)
- C6 비교 화면 링크 복사 버튼 (영업·디자이너)
**보류(P1·P2)**: 계통도 로빙 tabindex, 다크 모드 컬러 로고, 다크 사진 대비, 미니맵 가림, 오프라인 캐시, 비교 정원 확대.
