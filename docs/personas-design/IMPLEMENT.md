## 공통 규칙
- 저장소: /Users/kjmoon/LSE_News (Vite 8 · React 18 · TS strict · HashRouter · zustand · Vitest · Playwright)
- **자기 담당 파일만 수정.** 다른 담당 파일이 필요하면 고치지 말고 최종 보고에 "리더 통합 필요"로 적는다.
- 검증: `export PATH=$HOME/.local/bin:$PATH && npm run typecheck && npx vitest run` 까지만. **빌드·E2E(Playwright)는 돌리지 않는다**(리더가 통합 후 실행, 4173 서버 공유 충돌 방지). E2E 테스트 파일 수정은 해도 됨(자기 기능 관련만).

- 색은 src/styles/tokens.css 토큰 사용. 새 토큰이 필요하면 **B 담당에게만 tokens.css 수정 권한** — 다른 담당은 컴포넌트 CSS 안에서 `var(--x, 대체값)`으로 쓰고 보고.
- 접근성: 아이콘 버튼은 화면낭독기 이름·title, 토글은 aria-pressed, 움직임은 prefers-reduced-motion 존중, 포커스 이동 규칙(DEBATE.md P0-8).
