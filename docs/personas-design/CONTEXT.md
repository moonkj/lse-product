# UX/UI 디자이너 5인 토론 — 전체 화면 구성 고도화 (2026-11-19)

## 사용자 요청
"메뉴도 조잡함. 페르소나 UX/UI 디자이너 5명 추가해서 토론을 통해 전체 화면 구성에 대한 고도화 토론을 진행해줘. 수정하지는 말고 고도화 방안 보여주고 토론 내용은 보여줘"
- 사용자가 '조잡하다'고 짚은 예: 왼쪽 사이드바(계층 바로가기 + 커버리지 범례 + 선 종류 범례 + 공백 표 버튼이 한 열에 쌓여 있음)

## 제품
- LS ELECTRIC 전력계통 제품맵(웹). 단선결선도 위에 L1 초고압~L7 분전반·부하 + 감시·제어 + 신재생·저장 계층, 기기 76종 타일.
- 기기마다 자사 제품 보유 여부(커버리지 6상태: 보유·일부 보유·계열사 보유·패널 구성품·미보유·해당 없음), 제품 사진, 기기 설명, 자료·사양, 비교.
- **교육용 포털이 아님.** 영업·기술 실무자가 제품 위치·공백·자료·사양을 찾는 도구. 교육 탭·학습 포인트·투어·"신입" 문구 제안 금지.
- 배포: https://moonkj.github.io/lse-product/ (참고 사이트 디자인: https://lse-market-news.pages.dev/ — 같은 회사 시장동향 대시보드, 이 제품맵의 CI·톤 기준)
