## 합의안 (P1)
- **패널 순서**: 이름·상태·썸네일 → 고정 버튼 줄(비교 담기 등) → **자사 제품 목록** → 설명(1줄 요약, 펼치기). 스크롤 없이 제품이 보이게.
- **컴포넌트 통일**: Button 3변형(primary·secondary·ghost)×2크기, 배지 11종 → 4종(StatusBadge·Tag·FilterChip·Count), "비교에 담기 ↔ ✓ 담김 2/4(누르면 빼기)", PageHeader + 브레드크럼 1종, 페이지 폭 토큰 1개, 최소 글자 12px, 포커스 링 토큰 1개.
- **밴드 색**: 9색 → L1~L7 흰/연회색 2톤 교차 + 감시·신재생은 옅은 블루 1톤. 밴드 왼쪽 고정 이름표 "L4 수전설비 · 22.9kV · 10/13".
- **제품 사진 유지**: 기본 줌은 실사진(흰 판 56~72px). 60% 미만 개요 줌에서만 점 + 약칭(semantic zoom). D3의 '기본 줌에서 사진 빼기'는 4명 반대로 철회.
- **공백 표 진입**: 탭줄(40px)은 만들지 않음. 헤더 서비스명 옆 텍스트 메뉴 **"계통도 · 공백 표"**(현재 위치 밑줄, nav 링크). 사이드바·시작 카드의 공백 표 버튼 삭제. 공백 표의 행·열을 누르면 계통도 해당 밴드로 복귀.
- **모바일**: 헤더 1줄, [전체|공백만]은 칩 줄 맨 앞, 칩 줄 끝 흐림 표시, 하단 시트 3단(요약/반/전체), 범례는 시트 손잡이 옆 버튼.

## 신규 안건 1 — 계통도 전기 흐름 애니메이션
| 항목 | 합의 |
|---|---|
| 켜기 | **기본 꺼짐.** 도구줄 토글 **[⚡ 흐름]**(aria-pressed, 주소 `?flow=1`로 공유) |
| 범위 | 기기를 고르면 **그 기기로 들어오는(상류)·나가는(하류) 경로만** 흐르고 나머지는 흐림. 기기 없이 토글을 켜면 전체 전력선(발표용) |
| 대상 | 전력선 59개 + 모선. **신호선 23개는 흐르지 않음**, 택1 7개는 그 경로를 골랐을 때만 |
| 방향 | 데이터의 상류→하류. 태양광(PV→DC→PCS)은 역방향, ESS↔PCS는 ⇄ 표지 → **연결선에 흐름 방향 속성 추가(데이터 작업)** |
| 표현 | 원래 실선 위에 2px CI 블루 대시(8/16)가 이동(CSS만, JS 루프 없음). 빛 번짐 없음, 빨강·노랑 없음. 속도 24~48px/s(D3 24 · D2 48) → 시안으로 결정 |
| 꺼짐·대체 | **Gap 보기에서는 끔.** 인쇄·움직임 줄이기 설정은 **정지 화살표 ▸**. 화면 밖·끄는 중·탭 숨김이면 정지. 5초 넘게 움직이므로 정지 수단 필수(WCAG 2.2.2) |
| 소수 의견 | D5: 흐름이 꺼져 있어도 선 위에 정지 화살표를 늘 표시 → 화면 소음 우려(D2)로 보류 |

## 신규 안건 2 — 실시간 전력수급 현황
| 항목 | 합의 |
|---|---|
| 데이터 | 전력거래소 공개 데이터(현재 수요·공급능력·공급예비력·예비율), GitHub Actions 10~30분 주기 수집 → JSON |
| 위치 | **계통도 도구줄 오른쪽 28px 알약** "예비율 12.3% · 정상 · 14:20" (D1·D2) / 소수안: L1 밴드 이름표 옆(D3), 헤더 칩(D4) → 도구줄 안이 다수, 모바일은 칩 줄 끝 |
| 열면 | 팝오버(모바일은 시트): 현재 수요·공급능력·공급예비력(GW)·예비율, 오늘 24시간 수요 스파크라인(공급능력 점선 겹침), 출처·기준 시각·다음 갱신 |
| 단계 표시 | 전력거래소 경보는 **예비력(GW) 기준** → 단계 이름 글자 + 아이콘 + 색. **정상은 회색(무색)**, 준비·관심 황토 → 주의·경계 주황 → 심각 적갈. **CI 레드·커버리지 초록·노랑은 쓰지 않음**(위젯 전용 `--grid-*` 토큰) |
| 지연·실패 | 공개 주기의 2배(약 40분) 넘게 갱신 없으면 회색 + "지연 · 마지막 13:05", 실패하면 마지막 값 유지 + "갱신 실패 ↻". 오래된 값을 최신처럼 보이지 않게 |
| 접근성 | 정기 갱신은 읽어 주지 않음. 단계가 바뀔 때만 한 번 알림 |
| 확인 필요 | 경보 기준값(준비 5.5 / 관심 4.5 / 주의 3.5 / 경계 2.5 / 심각 1.5 GW)은 페르소나 기억값 → 전력거래소 공식 기준으로 확인 후 적용 |
