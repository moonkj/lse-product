# D1 한서진 — 정보구조·내비게이션 (2라운드)

## 1. 동의하는 안
- **D3-B·D2-A 공통: 사이드바 = 계층 목록 전용.** 4명이 같은 방향이라 P0로 확정하자는 입장.
- **D2-C·D3-A: 타일 테두리 회색 1px + 공백만 색.** 단, 미보유 2px 빨강 + 일부 보유 1.5px 노랑까지(D2안). Gap 보기 정의(미보유+일부)와 맞아야 한다.
- **D4-C: 패널 순서 = 머리 → 버튼 줄 → 자사 제품 → 설명 요약.** 제품맵의 핵심 질문("우리 제품 뭐 있나")이 첫 화면에 온다.
- **D5-B·E: 같은 행동은 같은 문구, `PageHeader` 1종 + 브레드크럼 통일.** 내 1라운드 F안과 같다. 07의 "← 돌아가기"도 폐지.
- **D5-I: 넓게 보기는 밀도만 바꾸고 탐색 UI는 그대로.** 데스크톱에서 사이드바가 칩 줄로 바뀌면 같은 사람이 두 가지 메뉴를 배워야 한다.

## 2. 반대·수정 제안
1. **D2-A 범례 기본 접힘 → 반대.** 이전 토론(personas-ux)에서 "데스크톱 범례 기본 접기"를 하지 말 것으로 정했다. 절충: 범례는 캔버스 왼쪽 아래에 두고, **커버리지 6종은 1줄 요약으로 늘 보이게**(✓59 ◐2 ◆2 ⊡3 ✕9 −1), 선 종류만 "선 ▾"로 접는다.
2. **D4-A [⋯] 메뉴 → 수정.** 넣을 것이 2개뿐이라 메뉴로 숨길 이유가 약하고 찾기도 어려워진다(D5 지적). 넓게 보기·다크 모드는 **32px 아이콘 버튼 + 툴팁**(D2-F)으로 하고, 인쇄는 지금처럼 캔버스 도구줄에 둔다.
3. **D3-D 기본 줌에서 실사진 제외 → 반대.** 제품맵에서 제품 사진은 핵심 정보다. D3 본인이 낸 절충안(기본 줌 사진 72px·흰 배경, 축소 개요 단계에서만 심볼)을 받는다.
4. **D4-G 제품을 패널 2단계로 열기 → P2로 미룸.** 기기·제품 페이지는 공유 링크의 기준 페이지다. 패널에는 제품 줄 + [카탈로그 n] 칩까지만 두고, 누르면 지금처럼 페이지로 이동한다. 깊이(계통도 → 기기 → 제품)는 한 축으로 유지한다.

## 3. 핵심 쟁점 입장
- **(a) 범례**: 캔버스 왼쪽 아래 카드. 커버리지 1줄은 늘 펼침, 선 종류만 접기. 미니맵은 D3-H대로 오른쪽 위로 옮겨 서로 겹치지 않게 한다.
- **(b) 테두리**: 회색으로 통일하고 미보유·일부 보유만 색. 선택은 바깥 포커스 링(D3-A)으로 표시해 커버리지와 다른 채널을 쓴다.
- **(c) 헤더**: 로고·서비스명·검색·아이콘 2개만 둔다. **[제품|Gap]은 캔버스 도구줄 맨 왼쪽 "보기: 전체 / 공백만"**으로 옮긴다. 계통도 화면에서만 의미가 있으므로 다른 페이지에서는 자연히 사라지고, D4가 지적한 "07에서 Gap이 켜져 있는 이유" 문제도 함께 해결된다. 모바일만 D4-D대로 칩 줄 맨 앞에 둔다.
- **(d) 빈 패널**: D4-B에 동의한다. 선택 전에는 접고 선택하면 열린다. 조건은 세 가지: 포커스가 패널 제목으로 이동, 움직임 줄이기 설정이면 즉시 전환, 닫으면 포커스가 원래 타일로 복귀. 내 1라운드 H안(빈 패널 요약)은 철회한다.
- **(e) 공백 표 진입**: 40px 보조 탭줄 안은 **철회하고 수정**한다. 세로 공간을 쓰지 않도록 **헤더 서비스명 오른쪽에 텍스트 메뉴 "계통도 · 공백 표"(14px/600, 현재 위치는 밑줄 2px)**를 둔다. 검색창은 1440에서 520px, 1280에서 440px로 줄인다. 비교는 D4-H의 비교 바가 입구를 맡는다. 사이드바와 시작 카드에 있는 공백 표 버튼은 삭제한다.

## 4. 신규 안건
### 전기 흐름 애니메이션
- **기본은 꺼짐, 선택한 기기의 상류→하류 경로에만 켠다.** 76종 전체가 계속 흐르면 공백 강조와 시선을 다툰다. 도구줄에 토글 "흐름 표시"(기본 꺼짐)를 둬서 켜면 전체 전력선이 흐르게 한다(발표용).
- 실선 전력선과 모선에만 적용하고 신호 점선에는 적용하지 않는다. 흐름이 "전력"을 뜻하는 단일 의미여야 한다(D3 원칙).
- 성능: stroke-dashoffset CSS 애니메이션으로 화면에 보이는 선만 그린다. 탭이 숨겨지면 멈춘다.
- 움직임 줄이기 설정이면 정지 화살표(▸)로 대체한다. 인쇄도 정지 화살표로 한다.
- **Gap 보기에서는 강제로 끈다.** 그 화면의 주인공은 공백이다.

### 실시간 전력수급 현황
- **위치: 캔버스 도구줄 오른쪽**(D2가 지우자고 한 "드래그로 이동…" 문구 자리)에 1줄 위젯 "전력수급 예비율 12.3% · 정상 · 14:20". 헤더는 전역 메뉴 자리이고 제품 페이지와 관계가 없으므로 피한다. 별도 화면은 데이터가 4개뿐이라 과하다.
- 누르면 팝오버 카드: 현재 수요 / 공급능력 / 공급예비력(GW) / 예비율. 아래에 "출처: 전력거래소 공개 데이터 · 14:20 기준 · 약 15분마다 갱신"을 표시한다.
- 단계 색: 전력거래소 경보 단계는 **예비력(GW) 기준**(준비 5.5 / 관심 4.5 / 주의 3.5 / 경계 2.5 / 심각 1.5 미만)이므로 단계 이름을 글자로 함께 쓴다. 정상은 중립 회색 글자로 둔다. 관심 이상만 막대 모양 표시 + 주황·빨강을 쓰고, 원형 커버리지 배지와 모양을 달리해 의미가 섞이지 않게 한다.
- 수집이 60분 넘게 끊기면 회색 "지연 · 마지막 13:05"로 표시한다. 오래된 숫자를 현재 값처럼 보여주지 않는다.
- 모바일은 L1 밴드 이름표 옆에 "예비율 12.3%" 텍스트만 둔다.
