# D4 이준호 (인터랙션·모바일) — 2라운드

## 1. 동의하는 안
- **D3-A / D2-C 타일 테두리 1px 회색 + 미보유 예외 + 선택은 바깥 포커스 링**: 선택과 커버리지가 같은 채널을 쓰지 않게 되면, 선택했을 때의 피드백이 비로소 분명해진다.
- **D1-E / D2-G 도구줄 1단 통합, 시작 카드 띠 제거**: 제 1라운드 진단 3과 같습니다.
- **D5-B "비교에 담기 ↔ 비교에서 빼기" + aria-pressed**: 제 H안(담긴 상태 표시)과 그대로 합칩니다. 버튼 문구는 "✓ 담김 2/4"로 하고, 누르면 빼기가 됩니다.
- **D5-A 터치 44px 토큰**과 **D1-G 칩 줄 끝 흐림 + Gap을 첫 칩으로**: 제 D안과 같습니다.
- **D3-H 미니맵 기본 접힘**: 오른쪽 아래를 비교 바와 하단 시트에 내줄 수 있습니다.

## 2. 반대·수정
- **D1-B 보조 탭줄 40px 상시 노출 → 수정**: 모바일에서는 세로 40px이 너무 큽니다. 데스크톱은 헤더 안 검색창 왼쪽에 [공백 표 16]·[비교 2] 링크로, 모바일은 [⋯] 메뉴와 비교 알약으로 대신합니다.
- **D1-H 빈 패널에 계층 요약 → 반대**: 패널을 비워 두는 것보다 계통도 폭이 더 가치 있습니다. 계층 요약은 D3-E 밴드 이름표("L4 10/13")가 이미 캔버스 안에서 보여 줍니다.
- **D5-I 넓게 보기에서 칩 줄 폐지 → 부분 반대**: 높이 600px 이하(가로 폰)에서는 사이드바 200px가 치명적이라 칩 줄이 필요합니다. 절충안: 칩 줄 컴포넌트를 모바일과 압축 화면에서 같은 하나로 쓰면 "익힐 UI는 둘"인 상태가 유지되어 수용 가능한 수준입니다.
- **D3-D 기본 줌에서 실사진 빼기 → 반대**: 영업 담당자는 사진으로 기기를 알아봅니다. D3가 낸 절충안(72px 썸네일 + 흰 배경)을 지지합니다.

## 3. 핵심 쟁점 입장
- **(a) 범례**: 캔버스 왼쪽 아래 "범례 ▾" 칩. 데스크톱은 기본 펼침(이전 토론에서 "데스크톱 범례 기본 접기 금지"로 합의), 모바일은 하단 시트가 접힌 상태일 때 시트 손잡이 옆 [범례] 버튼으로 엽니다. 미니맵은 오른쪽 위로 옮겨 서로 겹치지 않게 합니다.
- **(b) 테두리**: D3-A로 갑니다. 모바일 배지는 18px입니다.
- **(c) 헤더**: [보기 제품|Gap]은 도구줄 맨 왼쪽(D1-C)에 동의하고, 헤더에는 아이콘 2개(넓게 보기·다크 모드, 툴팁 + aria-label)만 둡니다. 제가 냈던 [⋯] 메뉴는 철회합니다. 아이콘 2개면 굳이 숨길 필요가 없습니다.
- **(d) 빈 패널 기본 접기**: 끌어서 폭을 조절하는 기능이 막 들어간 만큼, 그 기능을 살려서 수정합니다. 기기를 고르기 전에는 **24px 레일**(손잡이 + "‹ 상세")만 남기고, 고르면 **사용자가 마지막으로 끌어 둔 폭**으로 열립니다. 닫은 뒤 다시 고를 때도 그 폭을 유지합니다. 레일을 끌어도 패널이 열립니다. 레이아웃이 밀리는 문제는 선택한 타일을 다시 가운데로 맞춰서 보완하고, prefers-reduced-motion이 켜져 있으면 애니메이션 없이 즉시 엽니다.
- **(e) 공백 표 보조 탭**: 탭줄은 만들지 않고 헤더 링크 [공백 표 16] + Gap 보기 안내 줄의 "표로 보기 →"로 두 갈래 진입을 둡니다.

## 4. 신규 안건
**전기 흐름 애니메이션**
- 토글은 도구줄 [보기] 옆 아이콘 토글 [⚡흐름]으로 둡니다. 기본은 꺼짐이고, 켜면 URL `?flow=1`에 저장되어 공유할 수 있습니다.
- 기기를 고르면 계통 전체 대신 **그 기기로 들어오는 경로(상류, 블루)와 나가는 경로(하류, 네이비)만** 흐르고 나머지 선은 흐리게 합니다. 기기를 고르지 않은 상태에서 켜면 모선 위주로 느리게 흐릅니다.
- 성능: SVG stroke-dashoffset을 CSS로 움직이고(JS 루프 없음), 화면에 보이는 선만 움직입니다. 탭이 숨겨지면 멈추고, 모바일은 초당 30프레임에 저전력 모드(Battery API가 지원될 때)에서는 자동으로 멈춥니다.
- 움직임 줄이기 설정이 켜져 있으면 움직이는 대신 **정지 화살표(▶) 표시**로 바꿉니다. 의미는 같고 움직임만 없습니다.

**실시간 전력수급**
- 데스크톱: 헤더 검색창 오른쪽에 작은 칩 「수급 ● 예비율 12.4% · 14:20」을 둡니다. 색은 정상(중립 회색)/주의(노랑)/경보(빨강)이고, 글자로도 상태를 함께 씁니다.
- 모바일: 헤더 공간이 없으므로 칩 줄 맨 끝에 같은 칩을 붙이고, 누르면 하단 시트가 열립니다.
- 칩을 누르면 팝오버(모바일은 시트)가 열리고 현재 수요·공급·예비력, 오늘 24시간 스파크라인, 출처(전력거래소)와 수집 시각, "계통도 L1~L2 보기" 링크를 보여 줍니다. 별도 페이지로 이동하지 않습니다.
- 지연·실패 표시: 40분 이상 갱신되지 않으면 「14:20 기준 · 지연」 회색 점선 칩으로 바꾸고, 실패하면 「수급 정보 없음 ↻」(누르면 재시도)로 표시합니다. 어떤 경우에도 이전 값을 최신값처럼 보이게 하지 않습니다. 상태가 바뀌면 live region으로 한 번만 알립니다.
