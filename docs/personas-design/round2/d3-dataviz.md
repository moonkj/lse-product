# D3 박도윤 — 2라운드

## 1. 동의 / 반대
**동의**
- D2-C·D2-E: 테두리는 회색 1px로 통일하고 미보유만 색을 쓴다. 청록을 없애고 선을 4종으로 줄인다. 내 A·C안과 같다.
- D5-G: Gap 보기에서 opacity 대신 배경·테두리를 낮추고 글자 대비 4.5:1을 유지한다. 내 G안에 그대로 합친다.
- D1-D: 사이드바 숫자를 "10/13 + ●3" 고정 열로 둔다. 모드가 바뀌어도 같은 자리에 같은 인코딩이 오는 것이 시각화 원칙에 맞다.
- D4-B: 빈 상세 패널을 접는다. 캔버스 폭이 곧 정보 밀도다.

**반대·수정**
- D2-A "범례 기본 접힘" → 반대. 6상태는 처음 보는 사람이 해독하는 데 꼭 필요하다. 절충: 첫 방문에는 펼쳐 두고, 접으면 그 상태를 기억한다. 접혀 있어도 한 줄 요약("✓59 ◐2 ◆2 ⊡3 ✕9 –1")은 남긴다.
- D2-D "밴드 2톤 교차" → 수정. 9색 밴드는 줄이는 데 동의하지만, 흰색/회색 교차만으로는 사이드 계층(감시·신재생)과 전압 계층이 구분되지 않는다. 전압 계층 L1~L7은 2톤 교차, 사이드 계층은 옅은 블루 1톤으로 둔다.
- D4-H "담긴 타일에 점 표시" → 수정. 커버리지 배지와 같은 모서리에 두면 안 된다. 타일 아래 2px 블루 밑줄로 위치를 분리한다.
- D5 쟁점 "노드 글자 최소 12px" → 확대율에 연동한다. 화면에 그려지는 크기가 12px 미만이 되는 줌에서는 보조 글자를 숨긴다(semantic zoom 개요 단계).

## 2. 쟁점별 입장
(a) **범례 위치**: 캔버스 왼쪽 아래 도킹(D1-A와 같음). 미니맵은 반대쪽인 오른쪽 위에 둔다. 비교 바·시트는 가운데 아래에 둔다.
(b) **타일 테두리**: 회색 1px로 통일하고, 미보유는 2px 빨강, 일부 보유는 1.5px 황색으로 둔다. 데이터의 78%가 보유이므로 다수에 색을 칠하면 신호가 묻힌다.
(c) **헤더 버튼**: D1-C를 지지한다. [전체|공백만]은 캔버스 도구줄로 옮긴다. 보기 방식은 그림 옆에 있어야 한다. 넓게 보기·다크 모드는 32px 아이콘으로 바꾸고, 인쇄도 도구줄에 둔다.
(d) **빈 상세 패널**: 기본으로 접는다. D1-H의 계층 요약은 패널이 아니라 밴드 이름표("L4 · 10/13 · ✕0")로 대신한다.
(e) **공백 표 보조 탭**: 찬성한다. 다만 공백 표는 계통도와 같은 데이터를 다른 투영으로 보는 화면이므로, 행/열을 누르면 계통도의 해당 밴드로 돌아오는 연결이 함께 있어야 한다.

## 3. 신규 안건 설계

### 3-1. 전기 흐름 애니메이션
- **대상**: power 엣지 59개와 모선만. signal 23개는 정보 흐름이라 흐르지 않게 둔다. alt(택1) 7개는 정지 상태로 두고, 사용자가 택1 경로를 선택했을 때만 흐르게 한다.
- **방향**: 데이터의 from→to(상류→하류)를 따른다. 예외로 PV→DC→PCS는 하류에서 계통 쪽으로 흐르는 역방향이다. ESS↔PCS는 양방향이라 흐름을 표시하지 않고 ⇄ 표지만 붙인다. 이를 위해 엣지에 `flow: forward|reverse|bi` 속성을 추가하자고 제안한다(데이터 작업은 별도로 진행).
- **표현**: 대시가 이동하는 방식(stroke-dasharray 2 10, dashoffset 이동). 광점은 SVG 수백 개의 rAF 비용이 크고, 점선이 신호선과 헷갈릴 수 있다. 대시는 선 색보다 밝은 CI 블루 40% 오버레이로 그려 원래 실선 위에 겹친다. 그래서 정지 상태에서도 "실선=전력"이 유지된다.
- **속도**: 화면 기준 초당 24px로 고정한다. 줌과 무관하게 일정하게 보이도록 dashoffset을 scale로 나눈다. 전압별로 속도를 다르게 하지 않는다(의미가 없는 인코딩이다).
- **범위**: 기본은 꺼 둔다(도구줄 [흐름] 토글). 기기를 선택하면 그 기기의 상류 전원→기기→하류 1단계 경로만 흐르고, 나머지 엣지는 흐리게 한다. 이것이 핵심 용도다.
- **semantic zoom**: 개요(<60%)에서는 계층 간 간선만 굵은 흐름 1줄로 보여 주고, 기본·상세 단계에서는 엣지별로 흐른다.
- **Gap 보기**: 흐름을 끈다. 강조 대상이 공백이므로 움직임과 경쟁하면 안 된다.
- **인쇄**: 애니메이션은 없애고 방향 화살표(▸)를 엣지 중간에 정적으로 찍는다.
- **reduced-motion**: 애니메이션 대신 정적 화살표로 대체하고 토글은 숨긴다.
- **성능**: CSS 애니메이션 1개 클래스를 공유해 GPU 합성만 쓴다(엣지 89개는 문제가 없다). 뷰포트 밖 엣지는 `animation-play-state: paused`로 멈추고, 패닝 중에도 멈춘다. 탭이 보이지 않으면 정지한다.

### 3-2. 실시간 전력수급 현황
- **형태**: 숫자와 스파크라인을 함께 쓴다. 게이지는 면적만 크고 비교가 어렵다. 큰 숫자는 "예비율 14.2%" 하나만 두고, 아래에 현재 수요·공급능력·예비력(GW)을 작은 숫자 3개로 둔다. 오늘 0시부터 지금까지의 수요 스파크라인(120×28px)에 공급능력 선을 점선으로 겹친다.
- **상태색**: 예비력 단계(전력거래소 기준: 정상 / 준비 5.5GW 미만 / 관심 4.5 / 주의 3.5 / 경계 2.5 / 심각 1.5)를 따른다. 정상은 색을 쓰지 않고, 준비 이상만 황색에서 빨강으로 칠한다. 공백 색과 같은 원칙이다.
- **위치**: L1 밴드 이름표 오른쪽에 붙인다. 이름표는 "L1 초고압 765/345kV │ 전국 수급 예비율 14.2% ▁▂▃▅▆". 전국 수급은 송전 계통 차원의 지표라 L1에 의미가 맞는다. 다른 밴드에는 붙이지 않는다. 계통도의 주제(제품 커버리지)를 흐리지 않도록 캔버스 하나에 위젯은 하나만 둔다. 밴드를 누르면 작은 팝오버로 24시간 차트를 보여 준다.
- **갱신·지연**: 숫자 옆에 "14:25 기준 · 5분 전"을 항상 표기한다. 공개 주기(10~30분)의 2배를 넘기면 숫자를 회색으로 바꾸고 "지연" 태그를 붙인다. 실패하면 마지막 값과 시각을 유지하고 "갱신 실패"를 표시한다. 출처는 "전력거래소"로 적는다. 인쇄할 때는 기준 시각을 함께 출력한다.
- **모바일**: 계층 칩 줄 맨 끝에 "예비율 14.2%" 칩 하나만 둔다.
