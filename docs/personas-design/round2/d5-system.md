# D5 정하린 (디자인 시스템·접근성) — 2라운드

## 1. 동의 / 반대·수정

**동의**
- **D3-A·D2-C** 타일 테두리 1px 회색 통일, 선택은 바깥 링으로 표시: 선택 상태와 커버리지가 같은 테두리를 쓰던 충돌이 없어집니다. 내 H안(`--focus-ring`)과 같은 토큰을 씁니다.
- **D3-C** 점선은 신호선에만 씀: 색 없이 선 모양만으로 구분됩니다(1.4.1).
- **D1-F** 브레드크럼 통일, 계층 단계도 링크로: 내 E안(`PageHeader`)의 첫 줄이 됩니다.
- **D4-C** 패널 순서를 제품 먼저로 바꿈: 머리·버튼 줄을 고정하면 키보드 탭 순서도 짧아집니다.
- **D2-B** 범례 아이콘 크기 통일과 짧은 라벨: 단, 아래 수정 조건을 붙입니다.

**반대·수정**
- **D2-B 원형 통일** → 원 안의 글리프(✓◐◆▣✕–)는 반드시 유지하고 14px→16px로 키웁니다. 테두리 모양까지 같으면 흑백 인쇄(D3-I)에서 글리프 말고는 구분할 단서가 없습니다.
- **D2-A 범례 기본 접힘** → 반대합니다(이유는 2-a).
- **D4-A [⋯] 메뉴** → 넓게 보기·다크 모드는 메뉴에 숨기지 말고 아이콘 버튼으로 노출합니다(2-c). 인쇄만 메뉴로 보내는 데는 동의합니다.
- **D4-B 패널 이동 180ms** → 수용합니다. 다만 `prefers-reduced-motion`이면 0ms로 하고, 패널이 열리면 포커스를 패널 제목으로, 닫히면 원래 타일로 되돌립니다.

## 2. 핵심 쟁점 입장
- **(a) 범례**: 위치는 D1·D3의 캔버스 왼쪽 아래 도킹 카드에 찬성합니다. 다만 **데스크톱은 기본 펼침**이어야 합니다. 이전 토론에서 '데스크톱 범례 기본 접기 금지'로 결정했기 때문입니다. 접은 상태는 사용자가 직접 접었을 때만 기억합니다. 범례 항목은 'Gap 강조' 동작을 하므로(이전 결정 C3) `<button aria-pressed>`로 만듭니다. 모바일과 압축 화면만 기본 접힘입니다.
- **(b) 테두리 회색 + 미보유만 색**: 빨강에만 기대면 적색맹 사용자에게 회색과 비슷하게 보입니다. 미보유는 **2px 빨강 + 테두리 모양 변화(파선이나 모서리 노치) + ✕ 배지**로 세 번 표시합니다. 일부 보유는 ◐ 배지만 둡니다. 배지와 테두리가 맞닿는 곳은 비텍스트 대비 3:1을 확인합니다.
- **(c) 헤더 아이콘화**: 32px 아이콘 버튼은 터치 기준에 못 미치므로 터치 영역은 44px로 늘립니다. `aria-label`은 상태를 반영한 이름("다크 모드 켜기"/"끄기")으로, 토글이면 `aria-pressed`를 씁니다. 툴팁은 hover와 focus 모두에서 뜨고 Esc로 닫혀야 합니다(1.4.13). 툴팁에 단축키도 함께 적습니다.
- **(d) 빈 패널 접기**: 찬성합니다. 접힌 자리에 "상세 열기" 손잡이 버튼을 남기고, 끌어서 폭을 조절하는 동작에는 키보드 ←→ 대안을 둡니다(2.5.7).
- **(e) 공백 표 보조 탭**: 찬성하되 탭 이름은 'Tab'이 아니라 **내비게이션 링크**(`nav` + `aria-current="page"`)로 만듭니다. "공백 표 16"의 숫자는 "공백 16종"처럼 텍스트로 읽히게 합니다. 이렇게 하면 사이드바 버튼과 시작 카드 칩을 지워도 진입 경로가 남습니다.

## 3. 새 안건

### 전기 흐름 애니메이션
- 기본은 **정지 상태**에서 흐름 방향을 **선 위 화살표(▸, 48px 간격)**로 표시합니다. 움직이지 않아도 방향을 알 수 있으므로 애니메이션은 덧붙이는 효과입니다.
- 재생은 도구줄의 `[▶ 흐름]` 토글(`aria-pressed`)로 켭니다. 5초 넘게 움직이는 표현이므로 **일시정지 수단이 필수**입니다(2.2.2). `prefers-reduced-motion: reduce`이면 버튼은 보이되 기본 꺼짐으로 둡니다(2.3.3).
- 속도는 초당 3회 미만 깜빡임, 대비 변화는 작게 합니다. 인쇄와 화면 캡처에서는 애니메이션을 끕니다. 토큰 `--motion-flow-duration`, `--color-flow`를 새로 둡니다.

### 실시간 전력수급 현황
- **`KpiCard` 1종에 변형 3가지**: `metric`(현재 수요·공급능력), `status`(예비율 + 단계), `trend`(스파크라인). 각 카드는 값 → 단위 → 비교값 순서입니다.
- 예비율 단계(정상·준비·관심·주의·경계·심각)는 **단계 이름 텍스트 + 아이콘 + 색**으로 표시하고, 색 토큰은 `--grid-level-*`로 커버리지 색과 분리합니다.
- **갱신 때 live region을 쓰지 않습니다.** 10~30분마다 읽어 주면 소음이 됩니다. 단계가 바뀔 때만 `role="status"`로 한 번 알립니다. 그 밖의 갱신은 카드 아래 "갱신 14:30" 텍스트로만 보여 줍니다.
- 카드 아래에는 항상 **"출처: 전력거래소 공개 데이터 · 기준 14:25 · 다음 갱신 약 14:55"**를 표기합니다. 갱신에 실패하면 값을 회색으로 바꾸고 "지연" Tag를 붙입니다(색만으로 표시하지 않음).
