# D2 오유나 — 색 재검토 (흐름·선택·밴드)

**진단**: 블루 4px 선 안의 흰 대시 2.5px는 멀리서 보면 '파란 점선'으로 읽힙니다. 움직임은 밝기 대비가 커야 눈에 띄는데 지금은 대비가 작습니다. 선택선(블루 3px)과도 색이 같습니다.

## ① 흐름 — 연한 트랙 위에서 진한 펄스가 움직이게 (스플래시의 '전류' 문법)
| | 라이트 | 다크 |
|---|---|---|
| `.dflow__track` stroke / 굵기 | `#B9D6F0` / 6px | `#1E3A5F` / 6px |
| `.dflow__path` stroke / 굵기 | `#0068B7` / 4px | `#8CC4F0`(스플래시 선색) / 4px |
| 대시 / 간격 | 16 / 20 | 16 / 20 |
| 빛 번짐(허용) | `filter: drop-shadow(0 0 3px rgb(0 104 183 / .55))` | `drop-shadow(0 0 4px rgb(140 196 240 / .7))` |
| 속도 | 초당 56px (주기 36px ÷ 56 ≈ 0.64s) | 같음 |
- 빛 번짐은 흐름 경로에만 씁니다. 모션 감소 설정과 인쇄에서는 `filter: none`입니다.

## ② 선택 강조선과 흐름 구분 — "정지 = 네이비, 움직임 = 블루"
- `.dedge.is-selected`: `stroke: var(--color-brand)` (#00337F), 2.5px 실선. 다크는 `#B0CCFA`.
- 흐름이 켜지면 같은 경로의 선택선은 숨깁니다: `.diagram__inner:has(.dflow__track) .dedge.is-selected { stroke-opacity: 0 }`. 트랙이 그 역할을 대신합니다.

## ④ 활성 영역 — 블루를 섞지 않고 밴드 고유색을 지킴
- `.dband.is-active`: `background: var(--band-bg)` (100%), `box-shadow: inset 4px 0 0 #0068B7, inset 0 0 0 1.5px rgb(0 104 183 / .35)`. 라벨은 700, `#00337F`(다크 `#B0CCFA`).
- 나머지 밴드: 덮개 62%를 **40%**로 낮춥니다. `background: color-mix(in srgb, var(--band-bg) 60%, var(--color-surface) 40%)`. 다크는 `var(--color-bg)`와 섞습니다. 흐려져도 색조는 남습니다.
