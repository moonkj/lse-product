P1

상세 패널 순서: 제품 먼저

이름·상태·썸네일 → 고정 버튼 줄(비교 담기 등) → 자사 제품 목록 → 설명 1줄 요약(펼치기). 스크롤 없이 제품이 보이게 합니다.

P1

컴포넌트 통일

  • 버튼 3변형(주·보조·텍스트) × 2크기, 배지 11종 → 4종(상태 배지·태그·필터 칩·숫자)
  • "비교에 담기" ↔ "✓ 담김 2/4"(누르면 빼기)로 한 모양
  • 페이지 머리 + 브레드크럼 1종, 페이지 폭 1개, 최소 글자 12px, 포커스 링 1종
P1

계층 밴드 색 9색 → 3톤

L1~L7은 흰색·연회색 교차, 감시·신재생은 옅은 블루 한 톤. 밴드 왼쪽에 고정 이름표 "L4 수전설비 · 22.9kV · 10/13".

P1

제품 사진은 유지

기본 확대에서는 실사진(흰 판 56~72px). 60% 미만으로 축소했을 때만 점 + 약칭으로 바뀝니다. D3의 "기본 줌에서 사진 빼기"는 4명이 반대해 철회했습니다.

P1

공백 표 진입은 헤더 텍스트 메뉴

40px 탭 줄은 만들지 않고 서비스명 옆에 "계통도 · 공백 표"(현재 위치 밑줄). 사이드바·시작 띠의 공백 표 버튼은 삭제. 공백 표의 행·열을 누르면 계통도의 그 계층으로 돌아옵니다.

P1

모바일

헤더 1줄, [전체|공백만]은 칩 줄 맨 앞, 칩 줄 끝 흐림 표시, 하단 시트 3단(요약·반·전체), 범례는 시트 손잡이 옆 버튼.

P2

나중에

검색 결과 묶음("기기 1 · 제품 6"), 제품을 패널 안에서 열기(공유 링크 문제로 보류), 비교 바를 가운데 알약으로, 인쇄본 하단 범례·흑백 구분.

새 안건 1 — 계통도 전기 흐름 애니메이션

항목합의
켜기기본 꺼짐. 도구줄 [⚡흐름] 토글, 켠 상태는 주소(?flow=1)로 공유
범위기기를 고르면 그 기기로 들어오는 경로(상류)와 나가는 경로(하류)만 흐르고 나머지 선은 흐림. 기기 없이 켜면 전체 전력선(발표용)
대상전력선 59개 + 모선. 신호선 23개는 흐르지 않음. 택1 7개는 그 경로를 골랐을 때만
방향상류 → 하류. 태양광(PV→DC→PCS)은 반대 방향, ESS↔PCS는 ⇄ 표시. 연결선마다 흐름 방향 값을 넣는 데이터 작업이 필요
모양원래 실선 위에 2px CI 블루 대시가 이동(CSS만 사용). 빛 번짐·빨강·노랑 없음. 속도는 초당 24px(D3)~48px(D2) 사이에서 시안으로 결정
꺼지는 때공백만 보기에서는 끔. 인쇄·움직임 줄이기 설정은 멈춘 화살표 ▸로 대신. 화면 밖·끄는 중·탭 숨김이면 정지
소수 의견D5: 흐름을 꺼도 선 위에 멈춘 화살표를 늘 표시 → D2가 화면이 다시 복잡해진다고 반대해 보류

새 안건 2 — 실시간 전력수급 현황

항목합의
데이터전력거래소 공개 데이터(현재 수요·공급능력·공급예비력·예비율)를 GitHub Actions가 10~30분마다 받아 JSON으로 배포
위치계통도 도구줄 오른쪽 알약 "예비율 12.3% · 정상 · 14:20"(D1·D2). 소수안: L1 밴드 이름표 옆(D3), 헤더 칩(D4). 모바일은 칩 줄 끝
누르면작은 카드(모바일은 시트): 현재 수요·공급능력·공급예비력(GW)·예비율, 오늘 24시간 수요 그래프(공급능력 점선), 출처·기준 시각·다음 갱신
단계 색정상 · 회색준비·관심주의·경계심각
단계 이름을 늘 글자로 함께 씀. CI 레드와 커버리지 초록·노랑은 쓰지 않고 이 위젯 전용 색만 사용
늦을 때약 40분 넘게 갱신이 없으면 회색 + "지연 · 마지막 13:05". 실패하면 마지막 값 유지 + "갱신 실패 ↻". 오래된 값을 최신처럼 보이지 않게
화면낭독기정기 갱신은 읽지 않고, 단계가 바뀔 때만 한 번 알림
확인 필요경보 기준(준비 5.5 · 관심 4.5 · 주의 3.5 · 경계 2.5 · 심각 1.5 GW)은 페르소나 기억값이라 전력거래소 공식 기준으로 확인 후 적용

토론 기록

1라운드 — 각자 진단과 제안

D1 한서진 정보구조·메뉴

사이드바가 이동·범례·바로가기를 한꺼번에 떠안아 역할이 섞였다고 진단. 사이드바는 계층 이동만, 범례는 캔버스 왼쪽 아래 카드(기본 펼침)로. 헤더 아래 40px 보조 탭 [계통도][공백 표][비교]를 두고, [제품|Gap]은 도구줄 "보기: 전체/공백만"으로 내리자고 제안. 하위 페이지의 돌아가기 방식 3가지를 브레드크럼 하나로 통일.

D2 오유나 비주얼·CI

색이 너무 많은 곳에 쓰인다고 진단(커버리지 6색 테두리, 9색 밴드, 청록 택1선). 테두리는 회색, 밴드는 2톤, 선은 4종으로. 범례는 사이드바 아래에서 "범례 ▾"로 기본 접힘, 아이콘은 14px 원으로 통일. 상세 페이지의 카드 속 카드 3겹을 한 겹으로, 배지는 마켓뉴스 규칙(높이 20px·모서리 4px)으로.

D3 박도윤 계통도 시각화

커버리지를 테두리와 배지로 두 번 표시하고 선택도 테두리를 써서 신호가 묻힌다고 진단. 테두리 회색·미보유만 빨강·선택은 바깥 링. 점선은 신호선만. 줌 3단계(60% 미만 점+약칭, 기본 심볼·이름·배지, 120% 초과 실사진·정격)로 정보 밀도를 나누고, 기본 줌에서는 사진 대신 심볼을 쓰자고 제안.

D4 이준호 인터랙션·모바일

헤더 버튼 3개를 [보기] 세그먼트 + [⋯] 메뉴로 줄이고, 빈 상세 패널은 접었다가 기기를 고르면 400px로 열자고 제안. 패널은 제품 목록을 위로. 모바일은 헤더 1줄, 하단 시트 3단. 검색 결과를 "기기 1 · 제품 6"으로 묶고 비교 담기에 "✓ 담김 2/4"와 실행 취소 표시.

D5 정하린 디자인 시스템·접근성

같은 기능이 여러 모양이라고 진단("계통도에서 보기"가 버튼 2종·링크 1종, "비교에 담기"가 3모양). 버튼 1종 3변형, 칩·배지 11종 → 4종. 색만으로 구분하는 곳(Gap 흐림, 공백 숫자)을 고치고 포커스 링을 하나로. 9·11px 글자 폐지, 최소 12px.

2라운드 — 반박과 절충

D1 한서진

D2의 범례 기본 접힘에 반대(이전 토론에서 "데스크톱 범례 기본 접기 금지"로 정함). 커버리지 1줄은 늘 보이고 선 종류만 접는 절충안을 냄. D3의 사진 빼기에 반대. 자기 안 수정: 40px 보조 탭 철회 → 헤더 서비스명 옆 텍스트 메뉴 "계통도 · 공백 표"

D2 오유나

D3의 사진 빼기에 반대(카탈로그 실사진이 이 도구의 정체성). 흐름 애니메이션은 마켓뉴스 스플래시의 '전류' 연출을 이어받되 밝은 화면에 맞게 CI 블루로. 수급 위젯에 CI 레드 금지. 자기 안 수정: 범례 사이드바 접힘 철회 → 캔버스 왼쪽 아래 28px 한 줄 띠

D3 박도윤

D2의 밴드 2톤 교차를 수정 제안(감시·신재생은 옅은 블루로 구분해야 전압 계층과 섞이지 않음). D4의 비교 담김 점은 배지와 겹치니 타일 밑줄로. 흐름 애니메이션 상세 설계: 전력선 59·모선만, 신호선 23 제외, 태양광 역방향. 데이터에 흐름 방향 값 추가 필요. 자기 안 수정: 기본 줌 사진 72px 절충 수용

D4 이준호
