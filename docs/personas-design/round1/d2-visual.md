# D2 오유나 (비주얼·CI 시스템) — 1라운드: 시각 완성도 고도화

> 한 줄 결론: 색은 "공백"에만 쓰고, 선·테두리·배지는 절반으로 줄인다. 마켓뉴스처럼 **흰 면 + 회색 선 1겹 + 네이비/블루 2색**으로 돌아가면 '조잡함'의 70%가 사라진다.

## 1. 현재 문제 진단
1. **사이드바에 성격이 다른 블록 4개가 같은 무게로 쌓임** (01, 11) — 계층 목록 → 커버리지 6줄 → 공백 후보/확정 → 선 종류 5줄 → 공백 표 버튼. 구분선·제목 크기 차이가 없어 하나의 긴 목록처럼 읽힌다. 1280(11)에선 선 범례가 잘려 스크롤.
2. **범례 아이콘 모양·크기 불일치** (01) — 원(✓, ◐, ✕)·마름모(계열사, 다른 것보다 큼)·사각(패널, 해당 없음)이 섞여 세로 정렬선이 흔들린다. "패널 구성품(타사 조달)", "참조 타일(같은 기기 재등장)"이 200px 폭에서 2줄로 깨짐.
3. **타일 이중 부호화로 색 과다** (01, 02) — 테두리 2px 초록/보라 + 모서리 배지 + 9가지 계층 밴드 색. 화면의 대부분 타일이 초록이라 정작 공백(빨강)이 묻힌다. 03 Gap 모드에서 보유 타일을 흐리게 하는 것이 오히려 "정상 화면"처럼 보인다.
4. **선 종류 5 + 선택 1 = 6가지 선, 색조 3개** (01, 02) — 전력(검정 실선)·신호(회색 점선)·모선(굵은 검정)·택1(청록 점선)·참조(점선 상자)·선택(블루 점선). 청록 #0f766e는 CI에 없는 7번째 색.
5. **헤더 우측 버튼 3개가 모드 전환과 같은 무게** (01) — 제품/Gap(핵심 모드)과 넓게 보기·다크 모드(보조 설정)가 모두 흰 외곽선 40px. 마켓뉴스는 보조 버튼을 28px·12px로 낮춘다.
6. **계통도 위 크롬 2줄(약 105px)** (01) — "처음이세요?" 띠 + 확대 툴바. 상태 문구(오른쪽 "드래그로 이동…")는 13px 회색으로 아무도 안 읽는다. 모바일(09)은 헤더 2줄+칩+띠+툴바로 화면의 약 33%.
7. **상세 페이지 카드 속 카드 3겹** (04, 05) — 바깥 패널(상단 네이비 4px) → 사진 테두리 상자 → 회색 설명 상자 → 제품 카드 → 카드 안 [+] 테두리 버튼. 배지도 회색 태그·초록 pill·노란 "검수 전"·블루 링크칩 4종.
8. **공백 표는 모든 칸이 색 배지** (07) — 보유 ✓ 초록 칩이 40여 개 깔리고 KPI 5개가 5색 배경. 읽어야 할 것은 ✕ 9개뿐.

## 4. 다른 디자이너와 부딪힐 쟁점
1. **데이터시각화(D3)**: "타일 테두리 색이 커버리지를 한눈에 보여주는 핵심"이라 반대할 것. 내 입장: 보유가 78%인 데이터에서 다수 색을 칠하면 신호 대 잡음이 뒤집힌다 — 소수(공백)만 칠한다.
2. **디자인시스템·접근성(D5)**: 범례 접힘은 "색 의미를 숨긴다", 아이콘 원형 통일은 "모양 구분이 줄어 색각 이상에 불리"하다고 볼 것. 대안: 원 안 글리프(✓◐◆▣✕–)는 유지해 모양 대신 글리프로 구분.
3. **IA·내비(D1) / 인터랙션(D4)**: 범례를 사이드바에서 빼 계통도 위 플로팅으로 보내자는 안과 충돌 가능. 나는 위치보다 "기본 접힘 + 1겹 구획"이 우선이라 본다. 모바일 크롬 33%는 D4와 공동 과제.
