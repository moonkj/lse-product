# D4 이준호 (인터랙션·모바일 UX) — 1라운드

관점: 영업 담당자가 고객 앞에서 태블릿이나 폰으로 "이 위치에 우리 제품 뭐 있어요?"에 3초 안에 답할 수 있는가.

## 1. 현재 문제 진단
1. **아무것도 안 고른 상태에서 빈 패널이 폭 25%를 차지함**: 01은 360px에 두 줄뿐이고, 11(1280)에서는 계통도가 약 720px로 줄어든다.
2. **헤더 버튼 성격이 섞여 있음**: 보기 전환(제품/Gap), 레이아웃(넓게 보기), 환경설정(다크 모드)이 같은 무게로 나란히 있다. 04~07 페이지에서도 제품/Gap이 그대로 보이는데, 07 공백 표에서 "Gap"이 켜져 있는 이유가 불분명하다.
3. **계통도 위에 막대가 두 줄 쌓임**: 01에서 시작 카드 줄과 확대 도구 줄이 약 110px를 쓴다. 시작 카드의 "검색창에 모델명…" 안내는 검색창 placeholder와 겹친다.
4. **패널에서 제품이 화면 아래로 밀림**: 02 순서가 사진(225px)→설명→역할·원리·포인트로 이어져, 정작 "자사 제품 7개" 목록은 스크롤해야 나온다.
5. **같은 설명이 세 단계에서 반복됨**: 02 패널, 04 기기 페이지, 05 제품 페이지의 설명 4줄이 같다. 제품으로 들어가면 페이지 전체가 바뀌어 계통도 맥락이 사라진다.
6. **검색 결과가 평평한 목록임**: 08은 기기 1개 뒤에 제품 6개가 섞여 있고 묶음 표시도 개수도 없다. 같은 VCB가 영문 사이트와 국문으로 중복 노출된다.
7. **모바일에서 계통도 영역이 좁음**: 09에서 헤더 2줄+칩+배너+확대 도구가 약 280px(33%)를 쓴다. 칩 줄은 L6에서 잘리는데 넘김 표시가 없고, 터치 기기에 ± 버튼은 거의 쓰이지 않는다.
8. **비교 담기 피드백이 약함**: 04 제품 카드의 "+"가 무엇을 하는 버튼인지 알 수 없고, 담은 뒤 상태(몇 개를 담았는지, 지도 어디에 있는지)도 보이지 않는다.

## 2. 개선안
| # | 현재 → 제안 | 효과 | 우선 |
|---|---|---|---|
| A | 헤더 오른쪽 버튼 3개 → **[보기: 제품·Gap] 세그먼트 + [⋯] 메뉴(넓게 보기·다크 모드·인쇄)**. 세그먼트는 계통도 화면에서만 보이고, 다른 페이지에서는 그 자리에 "계통도로" 버튼을 둔다 | 버튼 수 3→2, 지금 어떤 보기인지 분명해짐 | P0 |
| B | 빈 상세 패널 고정 → **기기를 고르기 전에는 패널을 0으로 접고, 고르면 400px로 밀어 열기(180ms)**. 선택한 타일은 남은 영역 가운데로 이동 | 1280에서 계통도 +360px | P0 |
| C | 패널 순서 → **머리(계층·이름·상태 배지·64px 썸네일) → 고정 버튼 줄 [비교 담기][페이지 열기↗][×] → 자사 제품 목록(3개 노출 + "7개 모두") → 설명 1줄 요약(펼치기)** | 스크롤 없이 바로 제품이 보임 | P0 |
| D | 모바일 → **헤더 1줄(로고 + 검색 아이콘 → 전체 화면 검색)**, 칩 줄 맨 앞에 제품/Gap 토글, 칩 줄 끝 흐림 처리. ± 버튼 대신 핀치 + 오른쪽 아래 "전체" 버튼. 시작 배너 줄은 없앰 | 계통도 영역 +180px | P0 |
| E | 하단 시트 접힘/펼침 2단 → **3단 스냅: 요약 120px / 반(제품 목록) / 전체**. 손잡이를 끌거나 탭해서 바꾸고, 반 단계에서도 지도를 끌 수 있음 | 지도와 제품을 함께 볼 수 있음 | P1 |
| F | 검색 → **"기기 1 · 제품 6"으로 묶고, 제품 줄마다 소속 기기 칩을 표시. 영문·국문 중복은 하나로 합침.** Enter를 누르면 지도 이동 + 패널 열기(페이지는 이동하지 않음). 입력 전에는 최근 검색 5개, 단축키 "/" | 검색에서 위치 확인까지 한 번에 | P1 |
| G | 제품을 누르면 페이지 이동 → **패널 안에서 2단계로 밀어 넣기(← 기기로)**: 제품 요약 + [사양][카탈로그 n][매뉴얼 n] 칩 + "전체 페이지↗". 04·05는 공유·인쇄용으로 남김 | 계통도 맥락 유지, 설명 중복 제거 | P1 |
| H | 비교 → **버튼이 "✓ 담김 2/4"로 바뀜 + 실행취소 토스트(4초)**, 지도에서 담긴 타일에 작은 점 표시. 비교 바는 가운데 알약 모양 "비교 2 · [비교하기]"로, 모바일에서는 시트 바로 위에 붙임. 04의 "+"에는 "비교" 글자를 붙임 | 담은 상태가 계속 보임 | P1 |
| I | 패널 폭 끌기 → **좁게 320 / 기본 400 / 넓게 560 세 단계로 맞춰지고 더블클릭하면 기본값.** 고른 폭은 기억 | 원하는 폭을 한 번에 맞춤 | P2 |
| J | Gap 진입 → **확인 토스트 "공백 11종 강조"**를 띄우고 상단 배너를 칩 크기로 줄임 | 상태가 바뀐 것을 알 수 있음 | P2 |

## 4. 다른 디자이너와 부딪힐 쟁점
1. **IA·내비**: 제품을 패널 2단계(G)로 열면 기기·제품 페이지의 역할이 줄어든다. 페이지를 정본으로 보는 쪽은 "깊이는 하나의 축으로만" 원칙을 들어 반대할 것이다. 제품/Gap을 칩 줄로 옮기는 안(D)도 보기 모드와 계층을 섞는다는 반론이 예상된다.
2. **디자인시스템·접근성**: [⋯] 메뉴와 아이콘 전용 버튼은 발견성을 떨어뜨린다. 패널이 열리고 닫히면서 레이아웃이 밀리는 것(B)은 포커스 이동과 모션 감소 설정 대응이 필요하다. 끌기 동작에는 반드시 버튼 대안을 둔다.
3. **데이터시각화·비주얼**: 빈 패널을 접으면 범례·요약을 둘 자리를 원하는 쪽과 충돌한다. 담긴 타일의 점 표시(H)가 커버리지 배지 체계에 끼어들고, 미니맵·비교 바·시트가 오른쪽 아래에서 겹치는 문제는 함께 정해야 한다.
