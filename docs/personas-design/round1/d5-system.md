# D5 정하린 (디자인 시스템·접근성) — 1라운드

## 1. 현재 문제 진단
1. **같은 기능인데 모양·문구가 셋**: "계통도에서 보기"(04, 네이비 채움) / "계통도에서 위치 보기"(05, 네이비 채움) / "계통도에서 보기"(07 목록, 밑줄 링크). "비교에 담기"도 패널 작은 외곽선(02), 페이지 큰 외곽선(04·05), 카드 "+" 정사각(04) 세 가지.
2. **알약 모양이 너무 많음**: CSS 클래스 기준으로 칩·배지 계열이 `cov-badge/pill/chip/icon`, `dp-chip`, `dp-gapchip`, `pg-chip`, `pg-badge`, `cmp-badge`, `ps-badge`, `doc-type-badge`까지 **11종**. 04 머리의 회색 알약 "L4·22.9kV / 개폐 / VCB"는 메타 정보, 05의 파란 알약 "카탈로그 3"은 이동 링크인데 생김새가 거의 같음.
3. **의미가 부딪히는 아이콘**: 05 "✓ 판매 중"이 커버리지 "보유"와 같은 초록 원 체크. 06 비교표 "✓ 보유"는 원 없는 체크라 패널(02)과 모양이 다름. 범례의 계열사 ◆가 다른 아이콘보다 커서(01) 한 줄 높이가 흔들림.
4. **페이지 머리말이 제각각**: 04·05는 브레드크럼 + 카드 히어로(폭 1200), 06은 브레드크럼 + 맨 제목(폭 1280), 07은 "← 계통도로 돌아가기" 링크 + 제목 + KPI 타일. 왼쪽 시작점이 144px/104px로 다름.
5. **토큰 밖 값이 많음**: 직접 쓴 font-size 13px 29곳·11px 9곳·**9px 1곳**(DiagramCanvas.css:653), 토큰 밖 radius 12가지, 컨트롤 높이 6가지(28~44px).
6. **색에 기대는 상태 표시**: Gap 모드(03)는 보유 타일을 옅게 처리해 글자 대비가 3:1 아래로 떨어지는 것으로 보임. 왼쪽 숫자는 빨강/검정 색만으로 "공백 있음/없음"을 구분함. 커버리지 막대(01)는 색만 쓰고 텍스트 대체가 없음.
7. **포커스 처리가 들쭉날쭉**: outline 2px 9곳, 3px 1곳, `outline: none` 7곳(계통도 viewport, app-main, panel-resizer 등). 계통도 viewport는 포커스를 받아도 링이 보이지 않음.
8. **넓게 보기가 다른 화면이 됨**: compact 상태는 헤더를 줄이고 사이드바를 계층 칩 줄(모바일 09와 같은 형태)로 바꿈. 데스크톱 기본 모드와 컴포넌트가 달라서 사용자가 두 가지 탐색 UI를 익혀야 함.

## 4. 다른 디자이너와 부딪힐 쟁점
- **IA·내비**: 넓게 보기에서 계층 칩 줄을 유지할지(모바일과 같은 형태) vs 사이드바를 접기만 할지(I안). 내 입장은 "모드가 달라도 컴포넌트는 같게"이고, 이 부분은 협의가 필요함.
- **비주얼·CI**: 커버리지 6색과 CI 블루(#0068B7)·계열사 파랑(#2f6fd6)이 서로 가까움. 선택·링크 블루와 계열사 상태를 모양(◆)만으로 구분해도 되는지, 계열사 색을 청록 쪽으로 옮길지.
- **데이터시각화**: 계통도 노드 안의 11px 이하 보조 글자(1:1 축척 기준)를 12px로 올리면 타일 크기가 커지고, 76종이 한 화면에 들어가는 밀도와 충돌함. 확대율 연동 최소 크기 규칙이 필요함.
