# D1 한서진 — 정보구조·내비게이션 (1라운드)

> 관점: "메뉴가 조잡하다"는 대개 **성격이 다른 정보(이동·범례·설정·행동)가 한 열에 섞여 있다**는 뜻이다. 장식보다 먼저 분류를 바로잡는다.

## 1. 현재 문제 진단

1. **사이드바 한 열에 4종 정보가 섞임** — 이동(계층 9개) + 상태 범례(6상태) + 테두리 범례(공백 후보/확정) + 선 종류 범례 5개 + 페이지 이동 버튼(공백 표 보기). 1440 높이를 꽉 채우고(01), 1280×720에선 선 범례가 잘려 스크롤해야 한다(11).
2. **전역 메뉴가 없음** — 계통도·공백 표·비교·검색이 같은 급의 화면인데, 공백 표로 가는 길은 사이드바 맨 아래 버튼과 시작 카드 칩뿐이고 비교는 비교 바로만 들어간다. 헤더의 [제품|Gap]은 '보기 방식'인데 메뉴처럼 보인다(01, 07).
3. **헤더 오른쪽 버튼 위계가 같음** — [제품|Gap] 토글, [넓게 보기], [다크 모드]가 같은 크기·같은 외곽선이라, 화면 전환(Gap)과 개인 설정(다크)이 구분되지 않는다(01).
4. **같은 숫자, 다른 뜻** — 사이드바 숫자가 제품 모드에선 "보유/전체 10/13", Gap 모드에선 "공백 수 0"으로 바뀐다. 머리글 작은 글씨로만 알린다(01↔03).
5. **캔버스 위 띠가 2단** — 시작 카드 띠(또는 Gap 안내 띠) + 확대·전체 보기·인쇄 도구줄이 따로 있어 계통도 위가 110px 넘게 잠긴다(01, 03).
6. **하위 페이지의 '돌아가기' 방식이 3가지** — 기기·제품은 브레드크럼(04, 05), 공백 표는 "← 계통도로 돌아가기"(07), 비교는 2단 브레드크럼(06). 브레드크럼의 "L4 수전설비"는 링크가 아니다(04).
7. **모바일 계층 칩은 L6 이후·감시·신재생이 화면 밖** — 스크롤 단서가 없고, Gap/다크 줄이 헤더를 2단으로 키운다(09).

## 4. 다른 디자이너와 부딪힐 쟁점

1. **범례 위치 (vs 데이터시각화 D3·접근성 D5)** — 나는 범례를 캔버스 도킹 카드로 옮기자는 입장. 범례가 그림을 가린다는 반론, 이전 토론의 "데스크톱 범례 기본 접기 금지"와 충돌할 수 있다. 그래서 기본 펼침 + 미니맵 반대쪽 배치를 조건으로 한다.
2. **보조 탭줄 추가 (vs 비주얼·CI D2·인터랙션 D4)** — 세로 40px 비용과 '헤더 2단' 인상. 대안으로 헤더 안 검색창 왼쪽에 탭을 넣는 안도 받을 수 있으나, 1280 폭에서 검색창이 좁아지는 문제를 함께 따져야 한다.
3. **[제품|Gap]을 헤더에서 내리는 것 (vs D2)** — 마켓뉴스 대시보드와의 헤더 일관성·Gap의 존재감이 줄어든다는 반론 예상. 나는 '보기 방식은 그 그림 옆에'가 원칙이며, 대신 공백 표 탭 배지로 공백의 존재감을 보완한다.
