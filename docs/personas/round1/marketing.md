# 1라운드 평가 — 마케팅팀 매니저 (B2B 브랜드·콘텐츠)

> 근거: CONTEXT.md, 스크린샷(r2-main, p2-gap, p2-gaptable, p2-product, p2-learn, p2-mobile), index.html, src/main.tsx, PLAN.md §4, equipment-types.json(gapNote)

## 1. 나는 누구인가
- LS ELECTRIC 마케팅팀 매니저. 브랜드 가이드(CI·톤앤매너) 관리, 공식 홈페이지·SNS·전시회 콘텐츠 기획, 제품 브랜드(Susol·Metasol·GIPAM 등) 메시지 일관성을 책임짐.
- 이 앱을 여는 상황: ① "LS ELECTRIC" 이름이 붙은 사이트가 **외부(GitHub Pages)에 공개**되므로 출시 전 브랜드 검수, ② 신입·대리점 교육 자료로 링크를 배포할 때, ③ 홈페이지 제품 페이지로 유입되는 경로로 쓸 수 있는지 판단할 때.

## 3. 좋은 점
- **공식 채널로의 연결이 명확**: 제품 상세(p2-product)에 "공식 제품 페이지 ↗", "자료실에서 전체 자료 보기 ↗" 버튼과 날짜가 붙은 PDF 목록. 홈페이지를 대체하지 않고 **유입 경로** 역할을 하는 구조라 역할 중복이 적음.
- **사진은 공식 사이트 이미지(사내 허가)** 사용 — 제품 비주얼이 홈페이지와 일치(VCB, ALTS, PF 타일 등).
- **톤이 절제되고 정돈됨**: 흰 바탕·파란 포인트·카드형 UI, 과장 문구 없음. 브랜드 신뢰감과 충돌하지 않음.
- **제품 브랜드명이 맥락 속에 등장**: Gap 패널(p2-gap)에서 "Susol VCB", "XGIPAM"이 '이 공백과 연결된 자사 제품'으로 노출되고, 모바일 시트(p2-mobile)에서도 "Susol VCB / Susol UL VCB"가 보임. 계통 위 위치 + 브랜드를 같이 보여주는 것은 홈페이지에 없는 차별 가치.
- 페이지별 `document.title` 설정(기기명·제품명) — 탭/북마크 식별에 유리.

## 4. 문제점

## 6. 다른 부서와 충돌할 것 같은 지점
- **기획/전략팀**은 공백(Gap)을 크게 보여주길 원하겠지만, 나는 **외부 공개 사이트에서는 숨기거나 중립 표현**을 원함 → 공개/사내 빌드 분리가 절충안.
- **영업팀**은 "자사 제품 없음" 대신 경쟁 대안·추천 제품을 보여주고 싶을 수 있으나, 외부 사이트에 비교·경쟁 정보를 넣는 건 브랜드·법무 리스크.
- **교육(HR)팀**은 퀴즈·초안을 빨리 공개해 쓰고 싶겠지만, 나는 **검수 전 외부 공개 반대**(오류가 회사 공식 입장처럼 읽힘).
- **개발팀**은 GitHub Pages·HashRouter의 단순함을 원하지만, 공유 미리보기·SEO·접근 제한은 호스팅 방식 변경을 요구할 수 있음.
- **홈페이지 운영 담당**과는 제품명·사진·자료 링크의 갱신 주기를 맞춰야 함(이 사이트가 낡으면 홈페이지 신뢰도까지 훼손).

## 7. 성공 지표
1. **출시 전 브랜드·공개 검수 통과율 100%**: 외부에서 접근 가능한 화면에 미확인 "미보유" 문구 0건, CI 승인 완료.
2. **공식 홈페이지 유입 클릭 수**(제품 상세 "공식 제품 페이지 ↗" 클릭 / 제품 상세 조회) — 분석 도입 후 월별 추적, 인기 기기 Top 10 파악.
