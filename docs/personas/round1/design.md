# 1라운드 평가 — 설계 엔지니어 (수배전반·계통 설계, 견적 지원)

근거: r2-full.png, r2-main.png, p2-equipment.png, p2-product.png, `src/data/equipment-types.json`(74종), `src/data/diagram.json`(노드 74 · 연결선 77)

## 1. 나는 누구인가
- 특고압 수전설비(22.9kV)부터 저압 배전반·MCC까지 단선결선도(SLD)를 그리고, 정격(정격전압·정격전류·차단용량 kA)으로 기기를 골라 견적용 BOM을 만든다.
- 하루 업무: 고객 사양서 검토 → 표준 결선 골라 수정 → 차단기·CT·계전기 정격 선정, 보호협조 확인 → CAD 도면·사양서 작성.
- 이 앱을 열 상황: ① 신입 설계자에게 "수전설비 어디에 뭐가 들어가나"를 설명할 때, ② 고객이 말한 기기가 자사 라인업에 있는지와 카탈로그를 빨리 찾을 때, ③ 영업이 그린 개념도가 맞는지 확인할 때.

## 3. 좋은 점
- **계층 구분이 실무 감각과 맞음**: L4 수전 → L5 변압 → L6 저압 → L7 분기의 순서, 그리고 계층마다 전압 라벨(r2-full 좌측 "L4 수전설비 · 22.9kV")을 붙인 점.
- **전력선과 신호선을 구분**: 실선(전력)·점선(계측·보호·제어)으로 나누고, `relay → vcb` 연결선에 "트립" 라벨을 단 점. 보호계전 개념을 설명하기 좋다.
- **공백 기기도 계통에서 빼지 않음**: LA, MOF, CT/PT를 빨간 점선 타일로 남겨 둠(r2-main). 설계에서는 타사품이라도 반드시 들어가는 기기라서 맞는 판단이다.
- **학습 포인트의 기술 내용이 대체로 정확함**: "CT 2차 개방 금지", "CT 2차 5A/1A", "MCCB는 AF/AT 구분", "ELCB 30mA 인체 보호", "22.9kV-Y 다중접지", "직입 기동 전류 6~8배".
- 제품 상세에서 카탈로그·매뉴얼 PDF에 바로 가고 날짜가 보임(p2-product, p2-equipment). 자료실을 검색하는 시간이 줄어든다.

## 4. 문제점 (계통 표현 오류 중심)
| 심각도 | 내용 | 근거 |
|---|---|---|
| **높음** | **345kV → 154kV 강압 변압기 누락.** 송전선로(345kV)에서 154kV GIS로 변압 없이 바로 이어지고 연결선에 "154kV" 라벨만 붙어 있음. 전압이 기기 없이 바뀐다. | diagram.json `n-tline → n-gis154 (voltage:154kV)` |
| **높음** | **22.9kV 모선에서 6.6kV로 변압 없이 넘어감.** VCB(22.9kV) → VC → MV Drive 연결선에 "6.6kV" 라벨이 붙음. 22.9/6.6kV 변압기가 빠졌다. 고압 인버터는 보통 VCB 피더에서 전용 입력 변압기(또는 내장 TR)로 받는다. | `n-vcb → n-vc`, `n-vc → n-mv-drive (6.6kV)` |
| **높음** | **VCB 뒤에 PF를 직렬로 그림.** VCB → PF → 유입변압기 구성은 실무에 없다. PF는 차단기 **대신** LBS/인터럽터 스위치와 조합해 쓰는 방식(PF형 수전)이다. 앱의 학습 포인트("차단기 대신 경제적으로")와도 맞지 않는다. | `n-vcb → n-pf → n-oil-tr`, pf.learnPoints |
| **높음** | **유입변압기 2차에 주차단기가 없음.** oil-tr → 버스웨이로 바로 연결돼 있다. 몰드 TR 쪽은 ACB를 거치므로 두 계통이 서로 다르다. | `n-oil-tr → n-busway (380V)` |
| 중간 | **ALTS와 LBS/ASS가 MOF에 병렬로 들어감.** 상용·예비 두 회선이 동시에 투입된 것처럼 보인다. ALTS는 2입력(상용/예비) 1출력의 인입 개폐기로서 LBS/ASS를 **대체**하는 위치에 와야 한다. 예비 회선도 RMU에서 따왔는데, 실제로는 다른 변전소·피더에서 오는 별도 회선이다. | `n-lbs → n-mof`, `n-alts → n-mof`, `n-auto-sw → n-alts` |
| 중간 | **ATS 출력이 아무 데도 안 감.** 상용(버스웨이)과 비상발전기 입력만 있고, 비상부하(소방·승강기) 모선이 없다. 절환의 의미가 그림에서 드러나지 않는다. | `n-busway → n-ats`, `n-egen → n-ats` |
| 중간 | **수전 단일 VCB 하나가 모든 피더를 담당.** 주 차단기(Main)와 피더 차단기의 구분, 모선(Bus) 표기가 없다. 범례에 "모선"은 있지만 L4에서는 쓰이지 않는다. CT/PT도 VCB 아래 별도 분기(전력선)로 그려 계측용 변성기가 부하처럼 보인다. | `n-vcb → n-ct-pt (kind:power)`, r2-main |
| 중간 | **태양광 연계 표현이 단순함.** PCS가 저압 ACB 노드에 바로 붙는다. 실제로는 연계용 차단기, (대용량이면) 연계 변압기·22.9kV 연계, 역송전 계량, 연계 보호(OVR/UVR/OFR/UFR, 단독운전 방지)가 들어간다. ESS→PCS 사이에는 DC 차단기도 빠져 있다. | `n-pcs → n-acb (380V 연계)`, `n-ess → n-pcs` |
| 중간 | **수전 필수 기기 누락**: 단로기(DS), COS(PT·소용량 TR 보호용), 접지·NGR, 변압기 보호(비율차동·온도계전기). 표준 결선도를 설명할 때 바로 질문이 나온다. | equipment-types.json에 해당 id 없음 |
| 중간 | **정격 데이터가 자사 자료와 어긋남**: VCB 전압이 "7.2~25.8kV"로 되어 있는데, 같은 화면 자료 목록에 "Susol UL VCB UVH 27/38kV"가 있다(p2-equipment). L1 헤더는 765/345kV인데 노드에는 345kV만 있다. | vcb.voltage, layers[L1] |
| 낮음 | 전압 표기가 섞여 있음: 대부분 "380/220V"(국내 관용)인데 MCB/RCBO만 "230/400V"(IEC 60038). 표기 순서도 고압/저압이 섞였다. 보호계전기 voltage "22.9kV"처럼 2차 기기에 1차 전압을 단 경우도 있다(입력은 CT 5A/PT 110V). | mcb-rcbo, protection-relay |
| 낮음 | 진상콘덴서가 category "measurement"로 분류됨. 역률 보상·전력품질 기기다. | capacitor.category |
| 낮음 | 사진 타일 계통도라 IEC 60617/KS C 0102 심볼 단선결선도가 아니다. 미보유 타일만 기호를 쓰는데, MOF가 CT 기호 하나로만 그려져 있다(실제 MOF는 CT+PT 일체). | r2-main |

## 6. 다른 부서와 충돌할 것 같은 지점
- **교육팀은 "한 장에 74종을 다 보여 주는 단순화"를 원하겠지만**, 나는 틀린 단순화(VCB-PF 직렬, 변압 없는 전압 변화)는 안 된다고 본다. 단순화하더라도 전기적으로 성립하는 구성이어야 한다. 이 때문에 노드가 몇 개 늘어난다.
- **영업·마케팅은 사진 타일과 '보유' 강조를 원하겠지만**, 설계자는 심볼 단선도와 정격이 필요하다. 토글로 둘 다 두는 방향으로 타협하자.
- **Gap/전략 쪽은 '미보유'를 사업 공백으로 강조하겠지만**, LA·MOF·CT/PT·DS·COS는 원래 패널에 타사품을 넣어 공급하는 기기라서 "공백 = 사업 기회"로 단정하면 안 된다. 커버리지와 "수배전반에 포함해 공급 가능"을 구분해 표시해야 한다.
- **외부 공개 제약**: 견적 단가, 실제 프로젝트 도면, 보호협조 정정값은 내가 가장 원하는 정보지만 넣을 수 없다. 공개 카탈로그 정격과 일반 표준결선까지만 담는 데 합의해야 한다.

## 7. 성공 지표
1. 설계팀 기술 검수에서 지적되는 계통·데이터 오류 **0건** 유지(분기마다 재검수).
2. 정격 범위가 들어간 기기 상세에서 카탈로그·도면 링크 클릭률, 설계 부서 사용자의 주간 재방문 수.
