# 1라운드 — 신입사원(입사 2주차) × HRD 교육 담당자

> 근거: CONTEXT.md, 스크린샷(p2-learn, r2-learn-finish, r2-main, p2-equipment, p2-mobile), `src/content/learn.json`(7단계·퀴즈 20·용어 36), `src/data/equipment-types.json`(학습 포인트), `src/pages/learn/*`(진도 로직, 읽기만 함).
> 표기: **[신입]** = 신입사원 관점, **[HRD]** = 교육 담당자 관점.

## 1. 나는 누구인가
- **[신입]** 전기공학 학사, 입사 2주차, 현장·영업 경험 없음. 회로이론·전력공학 수업에서 "송전·배전"은 배웠지만 VCB·MOF·ASS·ALTS 같은 **현장 약어와 우리 회사 제품명(Susol, GIPAM, iS7)** 은 처음 본다. 선배 회의에서 들은 약어를 몰래 찾아볼 때, 직무교육 숙제할 때, 부서 배치 전에 "우리 회사가 뭘 파는지" 감을 잡을 때 이 앱을 연다.
- **[HRD]** 신입 입문교육(집합교육 + 사내 이러닝) 기획·운영 담당. 이 포털을 **사전학습/복습 과제**로 넣을 수 있는지, 수료 판단에 쓸 수 있는지, 콘텐츠 오류가 났을 때 누가 고치는지를 본다.

## 2. 꼭 하고 싶은 일 Top 3
| # | 시나리오 | 현재 |

## 3. 좋은 점
- **[신입]** 투어 제목 "전기가 발전소에서 콘센트까지 오는 길"과 L1→L7 순서가 학교에서 배운 전력계통 흐름과 그대로 이어져, 처음 보는 기기도 "어느 전압 구간인가"로 자리를 잡을 수 있다(r2-learn-finish 상단 진행 바).
- **[신입]** 각 단계 intro가 "왜"를 설명한다. 예: L1 "전압을 높이면 전류가 줄어 선로 손실(I²R)이 줄어듭니다", L3 "배전 고장 대부분은 일시 고장이라 리클로저가…". 전공 지식과 현장 기기를 연결해 준다.
- **[신입]** 퀴즈는 즉시 정답·해설 표시. 해설이 혼동 쌍을 정확히 짚는다 — 차단기(GCB) vs 단로기(l1-gis-ds), 부하개폐기는 고장전류 못 끊음(l3-lbs), MCCB의 AF/AT(l6-mccb). 신입이 실제로 헷갈리는 지점이다.
- **[신입]** 기기 74종 모두 학습 포인트 1~2개(56종 1개, 18종 2개)가 있고, 상세 화면에서 "교육 투어에서 이 계층 배우기 →"로 투어와 연결된다(p2-equipment). 모바일 하단 시트에도 "신입 학습 포인트"가 보인다(p2-mobile) — 출퇴근 중 복습에 좋다.
- **[HRD]** 콘텐츠가 `learn.json` 한 파일에 구조화(단계·핵심 기기 ID·퀴즈·sourceEquipmentIds·용어)되어 있어 검토표로 뽑기 쉽다. `reviewStatus: "draft — 교육 담당자 검토 필요"`로 미검토임을 스스로 밝힌 점도 정직하다. 정답 위치도 0~3에 고르게 분포(정답 번호 찍기 방지).

## 4. 문제점
| 심각도 | 관점 | 내용 (근거) |
|---|---|---|
| 높음 | HRD | **진도·점수를 볼 수 없다.** localStorage 저장이라 PC를 바꾸거나 캐시를 지우면 사라지고, 교육 담당자는 확인할 방법이 없다. 그대로는 수료 요건으로 쓸 수 없다. |
| 높음 | HRD | **"완료" 정의가 약하다.** "다음" 버튼만 눌러도 그 계층이 완료로 기록되고(`next()` → `markDone`), 퀴즈는 맞히지 않아도 답만 하면 완료. 마지막 단계 URL로 바로 들어가 "투어 완료"를 누르면 "투어 완료 — 수고하셨습니다 / 계층 1/7 · 퀴즈 정답 0/20"이 함께 뜬다(r2-learn-finish). 축하 문구와 0점이 함께 보여 신입도 HRD도 혼란스럽다. |
| 높음 | 신입·HRD | **미검증 공백 정보가 교육에 그대로 노출된다.** 투어 각 단계에 "이 계층의 공백 — 자사 제품 없음: LA, MOF, CT/PT…"가 나오는데, 데이터는 "홈페이지 기준 — 실제 확인 필요"다. 신입은 이걸 사실로 외워 고객·대리점 앞에서 "우리는 MOF 안 합니다"라고 말할 위험이 있다. |
| 중간 | 신입 | **틀린 문제를 다시 풀 수 없다.** 답하면 보기가 잠기고(`disabled={answered}`), "처음부터 다시 보기"도 답을 지우지 않는다. 오답 복습·재도전이 안 돼 동기가 떨어진다. |
| 중간 | 신입 | **퀴즈가 intro에서 안 가르친 내용을 묻는다.** l6-pf(역률·진상콘덴서)는 L6 intro에 콘덴서 설명이 없고, l7-soft(직입 기동 6~8배·소프트 스타터)는 L7 intro·핵심 기기에 없다. l1-gis-ds의 "단로기"도 intro에 없다. 신입은 "배운 적 없는데?" 하게 된다. |
| 중간 | 신입 | **intro의 미정의 용어.** "수용가", "22.9kV-Y 다중접지", "탭 절환", "아크 소호", "지락", "무효전력", "역률", "단로기"가 용어집에 없다. RMU는 풀네임 없이 "배전용 가스절연 부하개폐기"로만 적혀 있다(용어 검토 필요). |
| 중간 | HRD | **퀴즈 난이도가 한쪽에 몰려 있다.** 20문항 대부분이 "~하는 기기는?" 식 정의 회상이고 오답 보기가 너무 쉽다(l5-oil의 "배터리 잔량", l2-bus의 "탭/진공 인터럽터"). "공장 수전설비에서 고장 시 무엇이 어떤 순서로 동작하나" 같은 적용형 문항이 없어 이해도를 가리기 어렵다. l3-lbs만 보기 3개라 형식도 고르지 않다. |
| 중간 | HRD | **범위 공백.** 계통도 9개 영역 중 감시·제어(PLC·HMI 등 6종)·신재생·저장(7종)은 투어·퀴즈에 없다. 용어집엔 PLC·HMI가 있는데 단계는 없다. 자동화 사업부로 갈 신입에게는 정작 자기 제품이 빠진 셈이다. |
| 중간 | HRD | **검토·갱신 책임이 정해져 있지 않다.** 문항별 검토자·검토일·근거 문서 필드가 없어, 제품이 단종·개명되면(퀴즈 해설의 "iS7, S100, G100") 누가 언제 고치는지 알 수 없다. |
| 낮음 | 신입 | 교육 탭 첫 화면(p2-learn)은 계통도 + 오른쪽 빈 "상세 정보" 패널이라, "투어 시작" 버튼 말고는 무엇부터 할지 안내가 약하다. 예상 소요 시간도 없다. |
| 낮음 | 신입 | p2-equipment 스크린샷에서 왼쪽 사이드바 스타일이 깨져 보인다(큰 제목·정렬 붕괴). 로딩 중 캡처였는지 재확인 필요. |

## 6. 다른 부서와 충돌할 것 같은 지점
- **기획·전략(Gap 담당)은** 공백을 교육 화면에서도 크게 보여 주길 원하겠지만, **나(HRD)는** 미검증 공백을 신입에게 사실처럼 가르치는 건 위험하다고 본다 → 교육 모드에서는 "확인 필요" 표기·기본 접힘(제안 2).
- **영업은** 제품명·모델 위주의 "팔기 위한" 학습을 원하겠지만, **신입 교육은** 계통 원리(왜 이 기기가 여기 있나)를 먼저 세워야 한다 → 기본 투어는 원리, 제품은 상세로 연결하는 현재 구조를 유지.
- **IT·보안은** 외부 공개 정적 사이트에 개인 진도·이름을 저장하는 데 반대할 것이다. HRD는 수료 확인이 꼭 필요하다 → 서버 저장 없이 "결과 요약 출력·제출"로 타협(제안 4), 정식 추적은 사내 LMS에서.
- **콘텐츠 작성 팀(개발/기획)은** 빨리 공개하고 싶겠지만, **HRD는** 검토 전 콘텐츠로 정식 과정을 운영할 수 없다 → 문항별 검토 메타와 "초안" 배지(제안 1).
- **사업부(자동화·에너지)는** 자기 제품 단계 추가를 원하고, **메인 화면 담당은** 범위가 늘어 복잡해지는 걸 꺼릴 수 있다 → 기본 7단계 + 선택 "심화 코스"로 분리.

## 7. 성공 지표
1. **입문교육 대상 신입의 투어 완주율 ≥ 80%, 계층별 퀴즈 평균 정답률 ≥ 70%** (제안 3·4 이후 결과 요약 제출분 기준 집계).
2. **콘텐츠 검토율 100%**: 퀴즈 20·용어 36 모두 검토자·검토일이 기록되고, 신입 설문에서 "약어/용어 때문에 막혔다" 응답이 1기수 대비 절반 이하.
