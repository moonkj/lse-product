# 1라운드 평가 — 기술영업 과장 (빌딩·플랜트 고객 담당)

근거: 스크린샷 r2-full, r2-main, p2-gap, p2-gaptable, p2-product, p2-equipment, p2-mobile / PLAN.md / docs/research/product-mapping.md

## 1. 나는 누구인가
- 빌딩(오피스·병원·데이터센터)·플랜트(공장·물류센터) 고객의 수전~분전 계통 제안을 맡은 기술영업 과장.
- 하루 업무: 설계사무소·시공사·고객 설비팀 미팅 2~3건, 견적·사양 회신, 카탈로그 송부, 사내 설계팀 협의.
- 이 앱을 열 상황: ① 미팅 중 태블릿·노트북으로 "저희가 수전부터 분전반·감시까지 다 됩니다"를 보여줄 때 ② 고객이 특정 기기를 물을 때 카탈로그를 즉시 찾을 때 ③ 미팅 후 자료 링크를 메일·메신저로 보낼 때.

## 2. 꼭 하고 싶은 일 Top 3
| # | 시나리오 | 현재 |
|---|---|---|
| 1 | 고객 앞에서 "빌딩 수전설비(L4)~분전반(L7)+EMS" 범위만 띄워 우리 제품 라인업을 설명 | **부분** — 계층 바로가기·줌으로 L4 이동은 됨(r2-main). 그러나 L1~L3(초고압·송전)까지 한 화면에 섞여 있고, 업종별(빌딩/공장/데이터센터) 보기 없음. 빨간 점선 "자사 제품 없음" 타일이 제품 모드에서도 그대로 노출 |
| 2 | 고객이 "VCB 카탈로그 주세요" → 그 자리에서 링크/QR 전달 | **부분** — 제품 상세에 카탈로그·매뉴얼 PDF 링크·날짜 있음(p2-product, p2-equipment). 공식 자료실 링크라 외부 고객도 열림. 하지만 "링크 복사"는 Gap 모드에만 있고(p2-gap), 제품/기기 페이지에 공유 버튼·QR 없음 |
| 3 | 수배전반+VCB+보호계전기+EMS를 하나의 "패키지"로 묶어 보여주기 | **불가** — 기기 단위 상세만 있음. 연결 기기(계통 속 위치: CT/PT→OCR/OCGR→VCB, p2-product)가 단초는 되지만 패키지·구성 예시 화면 없음 |

## 3. 좋은 점
- **전체 계통도 한 장(r2-full)**: 사진 타일 74종이 전압 계층별 색 띠로 정리돼 "발전부터 부하·신재생·감시까지"라는 LS ELECTRIC 포트폴리오 폭을 시각적으로 보여주기 좋다. 고객 첫 인상용으로 강력함.
- **계통 속 위치(p2-product)**: "CT/PT → OCR/OCGR → VCB" 미니 흐름이 계전기를 왜 같이 사야 하는지 설명하는 근거가 된다. 크로스셀 대화에 바로 쓸 수 있음.
- **자료 최신성 표시(p2-equipment)**: 카탈로그·매뉴얼에 날짜·언어(EN) 표기 — 해외 EPC 고객에게 영문 자료 즉시 전달 가능.
- **모바일 하단 시트(p2-mobile)**: 계층 칩+시트로 현장에서 폰으로도 VCB 설명·제품 4종 확인 가능.
- **공백 메모의 정직성(p2-gap)**: "홈페이지 기준 — 실제 확인 필요" 문구는 내부용으로는 바람직.

## 4. 문제점
| 심각도 | 내용 | 근거 |
|---|---|---|
| 높음 | **제품 모드에서도 공백이 빨간 점선+"자사 제품 없음"으로 노출** — 고객 앞에서 L4 수전설비를 띄우면 LA·MOF·CT/PT 3개가 빨갛게 떠 "LS는 수전반 핵심 계기를 못 만든다"로 읽힘. 실제로 수배전반 패키지에서는 타사 계기를 조달·내장하는 경우가 있을 수 있는데(확인 필요) 이 맥락이 화면에 없음 | r2-main, r2-full |
| 높음 | **외부 공개 사이트에 공백 표·CSV·보유율 76%가 그대로 공개** — 경쟁사가 우리 공백 목록을 그대로 가져갈 수 있음. 영업 자료로는 역효과 | p2-gaptable, CONTEXT(외부 공개) |
| 높음 | **제품·기기·공백표 페이지 좌측 사이드바 스타일 깨짐** — 제목이 거대한 글씨로 줄바꿈, 범례 아이콘 정렬 붕괴, 검색창 위 검은 점(●). 고객에게 띄우기 민망한 수준 | p2-product, p2-equipment, p2-gaptable |
| 중간 | 업종(빌딩/공장/데이터센터/병원) 시나리오 없음 — 빌딩 고객에게 765kV·HVDC는 불필요한 정보 | r2-full |
| 중간 | 공유 수단 부족 — 제품/기기 상세에 링크 복사·QR 없음. 자료 PDF 여러 개를 한 번에 보낼 방법 없음 | p2-product, p2-equipment |
| 중간 | 사양 표 없음 — "정격전류·차단용량 몇 kA까지?" 질문에 답 못 하고 PDF를 열어야 함 | CONTEXT(사양 미수집) |
| 낮음 | 제품 카드 썸네일이 4종 모두 같은 사진 — 라인업 차이가 안 보임 | p2-equipment |
| 낮음 | 발표 모드 부재 — 우측 패널·미니맵·키보드 안내 등 내부용 UI가 프로젝터 화면을 차지 | r2-main |

## 5. 제안
| # | 내용 | 기대 효과 | 노력 | 우선순위 | 데이터·리스크 |
|---|---|---|---|---|---|
| 1 | **사이드바 스타일 깨짐 수정**(제품·기기·공백표 페이지) | 고객 앞 시연 가능 최소 조건 | S | P0 | 없음 |
| 2 | **"고객 설명(발표) 모드"**: `?mode=present` — 보유·계열사 보유만 표시, 공백은 회색 중립 "협력 조달/별도 문의"로 표기 또는 숨김, 우측 패널·미니맵 최소화, 큰 글씨 | 약점 노출 없이 범위 설명. 제품 모드는 내부용으로 유지 | M | P0 | "협력 조달" 표기는 사실 확인 필요(구매·설계팀). 화면 요소 변경이므로 사용자 확인 후 진행 |
| 3 | **공백 정보 외부 비노출**: /gap, Gap 모드, CSV를 공개 빌드에서 제외하거나 사내 인증 뒤로 이동 | 경쟁사에 공백 목록 유출 방지 | M(정적 사이트라 별도 사내 배포 필요) | P0 | GitHub Pages 공개 구조와 충돌 — 기획·IT 결정 필요 |
| 4 | **공유 버튼 + QR**: 기기/제품 상세에 "링크 복사·QR 표시", 공유 링크는 발표 모드로 열리게 | 미팅 중 고객 폰으로 즉시 자료 전달 | S | P1 | 공식 자료실 링크만 사용(이미 공개 자료) |
| 5 | **업종 시나리오 필터**: "빌딩 수변전(L4~L7+BEMS)", "공장(L4~L7+MCC·VFD·PLC)", "데이터센터(+UPS/ATS·DC배전)", "신재생 연계" 프리셋으로 해당 노드만 하이라이트 | 고객 업종 맞춤 설명, 불필요한 초고압 제거 | M | P1 | 시나리오 구성은 팀 초안 → 영업팀 검토. 노드 데이터 이미 존재 |
| 6 | **패키지 카드**: "수전반 패키지 = 특고압 수배전반+VCB+보호계전기+WHM+EMS" 같은 묶음을 계통도 경로 하이라이트+자료 일괄 링크로 | 크로스셀·통합 제안 근거 | M | P1 | 가격·견적 정보는 넣지 않음(외부 공개) |
| 7 | 핵심 사양 요약(정격·차단용량 범위 2~3줄) | 미팅 중 질의 즉답 | L | P2 | 카탈로그 수작업 추출, 오기재 시 책임 문제 |
| 경쟁사 비교 | **공개 사이트에는 넣지 않음**을 권고. 필요 시 사내망 별도 문서로 | 법무·대외 리스크 회피 | — | 보류 | 데이터 없음(CONTEXT) |

## 6. 다른 부서와 충돌할 것 같은 지점
- **기획/전략팀**: 공백(Gap) 강조가 핵심 기능이라 생각하겠지만, 나는 외부 공개 화면에서 공백이 빨갛게 보이는 것 자체가 영업 리스크라고 본다 → 내부용/외부용 분리 필요.
- **교육(신입) 담당**: L1~L7 전체 계통과 "자사 제품 없음"까지 정직하게 보여주길 원하겠지만, 나는 고객 앞에서는 업종 범위만 축약해 보여주고 싶다 → 모드 분리로 해결 가능.
- **IT/보안·법무**: 공유 링크·QR을 늘리면 외부 유입이 커지고, 경쟁사 비교를 원하는 영업 요구와 공개 사이트 제약이 정면 충돌.
- **마케팅/브랜드**: 사진·제품명 표기를 공식 사이트와 맞추길 원할 것 — 업종 시나리오·패키지 명칭은 마케팅 메시지와 정렬 필요.

## 7. 성공 지표
- 영업 미팅에서 앱 시연 횟수(분기 영업 담당 대상 설문 또는 `?mode=present` 진입 수) — 목표: 담당자 50% 이상 월 1회 이상 사용.
- 공유 링크/QR 경유 자료 열람 수(공식 자료실 유입) 증가.
