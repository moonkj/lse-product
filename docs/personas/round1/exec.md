# 1라운드 평가 — 전력사업부 임원(사업부장급)

## 1. 나는 누구인가
- 역할: 전력사업부장. 포트폴리오 투자·M&A·파트너십 의사결정, 분기 경영회의 보고, 수주 전략 승인.
- 하루 업무: 사업계획 리뷰, 주요 수주 건 판단, 경쟁 동향 보고 청취, 대외 행사·고객 미팅.
- 이 앱을 열 상황: (1) 경영회의 전 "우리 포트폴리오의 빈칸이 어디냐"를 5분 안에 파악할 때, (2) 신규 사업·M&A 후보 검토 시 계통 상 위치와 인접 제품 시너지를 확인할 때, (3) 고객·투자자에게 "계통 전 구간 솔루션 업체"임을 보여 줄 때.

## 3. 좋은 점
- **한 장으로 보이는 포트폴리오**: 전체 계통도(r2-full.png)에서 L1~L7·감시·신재생 74종이 한 화면에 들어오고, 빨간 점선 타일만으로 공백 위치가 즉시 보임. 경영진 설명용 "그림 한 장"으로 가치가 큼.
- **계층별 보유율 숫자**: 좌측 바로가기에 L1 4/9, L3 2/5, L6 8/12 등 분수 표기 → 상류(L1·L3)가 상대적으로 약하다는 메시지가 바로 읽힘.
- **정직한 상태 정의**: "미보유(공백 후보, 홈페이지 기준 — 실제 확인 필요)"와 "계열사 보유(LS전선)"를 분리. 그룹 차원 포트폴리오 시각을 반영한 점이 좋음.
- **Gap 모드 공유 링크**(`?mode=gap`, "링크 복사" 버튼): 보고 라인에 URL 하나로 공유 가능.
- **연결된 자사 제품**: 공백을 "인접 제품의 결손"으로 볼 수 있게 함 → 번들 판매 손실 논의의 출발점.

## 6. 다른 부서와 충돌할 것 같은 지점
- **영업**은 공백 메모에 "경쟁사 X 제품으로 대응" 같은 대안을 넣길 원하겠지만, 나는 경쟁사·대응 정보는 **외부 공개판에 절대 불가**, 사내판에서만 허용.
- **교육/HR**은 접근 편의를 위해 외부 공개(로그인 없음)를 유지하고 싶겠지만, 나는 **공백 기능을 공개판에서 빼는 것**이 우선. 교육 기능은 공개 유지 가능하므로 "공개판=교육·제품, 사내판=전략" 분리로 타협.
- **제품기획**은 공백을 "로드맵에 있음"으로 표시하고 싶겠지만, 미발표 로드맵은 대외비 → 사내판 한정.
- **개발팀**은 관리자 모드·사양 표 수집 등 기능 확장을 우선하겠지만, 나는 **데이터 검증(공백 12건 확정)과 노출 통제**가 신규 기능보다 먼저.
- **홍보/브랜드**는 공식 사진·로고 사용 범위를 엄격히 볼 것 — 사내 허가 범위가 외부 공개까지 포함하는지 확인 필요.

## 7. 성공 지표
1. **공백 검증률**: 공백·일부 보유 15건 중 확인자·확인일이 기록된 항목 비율 → 4주 내 100%.
2. **의사결정 활용**: 분기 경영회의/사업계획 자료에서 이 포털의 매트릭스 또는 공백 표가 인용된 횟수, 그리고 전략 옵션이 "결정됨"으로 바뀐 공백 수(분기 3건 이상).
