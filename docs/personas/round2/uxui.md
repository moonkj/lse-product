# 2라운드 — UX/UI 디자이너 (시니어)

> 근거: 최신 스크린샷 scratchpad/cur/*.png(51d8dd9), round1 8명 평가, 승인 디자인 docs/design.

## 0. 1라운드 정정
- **철회**: 1라운드 P0였던 "하위 페이지 사이드바 레이아웃 깨짐"을 철회한다. cur/product·gaptable·learn을 보니 좌측 메뉴·헤더·검색창이 정상이고 검은 점도 없다. 다른 페르소나들(영업·마케팅·현장·임원·신입)도 같은 p2 스크린샷을 근거로 이 결함을 지적했다.
- **유지(최신 화면에서 다시 확인)**:
  - 모바일에서 VCB(L4)를 선택했는데 계층 칩은 "L5 변압"이 활성이다(cur/mobile).
  - 제품 상세 "계통 속 위치" 미니 체인의 VCB 타일이 상자 밖으로 넘친다(cur/product, 리더 지적과 같음).
  - 첫 화면 빈 패널 문제: cur/main은 VCB가 선택된 상태라 이 스크린샷으로는 판단할 수 없다. 1라운드 근거인 r2-main(미선택 상태)은 그대로 유효하다.
- **새로 확인**: 교육 L4 단계에서 진행 바에 이미 지나온 L1~L3 완료 표시가 없고 "학습 완료 0개 계층"으로 나온다(cur/learn). 신입 페르소나가 지적한 "다음만 눌러도 완료" 로직과 함께 보면, 완료 기준이 화면에서 일관되게 보이지 않는다.

## I1 외부 공개 vs 공백 노출 — **조건부 찬성(분리)**
- **입장 수정**: 1라운드의 "강조 유지·문구만 조정"을 거두고 **임원·연구소·마케팅의 공개/사내 빌드 분리에 동의**한다. 다만 사내판의 Gap 강조(빨간 점선·글로우)는 유지한다.
- **근거**: 공백 12건 중 11건이 같은 미확인 메모다. 이 상태로 외부 공개 화면에 빨간 시각 위계를 주는 것은 "확정 사실"처럼 읽히게 만드는 디자인 오류다. 시각 강조의 크기는 데이터 확신도에 비례해야 한다.
- **반박(영업·마케팅)**: 공개판에서 공백 노드를 **삭제**하는 데는 반대한다. 계통에 구멍이 생기면 교육용 그림 자체가 성립하지 않는다(설계 페르소나도 "타사품이라도 반드시 들어가는 기기"라고 했다).
- **타협안**: 공개판은 공백 노드를 사진 없는 **중립 회색 심볼 타일**로 바꾸고 라벨은 "본 맵 미등록"(마케팅 문구)으로 한다. 배지·Gap 탭·공백 표·KPI·CSV는 공개판에서 뺀다.

## I2 계통 정확성 vs 단순화 — **찬성(정정)**, "74종 각 1회"는 완화
- **동의(현장·설계)**: 틀린 연결은 고쳐야 한다. 단순화의 목적은 인지 부하를 줄이는 것이지 틀린 정보를 주는 것이 아니다.
- **근거·디자인 해법**: 변압기 2개, ACB 1개, 비상부하 1개 정도를 추가하는 것은 74→약 78개 수준이라 시각 부하가 미미하다. 승인 디자인의 **system 그룹 박스 규칙**(README: 수배전반=점선 그룹)을 쓰면 "같은 기기의 재등장"을 그룹 안 반복으로 자연스럽게 표현할 수 있다.
- **반박(연구소)**: DC·HVDC·디지털 변전소 하위 노드를 메인에 추가하는 데는 반대한다. 보조 뷰로 처리해야 한다.
- **타협안**: 메인 계통도 = 전기적으로 성립하는 최소 개념도(재등장 허용, 재등장 노드는 "2" 같은 보조 표기). 수전반 상세(현장)와 표준 템플릿(설계)은 **같은 타일 컴포넌트를 쓰는 보조 뷰**로 P1.

## I3 공백의 정의 — **찬성(새 상태 + 근거 필드)**
- **동의(설계·연구소)**: LA·MOF·CT/PT는 "패널 구성품·타사 조달"이라는 6번째 상태로 분리한다. 연구소가 제안한 `evidence/verifiedBy/verifiedAt/confidence` 필드에도 찬성한다.
- **디자인 조건**:
  - 상태를 늘려도 **모양 부호화는 유지**한다(예: ⊡ 테두리 점선 회색).
  - 확신도는 색이 아니라 **선 스타일**로 나타낸다. 후보는 점선, 확정은 실선이다.
  - 범례는 6개 이하로 유지하고, 그보다 늘면 범례를 접는다.
- **타협안**: confidence가 "확정"이 아닌 항목은 사내판에서도 "공백 후보" 라벨을 유지한다.

## I4 영업 발표 모드 — **조건부 찬성**
- **동의(영업)**: 프로젝터용 축약 UI(패널·미니맵 최소화, 큰 글씨)가 필요하다.
- **반박**: 그러나 I1에서 공개판을 중립화하면 **공개판 자체가 발표 모드 역할을 한다**. 모드를 하나 더 만들면 화면 상태가 3중(제품/Gap/발표)이 되어 일관성 비용이 커진다.
- **타협안**: 별도 모드 대신 공개판에 "발표 보기" 토글(UI 크롬 숨김 + 글자 확대)만 둔다. 공백 표현은 공개판 규칙을 그대로 쓴다. 업종 프리셋 하이라이트는 P1.

## I5 교육 품질 — **찬성(신입·HRD)**
- **동의**: 완료 기준 강화, 0점일 때 축하 문구 제거, 오답 다시 풀기에 찬성한다.
- **근거(화면)**: r2-learn-finish("투어 완료"와 1/7이 함께 표시), cur/learn(완료 표시 0개).
- **디자인 제안**: 진행 바를 3상태로 나눈다(방문함 / 퀴즈 완료 / 미방문). 투어의 "이 계층의 공백" 박스는 I1·I3 규칙을 따라 "확인 필요" 톤(빨강 → 중립)으로 바꾸고 기본 접힘으로 둔다.
- **양보선**: 수료 증빙은 "결과 요약 출력" 수준(HRD 제안 4)이면 충분하고, 서버는 필요 없다.

## I6 다음 분기 우선순위
- 온보딩(빈 패널 추천 카드)은 P0에서 **P1로 내린다**. 이유는 두 가지다. 정확성·노출 문제가 먼저이고, 공개판 구조가 바뀌면 추천 카드 내용도 바뀐다.
- 의미적 줌 P1, OG·파비콘·공식 고지 P0(작음·마케팅 동의), 정격 데이터 P1, 단종/후속 P1, PWA P2, 분석 P1.

## 내가 꼽는 P0 3개 (전체 관점)
1. **공개/사내 분리 + 공개판 공백 중립화**: 공백 노드는 회색 심볼과 "본 맵 미등록" 라벨로 바꾸고 Gap·공백 표·KPI는 사내판으로 옮긴다. "비공식 교육 자료·공식은 ls-electric.com" 고지도 함께 단다.
2. **계통 연결 오류 6~7건 정정 + 설계팀 검수일 표기**: 재등장을 허용하고, 그룹 박스 규칙으로 시각 부하를 통제한다.
3. **공백 판정 근거 필드 + 상태 재정의**: confidence·출처 필드를 넣고 "패널 구성품·타사 조달" 상태를 추가하며, 확신도는 선 스타일로 표현한다. 교육 완료 기준 수정과 모바일 칩·미니 체인 버그 같은 S급 일관성 수정은 이 3개와 함께 바로 처리한다.
