# 2라운드 교차 토론 — 전력사업부 임원(사업부장급)

**1라운드 정정**: 문제점 표의 "공백 표 좌측 사이드바 글자 겹침"(낮음)은 메인 화면 작업 중에 찍힌 옛 스크린샷(p2-gaptable) 때문이었습니다. 리더 정정에 따르면 51d8dd9에서는 정상이므로 **철회**합니다. 따라서 제안 4(경영 보고용 1장 내보내기)의 근거에서 "인쇄 CSS 깨짐"은 빼고, "기준일·검증 상태 표기 없음, CSV만 지원"만 근거로 남깁니다.

## I1 외부 공개 vs 공백 노출 — **찬성(분리)**, 조건부 타협 가능
- **동의**: 마케팅(공개 빌드에서 Gap·공백 표 숨김, "본 맵 미등록"으로 중립화), 연구소(공개판=보유 매핑·교육 / 사내판=Gap·KPI·CSV·메모), 영업(/gap·CSV 공개 제외).
- **반박**: UX의 "강조는 유지하고 문구만 '공백 후보·확인 필요'로". 문구를 부드럽게 해도 **미검증 미보유 목록 12건이 외부에 그대로 나간다**는 사실은 바뀌지 않습니다. 경쟁사가 수집할 수 있고, 틀린 항목은 우리에게 불리한 오정보가 됩니다(product-mapping.md "홈페이지에 없다고 실제 미보유라는 뜻은 아님").
- **타협선**: UX의 강조 디자인은 **사내판에서는 그대로 유지**합니다(Gap 모드의 존재 이유에는 동의). 사내 호스팅을 정하는 동안의 공개판은 다음 둘 중 하나로 합니다. ① Gap 모드·/gap·커버리지 KPI를 빌드 플래그로 끄기(최소안), ② 공백 타일은 남기되 "본 맵 미등록" 회색 중립 표기에 빨강·KPI 없이 두기.

## I2 계통 정확성 vs 단순화 — **찬성(정정 우선)**
- **동의**: 설계·현장이 지적한 연결 오류(345/154kV TR, 22.9/6.6kV TR, VCB-PF 직렬, 유입TR 2차 ACB, ALTS·LBS 병렬, ATS 부하, 기동기 택1)는 **회사 이름을 단 사이트에서 틀린 계통을 가르치는 것**입니다. 브랜드 리스크로 보면 공백 노출과 같은 급입니다.
- **입장**: 오류 정정 비용은 S~M 수준(설계·현장 평가 기준)인 데 비해 신뢰 효과는 큽니다. "74종 각 1회"는 수단일 뿐 목표가 아니므로 **변압기 등 반복 노드를 허용**합니다. 노드 수 지표는 "기기 종류 74"와 "노드 수"를 나눠 표기합니다.
- **타협선**: 수전반 상세·표준 템플릿 같은 보조 뷰는 P1로 둡니다. 이번에는 메인도의 전기적 성립성만 확보하고, 설계팀 1인 서명 검수(설계 제안 2)를 붙입니다.

## I3 공백의 정의 — **찬성(새 상태 + 근거 필드)**
- **동의**: 설계("LA·MOF·CT/PT·DS는 패널에 타사품을 넣어 공급 — 공백=사업 기회로 단정 불가"), 연구소(evidence·verifiedBy·verifiedAt·confidence 필드).
- **자기 수정**: 1라운드에서 저는 공백 12건 전체를 M&A·제휴 후보처럼 다뤘습니다. 이 가운데 패널 구성품(LA·MOF·CT/PT 4건)은 **"패널 구성품·타사 조달"** 상태로 나눠야, 남는 진짜 전략 공백(발전기·비상발전기·리클로저·APFC·ATS 등)이 의사결정 대상으로 또렷해집니다.
- **타협선**: 상태가 6개로 늘면 범례가 복잡해진다는 UX 우려는 받아들입니다. 메인 범례는 5개로 두고, "타사 조달"은 미보유의 하위 표기(배지 문구)로만 구분해도 됩니다. 근거 필드는 필수로 합니다.

## I4 영업 발표 모드 — **조건부 찬성**
- **동의**: 영업의 `?mode=present`(보유·계열사만 표시, 공백 축약)는 고객 미팅에 실용적입니다.
- **조건**: ① 공개판에서 공백을 끄면 공개판이 곧 발표 모드가 되므로, 별도 모드보다 **I1 분리로 흡수**하는 쪽이 비용이 적습니다. ② "협력 조달/별도 문의" 문구는 I3 검증에서 사실로 확인된 항목에만 씁니다. 확인되지 않은 "공급 가능" 표기는 과장 광고 리스크가 있습니다.
- **정직성 충돌**: 교육판(사내)은 공백을 정직하게 보여 주고, 고객용은 범위를 축약합니다. 둘은 청중이 다를 뿐 모순이 아닙니다.

## I5 교육 품질 — **찬성(HRD 안 지지), 우선순위는 P1**
- **동의**: HRD의 퀴즈·용어 검토 메타(reviewedBy/At)와 "초안" 배지, 투어에서 미확인 공백은 기본 접힘.
- **입장**: 수료 증빙(결과 요약 출력)은 사내 LMS 영역이므로 이 포털에서는 최소한으로 합니다. 퀴즈 검토 전까지 외부 공개판에서 퀴즈를 **"초안" 배지로 명시**하는 것은 P0(마케팅 의견과 같음), 완료 기준 강화는 P1입니다.

## I6 다음 분기 우선순위
- **P0로 볼 것**: 노출 통제(I1), 계통 정정(I2), 공백 근거 필드·검증(I3), 공식 고지/브랜드 검수(마케팅 제안 2).
- **P1**: 단종·후속 모델(현장. 영업·서비스 매출과 직결되어 투자 효과가 큼), 온보딩(UX), 경영 보고 1장 내보내기, 검토된 퀴즈.
- **P2**: 의미적 줌, PWA(현장 수요는 인정하지만 캐시 관리 비용이 큼), 정격 데이터(설계 핵심 요구지만 수집 비용 L, 사양 미수집 상태), 분석·OG.
- **반박**: UX의 "온보딩 P0". 신뢰(정확성·노출) 문제가 남아 있는 상태에서 유입을 늘리면 리스크만 커집니다. 순서는 신뢰 → 유입입니다.

## 내가 꼽는 P0 3개 (전체 관점)
1. **공개/사내 분리 + 공개판 공식 고지**: Gap·공백 표·KPI·CSV는 사내 전용, 공개판에는 "비공식 교육 참고 자료 · 공식 정보는 ls-electric.com" 고지. (임원·마케팅·영업·연구소)
2. **계통 연결 오류 정정 + 설계팀 서명 검수**: "74종 각 1회"를 완화해 반복 노드를 허용합니다. (설계·현장)
3. **공백 판정 근거 필드 + 사업부 검증 스프린트(15건)**: "패널 구성품·타사 조달" 구분 포함. 검증 전에는 "공백 후보"를 유지합니다. (연구소·설계·임원)
