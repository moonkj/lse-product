# 2라운드 — 신입사원(2주차) × HRD 교육 담당자

> 근거: ROUND2.md, round1 8명 평가, 최신 스크린샷 cur/learn.png(L4 단계), `src/content/learn.json`, `equipment-types.json`(learnPoints).
> **1라운드 정정**: p2-equipment 사이드바 깨짐 지적은 옛 스크린샷 문제이므로 **철회**한다. "계층 1/7인데 투어 완료" 화면은 마지막 단계에 URL로 바로 들어간 결과였다. 다만 근본 문제는 그대로다. cur/learn.png를 보면 퀴즈 0/3 상태에서도 "다음: L5 변압"이 활성화되어 있고, 누르기만 하면 그 계층이 완료로 기록된다.

## I1 외부 공개 vs 공백 노출 — **조건부 찬성(분리)**
- **동의**: 임원·마케팅·연구소가 낸 "공개판 = 제품·교육, 사내판 = 공백·전략" 분리안에 동의한다. 교육 기능은 로그인 없이 공개되어 있어야 신입이 집·모바일에서 사전학습을 할 수 있다. 임원도 "교육은 공개 유지 가능"이라고 했다.
- **UX 디자이너의 "강조 유지 + 문구 조정" 안에 대해**: 사내판 Gap 모드에서는 찬성한다. 하지만 **교육 투어는 다르게** 봐야 한다. cur/learn.png의 L4 단계에는 빨간 박스 "이 계층의 공백 — 자사 제품 없음: LA·MOF·CT/PT"가 핵심 기기 카드 바로 아래에 있다. 신입은 이걸 확정된 사실로 외운다.
- **타협선**: 공개판 투어에서는 공백 박스를 뺀다. 사내판 투어에서는 "공백 후보 · 확인 필요"로 표기하고 기본으로 접어 둔다. I3에서 새 상태가 정해지면, 공개판에도 사실로 확인된 "패널 구성품(타사 조달)" 설명만 넣는다.

## I2 정확성 vs 단순화 — **찬성(오류는 모두 수정), 단 복잡도 상한을 둔다**
- **동의**: 현장·설계가 낸 "단순화해도 틀린 연결은 안 된다"에 전적으로 동의한다. 교육 쪽 근거는 이렇다.
  - 투어 L1 intro는 "승압 변압기로 전압을 올린다"고 가르친다. 그런데 계통도에서는 345kV 선로가 변압기 없이 154kV GIS로 들어간다. 신입은 "그럼 154kV는 어디서 생기지?"에서 막힌다.
  - PF 학습 포인트는 "차단기 대신"인데, 계통도는 VCB 뒤에 PF를 직렬로 그린다(설계 지적). 앱이 스스로 모순된 내용을 가르치는 셈이다.
- **반박(현장·연구소가 원하는 범위에 대해)**: 피더 반복(VCB × n), 보호협조 시간, DS·COS·NGR, IEC 심볼, DC·HVDC 하위 노드를 **메인 계통도에** 넣는 것은 반대한다.
- **신입이 감당할 수 있는 선 (제안)**

  | 구분 | 기준 | 어디에 |
  |---|---|---|
  | **반드시 정확(메인)** | ① 전압이 바뀌는 곳에는 반드시 변압기가 있다 ② 전력 경로의 직렬·병렬이 전기적으로 성립한다(VCB-PF 직렬, ALTS-LBS 병렬 투입 금지) ③ 대체 관계는 "택1"로 표기한다(MS·VFD·소프트스타터) ④ 모든 개폐기에는 출력(부하)이 있다(ATS → 비상부하) ⑤ 변압기 2차에는 주차단기가 있다 | 메인 계통도 |
  | **생략 허용(메인)** | 같은 구성의 반복(피더 × n), 보조 부품(DS·COS·NGR·접지), 정정값·TCC, 심볼 표기 | 생략한다. 단, 기기 상세에 "실제로는 피더마다 반복됩니다" 같은 한 줄을 단다 |
  | **보조 뷰** | 수전반 상세(메인 + 피더 VCB × 3, 피더별 CT-OCR, 저압 모선), 보호협조 순서 | L4·L6 "자세히 보기" = 투어 심화 과정 |
  | **수치 상한** | 계층 한 화면 노드 ≤ 15개(지금 L7은 17개), 투어 한 단계 = 핵심 기기 3개 + 새 용어 5개 이하, 메인 노드 증가 ≤ +6 | 전체 |
- **"74종 각 1회" 원칙에 대해**: 재등장을 허용하자. 교육 관점에서는 "전압이 바뀌는 곳마다 변압기가 또 나온다"는 것 자체가 배울 내용이다. 공백 집계가 흔들리지 않도록 재등장 타일은 흐린 "참조 타일"로 그리고 74종 집계에서 뺀다.

## I3 공백의 정의 — **찬성(새 상태 + 근거 필드)**
- **동의**: 설계(LA·MOF·CT/PT는 패널에 타사품을 넣는 구성품이다)와 연구소(`evidence/verifiedBy/verifiedAt/confidence`) 의견에 동의한다. 교육 근거는 이렇다. 신입이 배워야 할 사실은 "수배전반에는 타사 계기가 들어갈 수 있고, 우리는 그 패널을 공급한다"는 사업 구조다. 지금처럼 보이는 "우리는 MOF가 없다"가 아니다.
- **타협선**: 상태 이름과 판정은 사업부가 정한다. 판정이 나기 전까지 교육 화면에서는 해당 내용을 표시하지 않는다.

## I4 영업 발표 모드 — **조건부 찬성**
- **동의**: 영업의 발표 모드(`?mode=present`) 자체에는 동의한다. 화면 하나를 보는 방식(뷰)이 하나 더 생기는 것이라 교육과 충돌하지 않는다.
- **반박**: 확인되지 않은 공백을 "협력 조달"로 **바꿔 부르는 것**은 반대한다. 영업도 "사실 확인 필요"라고 적었다. 또 발표 모드가 교육 탭의 기본 화면이 되어서는 안 된다.
- **타협선**: 발표 모드는 공백을 숨기기만 한다. "협력 조달"이라는 표기는 I3에서 판정이 끝난 항목에만 쓴다.

## I5 교육 품질 — **찬성(내 핵심 쟁점)**
- **동의**:
  - UX: 투어 완료 문구를 진도에 따라 다르게 보여 주자.
  - 마케팅: 검수 전 콘텐츠가 공식 입장처럼 읽힌다.
  - 설계: 검수일·검수자를 표시하자.
- **최소선**:
  - 계층 완료 = 퀴즈를 모두 답한 상태. "다음" 버튼은 막지 않되 "미완료"로 표시한다.
  - 틀린 문제는 다시 풀 수 있게 한다.
  - 퀴즈 20문항·용어 36개 각각에 검토자(부서)와 검토일을 남긴다.
  - intro에서 가르치지 않은 것을 묻는 문항 3개를 고친다(l1-gis-ds, l6-pf, l7-soft).
  - 수료 증빙은 서버 없이 "결과 요약 인쇄/PDF"로 한다.
- **양보**: 마케팅의 "검수 전 외부 공개 반대"는 비공개 전환까지 갈 필요는 없다고 본다. "초안" 배지와 noindex를 달고, 정식 과정 배정은 검토가 끝난 뒤에 하는 선이면 충분하다.
- **의존 관계**: I2의 P0 수정이 끝나기 전에는 이 앱을 신입 정식 과정에 넣지 않는다. 틀린 계통을 수료 요건으로 만들 수는 없다.

## 내가 꼽는 P0 3개 (전체 관점)
1. **계통 연결 오류 수정 + 설계팀 서명 검수**. 위 "반드시 정확" 5개 기준으로 수정하고 재등장 타일을 허용한다. 교육·현장·설계·연구소가 모두 이 위에 서 있다.
2. **공개/사내 노출 정리 + 공백 근거 필드**. 공개판에서는 공백 표·Gap 모드·투어 공백 박스를 숨기고, "공식 정보는 ls-electric.com" 고지를 단다. 15건 판정을 사업부가 확인한다(임원·마케팅·연구소·영업 공통).
3. **교육 콘텐츠 검토와 완료 기준 최소선**. 퀴즈·용어 검토 기록, 퀴즈를 다 풀어야 완료, 오답 다시 풀기, 완료 문구 분기. 이게 갖춰져야 HRD가 정식 과정에 넣을 수 있다.
