# 2라운드 교차 토론 — 마케팅팀 매니저 (B2B 브랜드·콘텐츠)

> 근거: ROUND2.md, round1/ 8명 평가, 최신 스크린샷 cur/product.png 등, CONTEXT.md 리더 정정

## 0. 1라운드 정정
- **철회**: "공백 표·제품 상세 좌측 메뉴 스타일 깨짐(제안 6)"은 작업 도중에 찍힌 옛 스크린샷(p2-*) 때문에 생긴 오판이었다. cur/product.png 를 보면 현재 사이드바는 정상이다. 따라서 문제점 '중간' 항목과 제안 6을 철회한다.
- **대체 근거(외부 완성도)**: cur/product.png 의 "계통 속 위치" 미니 체인에서 오른쪽 VCB 타일이 상자 밖으로 넘친다(리더도 발견). 외부 인상에 영향을 주지만 심각도는 **낮음**, S 규모 수정이다.

## I1. 외부 공개 vs 공백 노출 — **찬성(분리)**
- **동의**: 임원(제안1)의 "공개판은 위치·자료·교육만", 연구소(제안2)의 "Gap 표·KPI·CSV·메모는 사내 전용", 영업(제안3).
- **부분 반박**: UX는 "강조 유지 + 문구만 '공백 후보·확인 필요'"를 제안했다. 이 방식은 **사내판에서는 맞다.** 하지만 공개판에서는 문구를 바꿔도 "빨간 점선 = 이 회사에 없는 것"이라는 시각 메시지가 그대로 남는다. 게다가 근거가 "홈페이지에서 못 찾음"(11건 동일)이라, 회사가 스스로 미확인 약점을 공표하는 셈이 된다.
- **타협선**: 사내 호스팅이 마련되기 전까지는 **공개 빌드에서 Gap 모드·/gap·CSV·커버리지 숫자를 끄고**, 메인 타일의 미보유 표시는 회색 중립 "본 맵 미등록 · 공식 문의"로 바꾼다. 이 방식은 사진 대신 기호만 보이게 되므로 UX가 원하는 '모양 부호화'와도 충돌하지 않는다. 사내판에서는 UX 안을 그대로 쓴다.

## I2. 계통 정확성 vs 단순화 — **찬성(정정 우선)**
- **동의**: 설계·현장의 오류 6건 정정 P0. 외부 공개 사이트에 "LS ELECTRIC" 이름을 걸고 전기적으로 틀린 계통(VCB-PF 직렬, 변압기 없는 전압 변화)을 보여주는 것은 공백 노출과 **같은 급의 브랜드 리스크**다. 기술 회사의 전문성 평판을 직접 깎기 때문이다.
- **입장**: "74종 각 1회"는 내부 설계 원칙일 뿐 브랜드 약속이 아니다. TR처럼 같은 기기가 다시 나오는 것을 허용해도 괜찮다고 본다.
- **타협선**: 노드가 늘어도 메인은 개념도 수준으로 두고, "수전반 상세"(현장 제안2)·"표준 템플릿"(설계 제안4)은 P1 보조 뷰로 미룬다. 단, 보조 뷰의 템플릿 명칭(빌딩/공장/데이터센터)은 공식 솔루션 메시지와 맞추도록 마케팅이 검수한다.

## I3. 공백의 정의 — **찬성(새 상태 + 근거 필드)**
- **동의**: 설계의 "LA·MOF·CT/PT·DS·COS는 원래 패널에 타사품을 넣어 공급하는 구성품이므로 공백=사업 기회로 단정 금지", 연구소의 근거 필드(evidence·verifiedBy·verifiedAt·confidence).
- **마케팅 관점**: 새 상태 "**수배전반에 포함해 공급**"은 외부에도 오히려 **긍정 메시지**다. "단품은 없어도 수배전반 솔루션으로 공급한다"는 뜻이 되기 때문이다. 다만 이 문구를 쓰려면 사실 확인(설계·구매)이 끝나야 한다. 확인 전에는 쓰지 않는다.
- **타협선**: 공개판에는 confidence가 "확정"인 항목만 상태를 표기한다. 나머지는 중립 표기로 둔다.

## I4. 영업 발표 모드 — **조건부 찬성**
- **동의**: 영업의 `?mode=present`. 고객 앞에서 공백을 빨갛게 띄우지 않는 것은 브랜드에도 이득이다.
- **반박**: "협력 조달/별도 문의" 표기를 근거 없이 쓰면 과장 표현이 되어 정직성 문제가 생긴다(신입·연구소 우려에 동의).
- **조건**: ① I1에서 공개판이 기본적으로 중립이라면, 발표 모드는 별도 기능이 아니라 **공개판 = 발표 모드**로 합쳐 개발량을 줄인다. ② 표기 문구는 I3의 확인된 상태에서만 자동으로 만들어지게 하고, 수작업 미화 문구는 금지한다. ③ 업종·패키지 명칭은 마케팅이 검수한다.

## I5. 교육 품질 — **찬성(검토 전 '초안' 배지)**
- **동의**: 신입(HRD) 제안1·2. 외부에 공개된 퀴즈의 오답은 "LS ELECTRIC 공식 교육 내용"처럼 읽힌다. 검토 전 콘텐츠에는 "초안" 배지와 "공식 정보는 ls-electric.com" 고지가 필요하다.
- **투어 공백 노출**: I1과 같은 원칙을 적용한다. 공개판 투어에서는 미확인 공백을 감춘다.
- **양보**: 완료 기준·수료 증빙(P1)은 HRD 판단에 맡긴다. 다만 수료 출력물에 로고를 넣을 경우 CI 규정을 따른다.

## I6. 다음 분기 우선순위 — OG/브랜드는 **P0 일부만**
- OG 태그·파비콘·robots 설정과 "비공식/교육용 고지"는 S 규모라 공개 직후 바로 해야 한다. 공유 링크가 빈 카드로 퍼지는 것은 막아야 한다. 단, 공개 범위가 사내 전용으로 정해지면 robots는 noindex로 둔다.
- 전체 CI 리뉴얼과 브랜드군(Susol·Metasol·GIPAM) 묶음 표기는 P1로 양보한다.
- 분석 도입은 P1. 홈페이지 유입("공식 제품 페이지 ↗" 클릭) 측정은 사내판·공개판 결정 이후에 한다.
- 온보딩·의미적 줌(UX)·PWA(현장)는 P1~P2로 본다. 정격·단종(설계·현장·연구소)은 P1이다. 단종 제품을 "판매 중"으로 오표시하는 건은 외부 오정보이므로 확인된 건부터 우선 반영한다.

## 내가 꼽는 P0 3개 (전체 관점)
1. **공개판/사내판 분리**: 공개판에서는 Gap 모드·공백 표·KPI·CSV를 끄고 미보유를 중립 표기한다(임원·영업·연구소·마케팅 합의, UX 안은 사내판에 적용).
2. **계통 연결 오류 6건 정정 + 설계팀 검수 표기**(설계·현장 제안). 외부에 틀린 기술을 보여주는 것은 기술 브랜드에 치명적이다.
3. **공백 근거 필드와 "수배전반에 포함해 공급" 상태 도입 + 공개 고지·OG 기본 세트**(연구소·설계 제안 + 마케팅 S 작업). 미확인 정보를 '확정'처럼 보이게 하지 않는 최소 장치다.
