# B8 윤미래 — 2라운드 (영업 실무자, 가상 인물)

## 1) 동의하는 기능
- **B2 기기별 구매 방식 카드**: 단가계약인지, 일반경쟁인지, 중소기업자간 경쟁제품인지가 영업에서 가장 먼저 걸러야 할 정보입니다. 제 1라운드 '시장 동향' 카드에 한 줄로 합치면 좋겠습니다.
- **B7·B10 프로젝트 유형별 기기 목록·프리셋 + B10 미보유 공백 경고**: 고객 미팅에서는 "데이터센터면 이 기기들이 들어간다"는 말이 바로 통합니다. UPS·비상발전기 같은 미보유 칸은 숨기지 않아야 패키지 영업 리스크를 미리 알 수 있습니다.
- **B3 송변전 프로젝트 파이프라인(기기 태그 포함)**: 한전 담당 영업이 1~3년 앞을 내다볼 때 쓰는 근거입니다. 다만 공고 실적과 나란히 보여야 합니다.
- **B9 숫자 메타데이터 강제(source·asof·kind)**: 미팅 자료에 출처 없는 숫자가 들어가면 신뢰를 잃습니다. 모든 카드에 공통으로 적용하는 데 찬성합니다.

## 2) 반대·수정
- **B6 공백 매트릭스의 버블 크기=시장규모(TAM)**: 기기 단위 TAM은 공개 근거가 약합니다. B6 스스로도 UPS 사례에서 보고서 간 편차가 크다고 적었습니다. 절충안은 버블 크기를 **공개 공고 건수(최근 4분기)**로 대신하고, TAM은 범위값으로 ⓘ 안에만 두는 것입니다.
- **B3·B4 수요 환산·추정기를 기기 카드에 노출**: 영업이 이 숫자를 고객 앞에서 쓰면 "LS가 발주 물량을 예측한다"는 오해와 입찰 공정성 논란이 생길 수 있습니다(B3 자신도 지적함). 절충안은 기기 카드에는 방향(↑↑/↑)만 두고, 환산 숫자는 내부용 A4에 "추정" 배지와 가정을 함께 싣는 것입니다.
- **B1 계획 물량 레이어 단독 P0**: 계획 물량과 실제 발주는 다릅니다(B1·B2 모두 인정). **계획 대비 실제 공고 건수**를 함께 보여주는 조건이라면 P0에 동의합니다.

## 3) 쟁점 입장
- (a) **프로젝트 단위 실무 정보를 먼저** 보여줘야 합니다. 첫 화면은 기존 계통도에 공고·조달 배지를 얹는 형태로 하고, 거시 차트는 접힌 패널(P1)로 둡니다.
- (b) **지표별 신호등만** 둡니다(B9와 동의). 하나로 합친 점수는 고객 앞에서 근거를 설명하기 어렵습니다. 정렬이 필요하면 사용자가 지표 하나를 골라 정렬하게 합니다.
- (c) 추정치는 **기기 카드에 노출하지 않습니다.** 범위값·가정·"추정" 배지를 붙여 A4·ⓘ 안에만 둡니다. 공식 통계와 공식 전망은 그대로 보여줍니다.
- (d) **기존 계통도·기기 상세에 레이어·카드로 얹습니다.** 별도 '시장' 화면은 만들지 않거나, 만들더라도 거시 패널 하나로 최소화합니다. 기존 요소를 바꾸는 일은 사용자 확인을 받은 뒤 진행합니다.
- (e) **대시보드는 원본(공고·뉴스·공시 목록)**, **제품맵은 기기 id별 요약과 링크**를 맡습니다. 키워드→기기 매핑 규칙은 두 사이트가 같은 파일 하나로 관리하고, 대시보드 빌드 산출 JSON을 제품맵 Actions가 받아 씁니다(별도 수집기를 새로 만들지 않음).

## 4) 최종 P0 3개
1. **공고→기기 연결 + 기기 상세 '시장 동향' 카드**(B8): B2의 구매 방식 한 줄을 합칩니다. 나라장터·한전 공개 API 기준입니다.
2. **프로젝트 유형별 기기 목록 + 미보유 공백 경고**(B7·B10 통합)
3. **송변전 프로젝트 파이프라인 × 커버리지 겹쳐 보기**(B3 1·5번): 공고 실적을 함께 보여줍니다. 계획 수치는 제11차 장기 송변전설비계획(한전, 2025.5) 기준이며, 사업별 일정은 "확인 필요"로 표시합니다.
