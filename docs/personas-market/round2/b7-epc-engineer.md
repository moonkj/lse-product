# B7 오세훈 — 2라운드 (EPC·설계 실무자, 가상 인물)

## 1) 동의하는 기능
- **B10 수요처 유형별 표준 계통 프리셋 + 공백 경고(빨간 테두리)**: 1라운드 내 BOM 골격 제안과 같은 내용입니다. "필수·이중화·선택" 3단 표시는 사양서를 쓰는 순서와 맞아서 B10 안으로 합치는 데 찬성합니다.
- **B9 공급 병목 보드**: 리드타임에 "2차 인용(확인 필요)" 배지를 달고 기준일을 표시하는 방식에 찬성합니다(美 대형 변압기 약 128주, Wood Mackenzie 2025 2분기, 2차 인용). 다만 위치는 기기 상세 카드여야 합니다.
- **B8 기기 상세 '시장 동향' 카드 + 공고→기기 매핑**: 대시보드 JSON을 재사용하고, 제품맵에는 요약과 링크만 둡니다. 운영 비용이 가장 적게 듭니다.
- **B3 커버리지 × 파이프라인 겹쳐 보기**: 미보유 칸을 숨기지 않는 원칙에 동의합니다.

## 2) 반대·수정
- **B6 공백 매트릭스 버블(P0) → P1으로 낮추고 신뢰도 필터를 필수로**: B6 스스로도 공백 14개 중 13개가 "확인 필요"라고 밝혔습니다. 근거가 약한 채 시장규모 버블을 첫 화면에 띄우면 설계자는 도구 전체를 믿지 않게 됩니다. 절충안: 확정된 항목만 버블로 그리고, 나머지는 회색 목록으로 둡니다.
- **B3 기기별 수요 환산표, B4 시장 규모 추정기**: "변전소 1곳 ≈ GIS n베이"는 설계마다 2배 이상 차이 납니다(경험상 추정·확인 필요). 절충안: 환산 규칙은 공개하고, 화면에는 개수 대신 범위와 방향(↑↑/↑)만 표시합니다.
- **B9 5지표 패널을 첫 화면에 두는 안**: 전력시장 지표는 중요하지만 실무 판단에는 바로 쓰이지 않습니다. 기능은 유지하되 별도 섹션으로 둡니다.

## 3) 쟁점 입장
- **(a)** 첫 화면은 **프로젝트 단위 실무 정보**로 합니다. 유형 선택 → 계통도 강조 → 조달·규격 배지 순서입니다. 거시 차트는 두 번째 단계입니다.
- **(b)** **지표별 신호등만** 씁니다. 가중합 점수는 가중치를 누가 정하느냐는 논쟁만 낳고, 점수 하나만 따로 퍼져 나갑니다. 꼭 필요하면 정렬용으로만 숨겨서 씁니다.
- **(c)** 화면에 보이는 숫자는 공식 통계·공식 계획으로 한정합니다. TAM이나 기기 수요 환산 같은 추정치는 펼침 영역에 두고, "추정" 배지와 가정 공개를 필수로 합니다. A4 인쇄에는 넣지 않습니다.
- **(d)** **기존 계통도와 기기 상세 위에 레이어·카드로 얹습니다.** 다만 시계열 차트(수급, 전원믹스, 송변전 파이프라인)는 시간축이 달라서 접힌 "시장" 섹션 하나로 묶습니다. 어느 쪽이든 화면 변경은 사용자 확인이 필요합니다.
- **(e)** 마켓뉴스 대시보드는 **원본 목록**(뉴스·입찰·공시·주가)을 맡고, 제품맵은 **기기 id 기준 요약 + 링크**를 맡습니다. 매핑 규칙 파일은 하나로 같이 씁니다(B8 안).

## 4) 최종 P0 3개
1. **유형별 프리셋 + 필수 기기 공백 경고**(B10, B7 BOM 골격 통합) — CSV·A4 출력 포함
2. **기기 카드 신호 배지**: 조달 난이도(B9 병목 보드 + B7 신호등) + KEC·기술기준 개정 알림(B7). 시행일과 경과조치를 표시하고 출처와 기준일을 필수로 답니다.
3. **기기 상세 '시장 동향' 카드**(B8): 공고·뉴스 요약, 대시보드 데이터 재사용
