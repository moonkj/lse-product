# B5 정다은 (재생에너지·ESS IPP 임원, 가상 인물) — 2라운드

## 1) 동의하는 기능
- **B1 #3 재생에너지 연계 압력계**: 내 1라운드 제안 #1(SMP·REC 수익 신호판)·#2(출력제어)·#5(보급목표 진척)와 같은 흐름이다. 셋을 하나로 합쳐 REN 계층 머리줄에 붙이자. 11차 전기본의 출력제어율 상향(B1 인용, 원문 확인 필요)도 같은 줄에 둔다.
- **B8 #1·#2 기기 상세 '시장 동향' 카드 + 공고→기기 매핑**: 내 #3(입찰 트래커)이 여기에 들어간다. ESS 중앙계약시장 공고는 "ESS·PCS" 키워드로 `ess`·`pcs`에 바로 연결된다.
- **B9 출처 메타 규칙**(`source`·`asof`·`kind`, 빠지면 빌드 실패): SMP·REC·출력제어 수치는 블로그 2차 집계가 섞이기 쉽다. 이 규칙이 없으면 내 지표도 믿고 쓸 수 없다.
- **B7 #3 규격 변경 알림**: KEC 개정이 `pv`·`dc-devices`에 걸린다. 사업자 입장에서는 시행일이 곧 설비를 교체할 시점이다.

## 2) 반대·수정
- **B6 #1 공백 버블의 시장규모(원)와 B4 #4 추정기의 사용자 입력 계수 → 수정**: 계수 한 번 바꾸면 "몇 조" 숫자가 근거 없이 퍼져 나간다. 절충안: 버블 크기는 범위·상대 순위로만 그리고, 계수 입력은 화면에서 빼고 내부 문서에만 둔다.
- **B3 #2 기기별 수요 환산표 → P2로 내림**: 재생에너지 쪽은 프로젝트 1건당 PCS·변압기 수가 설계에 따라 크게 달라진다. 가정을 공개하고 접힌 상태로 둔다면 허용한다.
- **내 1라운드 '시장 온도' 가중 점수 → 철회**: B9 의견을 받아들인다. 가중치를 정할 근거가 없다.

## 3) 쟁점 입장
- (a) **실무 정보 먼저.** IPP 판단은 "이 지역에 붙일 수 있나, 다음 입찰이 언제인가"라는 프로젝트 단위 질문이다. 거시 지표는 계층 머리줄 한 줄과 기기 카드 배지로 줄인다.
- (b) **지표별 신호등(↑→↓)만 둔다.** 정렬 기준은 사용자가 고르게 한다.
- (c) 기본으로 보여 줄 것은 **실적과 공식 전망까지**다. 기기 수요 환산은 범위와 가정을 함께 보이되 접힌 상태로 두고, 원 단위 TAM은 화면에 두지 않는다. 2차 인용 수치에는 "확인 필요" 배지를 단다.
- (d) **별도 화면은 만들지 않고 레이어·카드로 얹는다.** 연간 요약은 기존 A4 인쇄를 확장해서 해결한다. 화면 형태를 바꾸는 일은 사용자 확인을 받은 뒤 진행한다.
- (e) **원문(뉴스·입찰 목록·주가)은 마켓뉴스 대시보드에 둔다.** 제품맵은 기기 id 단위 요약과 링크만 맡는다. 매핑 규칙 파일은 B8 제안대로 하나로 같이 쓴다. KPX 계열 시계열(수급·SMP)은 제품맵 Actions가 이미 진행 중인 수집에 묶고, 대시보드는 그 결과를 링크한다.

## 4) 최종 P0 3개
1. **기기 상세 시장 동향 카드 + 공고→기기 매핑** (B8 #1·#2, 내 #3 흡수)
2. **REN 연계 압력계** (B1 #3 + 내 #1·#2·#5): 목표 대비 실적, SMP·REC, 출력제어를 신호등으로
3. **출처·기준일·실적/전망 구분 메타 규칙** (B9): 모든 시장 데이터의 공통 기반
