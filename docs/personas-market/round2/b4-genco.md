# B4 박영진 (발전공기업 기술본부장, 가상 인물) — 2라운드

## 1) 동의하는 기능
- **B3 #1 송변전 프로젝트 파이프라인 + #5 커버리지 겹쳐 보기**: 내 "발전소 전환 일정표"와 같은 구조(사업 막대 → 기기 태그)다. 발전(석탄→LNG·양수, 신규 원전)과 송변전을 **하나의 파이프라인**으로 합치자고 제안한다.
- **B9 #1 연간 5지표 패널과 신뢰도 배지 3단계**: 내 "전원믹스 궤적"은 이 패널의 설비용량(원별) 지표로 흡수한다. `source·asof·kind` 필드를 강제하자는 제안에 찬성한다.
- **B1 #4 / B3 #3 계획 차수 비교**: 11차→12차 사이에 원전·SMR·석탄 목표가 계속 바뀌고 있다(12차는 수립 중, 확인 필요). 차수 비교 없이 계획값만 보여 주면 오판한다.
- **B8 #1 기기 상세 '시장 동향' 카드**: 대시보드 JSON을 재사용하므로 비용이 가장 적게 든다.

## 2) 반대·수정
- **B6 #1 버블 크기 = 시장규모(TAM), 매력도 가중 점수** → 반대. 공개 단가가 없어 버블 크기 자체가 지어낸 값이 된다. **절충**: 버블 크기는 물량(GW·개소, 출처 있는 값)으로 하고, 금액은 A4 내부용 범위 표기로만 둔다.
- **B6 "발전기 = 포기 후보"** → 수정. 발전기 자체는 동의한다. 다만 발전소 소내 배전(특고압반·MCC·고압 인버터)과 SCADA는 보유 기기다. 발전 계층 전체를 포기하는 것처럼 읽히지 않도록, 발전기 하나만 "범위 밖"으로 표시하자.
- **내 #4 시장 규모 추정기 / B3 #2 수요 환산표** → 스스로 축소한다. 환산 규칙(가정)만 공개하고, 기기 수량은 "추정" 배지와 함께 범위로만 보여 준다. 금액 합계는 기본 화면에 띄우지 않는다.

## 3) 쟁점 입장
- (a) **프로젝트 단위를 먼저.** 발전사도 "호기" 단위로 움직인다. 첫 화면은 기존 계통도에 계층 배지(향후 신설·전환 GW, 진행 중 사업 수)만 얹고, 거시 차트는 한 번 클릭해서 여는 구조로 한다.
- (b) **신호등만 둔다**(B9 입장). 지표 사이의 공통 축은 "확정도 단계"(정책 발표 → 계획 반영 → 계약·착공) 하나만 허용한다.
- (c) 물량(GW·개소·베이)은 "추정" 배지를 달아 노출한다. TAM 금액은 기본 화면에 띄우지 않는다.
- (d) **별도 탭은 만들지 않는다.** 계통도 레이어와 기기 카드로 얹고, 거시 패널은 접히는 서랍 하나로 둔다. 화면 변경은 사용자 확인을 받는다.
- (e) 마켓뉴스 대시보드는 원본 흐름(뉴스·입찰·공시 목록, 일 단위)을 맡고, 제품맵은 기기별 요약과 계획 구조(연·분기)와 링크를 맡는다. 키워드↔기기 매핑 파일은 두 사이트가 하나를 공유한다(B8 안).

## 4) 최종 P0 3개
1. **통합 프로젝트 파이프라인**(B3 #1 + B4 전환 일정표, 커버리지 겹침과 차수 비교 배지 포함)
2. **연간 전력시장 5지표 패널**(B9 #1, 원별 설비용량을 전원믹스 궤적으로 표시, 신뢰도 배지)
3. **기기 상세 시장 동향 카드**(B8 #1, 대시보드 데이터 재사용)

> 수치 근거는 1라운드 출처와 같다(11차 전기본 2025.2 확정, 12차는 확인 필요).
