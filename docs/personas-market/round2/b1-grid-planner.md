# B1 최정훈 (전력계통 계획) — 2라운드

## 1) 동의하는 기능
- **B3 송변전 프로젝트 파이프라인 + 일정 변동 로그**: 제 ①계획 물량 레이어·④차수 비교와 같은 방향. 합쳐서 하나로 만들고 "계획 기반 설비 소요" 표현(B3)을 따릅니다.
- **B3 커버리지 × 파이프라인 / B10 공백 경고**: 계획 물량에 미보유 칸(L1 피뢰기·초고압 CT/PT, L3 리클로저·주상변압기)을 겹치는 것이 이 기능의 핵심 가치입니다.
- **B5 입찰 일정·결과 트래커(ESS 중앙계약시장 등)**: 재생e 연계 압력을 실제 발주로 바꿔 주는 가장 단단한 신호입니다. 제 ③압력계는 이 트래커 헤더로 흡수합니다.
- **B9 출처 스키마(source·asof·kind·method 강제, 빌드 실패)**: 계획값·실적·2차 인용이 섞이는 사고를 막는 전제 조건입니다.

## 2) 반대·수정
- **B6 계층별 기회 막대(TAM)를 P0로 두는 것**: 반대합니다. 기기 단가 공개 자료가 없어 금액은 대부분 추정이 됩니다. 절충안은 P0를 물량(C-km·개소·MVA·MW) 막대로 하고, 금액은 계획서에 명시된 전압별 투자비(10차 345kV 21.3조 등)만 쓰는 것입니다.
- **B3·B4 확정도 가중치(0.3/0.6/0.9, 1.0/0.6/0.3)**: 서로 값이 다릅니다. 하나의 단계 정의(정책 발표 → 계획 반영 → 입지 확정 → 착공)로 통일하고, 가중치 대신 단계 배지로 보여 줍니다.
- **B2·B5 접속 여력 지도(P1)**: 한전 접속 가능 용량은 공개 범위·형식이 불안정합니다(확인 필요). 자동 수집이 아니라 수동 분기 갱신 P2로 낮추자고 봅니다.

## 3) 쟁점 입장
- (a) **실무 먼저.** 첫 화면은 기존 계통도에 프로젝트·계획 신호를 겹친 화면으로 하고, 거시 차트(B9 5지표)는 접힌 섹션에 둡니다. 다만 송변전 계획 레이어는 임원과 실무가 함께 쓰는 공통 축입니다.
- (b) **신호등.** B9과 같은 입장입니다. 제가 1라운드에 낸 가중합 점수는 철회합니다. 지표별로 확정도·증가율·커버리지·지연위험을 ↑→↓로 보여 주고, 정렬만 사용자가 고르게 합니다.
- (c) **추정치는 기기 상세 안에서만**, "추정" 배지와 가정 공개를 붙여 보여 줍니다(B3 환산표 방식). 계통도 전체 화면과 A4 첫 장에는 공식 수치만 둡니다.
- (d) **별도 화면을 만들지 않습니다.** 계통도 계층 옆의 레이어 토글과 기기 상세 카드로 얹습니다. 기존 화면 형태가 바뀌면 사용자 확인을 거칩니다.
- (e) **마켓뉴스 = 원본 목록**(뉴스·공고·주가, 하루 2회), **제품맵 = 기기·계층 단위 요약과 링크**(B8 안). 계획서 기반 연·분기 데이터는 제품맵이 직접 관리합니다.

## 4) 최종 P0 3개
1. **계획 파이프라인 레이어**(B3 + B1 통합): 11차 송변전계획 물량·사업 일정·차수 diff를 L1~L3에 겹침. 예: HVDC 선로 492→3,818C-km(한전 2025.5).
2. **커버리지 × 수요 공백 강조**(B3·B10·B6 공통): 계획·프로젝트 수요가 있는데 자사가 미보유·일부 보유인 칸. 판정 신뢰도 배지 포함(B6 지적처럼 13건은 "확인 필요" 상태).
3. **기기 상세 '시장 신호' 카드**(B8 + B5 입찰 트래커): 관련 공고·입찰 MW·계획 반영 여부를 출처·기준일과 함께. 데이터는 마켓뉴스 JSON 재사용.

※ 전력망특별법 시행·개정 일자는 B3·B5 기재가 서로 달라 원문 확인 필요.
