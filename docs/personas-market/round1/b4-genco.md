# B4 박영진 — 발전공기업 기술본부장 (가상 인물)

> 관점: 전원믹스 변화 → 발전소 폐지·전환·신설 → 그때 필요한 전기설비. 수치는 출처를 달거나 "추정·확인 필요"로 표시.

## ① 핵심 질문
1. 앞으로 10년간 **어느 발전원이 몇 GW 늘고 몇 GW 줄어드나?** 11차 전기본(2025.2 확정, 2024~2038)에는 2038년 무탄소 비중 70.7%, 신규 대형 원전 2기(2037·2038, 각 1.4GW), SMR 1기가 들어 있다(보도 기준. SMR 반영 여부는 보도마다 달라 원문 확인 필요). 석탄은 노후 28기를 LNG로 전환(14.1GW, 2024~2036)하고, 12기는 양수·수소·암모니아로 전환한다. 정부는 이후 "2040년까지 석탄 40기 폐지"로 앞당겼다(2025 COP30 발표 보도). 12차 전기본은 수립 중이라 확정 수치를 확인해야 한다.
2. 석탄 1기를 LNG로 바꿀 때 **전기설비는 무엇을 교체하고 무엇을 재사용하나?** (주변압기·GIS·소내 배전·보호계전)
3. 원전 수출(체코 두코바니 5·6호기, APR1000 2기, 2025.6 본계약, 착공 목표 2029)과 SMR에서 **LS ELECTRIC 제품이 들어갈 자리는 어디인가?**
4. 지금 제품맵의 **L1 발전 구간이 발전소 내부를 담고 있나?** 발전기(미보유)와 승압변압기(345/765kV 공급 범위 확인 필요)뿐이다. **발전기 차단기(GCB)·소내변압기·발전기 보호·여자 설비**는 76종 기기 목록에 없다.

## ③ "미래 유망 시장" 판단 기준
- **확정도 가중 GW**: 확정 사업(인허가·계약) 1.0, 전기본 반영 0.6, 정책 발표만 0.3을 곱한다. 가중치는 예시이며 토론으로 합의해야 한다.
- **기기 침투 가능성**: 해당 전환 패키지에서 자사 보유·일부 보유 기기가 차지하는 비중(건수 기준. 금액 가중은 추정).
- **발주 시점 선행성**: 상업운전 연도 −3~5년(전기설비 발주 시점)으로 당겨서 표시한다. 리드타임은 추정·확인 필요.
- **진입장벽 표시**: 원전 안전등급(Q-class) 여부, 송전급 보호계전 납품 실적 요건을 표시한다. 장벽이 높으면 "유망하지만 지금 바로 들어가긴 어려움"으로 분리한다.

## ④ 화면 배치
```
[발전 계층 L1 클릭] ─┬─ 좌: 전원믹스 궤적(실적 실선 / 계획 점선)
                     ├─ 중: 전환 일정표(호기별 막대, 발주 예상 시점 마커)
                     └─ 우: 선택한 전환 형태의 설비 패키지 → 기기 칩(커버리지 색) → 기존 기기 카드로 이동
```
계통도 L1 위에 "향후 10년 신설·전환 GW" 배지만 덧붙이고, 기존 화면 요소는 바꾸지 않는다(바꿀 경우 사전 확인).

## ⑤ 리스크·반론 예상
1. **시장 규모 숫자 남용**: 영업 페르소나는 "몇 조 원"이라는 한 줄을 원하지만, GW당 설비비는 공개 출처가 거의 없다. 기본값을 비워 두는 것이 원칙이고, 이 점에서 부딪힐 것이다.
2. **정책 변동성**: 11차와 12차 사이에 원전·석탄 목표가 계속 바뀐다. 계통 전문가는 "계획은 바뀌니 실적만 보라"고 반론할 수 있다. 그래서 계획 버전을 비교하는 토글(11차 대 12차)이 필요하다.
3. **범위 확장 논란**: 발전소 소내 기기 추가는 "제품맵은 LS ELECTRIC 계통도"라는 원칙과 충돌할 수 있다. 미보유 기기만 늘어나 공백이 커 보이는 부작용도 있다. 대안은 별도 행을 접힌 상태로 두는 것이다.
