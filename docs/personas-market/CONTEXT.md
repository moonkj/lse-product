# 전력시장·사업 전문가 10인 토론 — 제품맵 × 전력시장 분석 기능 (2026-11-19)

## 사용자 요청
"페르소나 10명 추가 투입해서 (전력계통 전문가, 한전 임원, 전력기업 임원, 실무자 등등) 제품과 연동하여 연간 전력시장 분석이라던지, LS ELECTRIC 제품이 이 전력시장에 어떻게 연계되어 미래에 어떤 시장이 더 나은지 분석까지 보여주는 기능 등을 토론을 통해 방안 더해줘"
- **수정하지 말고 방안만.** 기능 제안 + 토론 내용.

## 운영 제약 (제안에 반영)
- 정적 사이트(GitHub Pages) + GitHub Actions 주기 수집. 서버·DB 없음. 비밀키는 Actions Secret.
- **공개 정보만.** 전력거래소(KPX)·EPSIS 전력통계정보시스템·한전 전력통계속보·전력수급기본계획(정부)·공공데이터포털·DART 공시 등. 로그인·유료 데이터 전제 금지.
- 교육용 포털이 아님(교육 탭·학습·신입 문구 금지). 실무 의사결정 도구.
- ls-electric.com 을 직접 접속하지 말 것(수집 규칙 별도). 일반 웹 검색은 가능.
- **숫자는 출처(기관·자료명·연도)를 달거나 "추정·확인 필요"로 표시.** 지어낸 수치 금지.
