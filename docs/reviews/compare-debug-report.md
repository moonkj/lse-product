## 높음

### H1. 계통도 데스크톱 폭 901~1100px에서 비교 바가 좁은 세로 막대로 찌그러짐
- 파일: `src/components/compare/Compare.css:59-61`
  ```css
  .app-shell--home .cmp-tray { max-width: min(760px, calc(100vw - var(--nav-w) - var(--panel-w) - 260px)); }
  ```
- 재현: 담기 3개 이상 + `/#/?node=n-vcb`, 창 폭 920 / 1024 / 1280.
  - 실측 바 크기: 920px → **100×316** ("기기 3"·"모두 비우기"가 한 글자씩 세로로 쪼개짐), 1024px → 204×222, 1280px → 460×178, 1440px → 620×100.
  - 원인 확인(가설 2개 검증): ① max-width 계산값이 `100vw − 200 − 360 − 260` = 920px에서 100, 1024px에서 204로 실측 폭과 정확히 같음 → 원인 맞음. ② flex-wrap·칩 최대 폭 때문이라는 가설 → 계통도 밖 화면(같은 폭)에서는 688~760px로 정상이라 아님.
  - 901px에서는 81px까지 줄어듦. 미니맵·패널과 겹치지는 않음(겹침 검사 false). 대신 바 높이가 커져 계통도 왼쪽 아래를 최대 316px 가림.
- 제안: 폭에 하한을 두고(`max(320px, …)`), 공간이 모자라면 칩 목록을 접어 "기기 3/4 · 비교하기"만 한 줄로 보이게. 또는 ≤1100px에서는 미니맵 위로 올리는 배치.

## 중간

### M1. 다른 탭에서 담으면 목록이 덮어써져 사라짐 (storage 이벤트 미구독)
- 파일: `src/store/useCompareStore.ts:42-55` (`save`가 메모리 상태 전체를 덮어씀, `storage` 이벤트 구독 없음)
- 재현: 탭 A `/equipment/vcb`, 탭 B `/equipment/acb` 열기 → A에서 VCB 담기 → B에서 ACB 담기 → localStorage = `{"equipment":["acb"]}`. A를 새로고침하면 VCB가 없어짐. A의 화면은 계속 VCB만 보여 두 탭이 서로 다른 목록.
- 원인 확인: ① 이벤트를 구독하지 않아 B의 메모리가 오래된 값 → 맞음(B 화면에 VCB 없음). ② 저장할 때 합치지 않고 통째로 씀 → 맞음(저장값에 A 항목 없음).
- 제안: `window.addEventListener('storage', e => e.key === STORAGE_KEY && set(load()))`. 저장 직전에 load()로 다시 읽어 합치는 방법도 가능.

### M2. 모바일에서 비교 바가 페이지 마지막 링크를 가림
- 파일: `src/components/compare/Compare.css:154` (`padding-bottom: 140px`)
- 재현(390×844, 기기 3 + 제품 2 담기): 끝까지 스크롤해도 `/equipment/vcb` "교육 투어에서 이 계층 배우기 →", `/product/P01062` "원자력 발전소용 VCB" 링크가 바 아래에 깔림. 바 높이 174px + 아래 여백 8px = 182px인데 확보한 여백은 140px.
- 원인 확인: ① 여백 부족 → 맞음(계산값 140px, 실측 바 174px). ② 여백이 엉뚱한 요소에 적용됨 → 아님(`.pg`에 140px 적용 확인). 데스크톱(바 100px, 여백 96px)에서는 가려지는 요소 0.
- 제안: 바 높이를 CSS 변수나 ResizeObserver로 재서 여백에 반영. 아니면 모바일에서는 바를 한 줄로 접기(칩 숨김, "기기 3/4 · 비교하기"만).

### M3. "차이만 보기"가 표기만 다른 같은 값을 '차이'로 판정함
- 파일: `src/pages/ComparePage.tsx:519` (`c.text === r.cells[0].text` 문자열 그대로 비교), `:384`
- 재현:
  - `/#/compare?type=product&ids=P01062,P01064` 차이만 보기 → 정격주파수 "50 / 60 Hz" vs "50/60 Hz"가 차이 행으로 남음.
  - `ids=P01021,P01900` → 극수 "3 / 4 P" vs "3, 4 P".
- 데이터 근거: 같은 의미를 여러 표기로 씀. 주파수 `50/60`·`50 / 60`·`60, 50`, 극수 `3 / 4`·`3, 4`, 전압 단위 `V`·`V AC`·`Vac`·`VAC` (L11).
- 제안: 비교용 text만 정규화(공백 제거, `,`→`/`, 단위 대소문자·`AC` 통일). 화면 표기는 그대로 둠. 근본적으로는 데이터 표기 규칙을 정하고 specs.json 정리.

### M4. 단위가 괄호 주석 뒤에 붙어 읽기 어려움 (229개 중 45개)
- 파일: `src/lib/pages/compare.ts:57` (`${value} ${unit}`)
- 예: `110 (55~125) (PT 입력) V`, `5 (CT 입력) A`, `0.03/0.1/0.3/0.5 (또는 0.1/0.2/0.5/1) A`, `690 (18·22AF) / 1000 (40AF 이상) (Ue) V`, `0.05~6 (5A), 0.01~1.2 (1A) A`. 화면에서 "(PT 입력) V"처럼 단위가 주석에 붙어 보임 (prod-dark.png에서 확인).
- 제안: 값과 주석을 나누는 필드(`note`)를 두거나, 표시할 때 첫 괄호 앞에 단위를 넣기. 아니면 데이터에서 단위를 값 안 숫자 바로 뒤로 옮기기.

### M5. 긴 비교 표에서 열 머리글이 고정되지 않음
- 파일: `src/pages/ComparePage.tsx:587-618`, `src/pages/ComparePage.css` (thead에 sticky 없음. 그리고 `.cmp-scroll`이 overflow-x 스크롤 박스라 세로 sticky가 걸리지 않음)

- 기기 대표 사양 셀: 소속 제품마다 "제품명: 값 p.N"을 나열해 4~5줄이 됨(MCCB·VFD 행 222~281px).
- 제안: 표 위에 고정되는 열 이름 띠(스크롤 동기화)를 두거나, 표에 max-height를 주고 내부 세로 스크롤 + thead sticky. 기기 비교는 범위 요약 한 줄 + "제품별 보기" 펼치기.

### M6. specs.json이 첫 화면 번들에 들어가고, 검증에 실패하면 앱 전체가 멈춤
- 파일: `src/data/load.ts:23` (정적 import), `:66` (`parseOrThrow(SpecsFileSchema…)`)
- 측정: 데이터 청크 gzip 89.07 → 95.36 kB (+6.29 kB, 원본 +32 kB). specs.json은 비교 화면에서만 쓰는데 계통도 첫 로딩에 포함됨. 사양 값 1건이 형식 오류여도(예: page 0, 빈 value) RootErrorBoundary가 떠서 계통도까지 못 씀. 사양은 검수 전(reviewed=false) 데이터라 오류 가능성이 더 높음.
- 제안: specs를 ComparePage 안에서 동적 import(또는 `lib/pages/compare.ts`에서 지연 로드)하고, 실패하면 비교 화면에만 "사양 불러오기 실패"를 표시.

### M7. 사양 값과 인용 페이지가 맞지 않음 (데이터)
- 범위 값의 최소·최대가 서로 다른 페이지에 있는데 한 페이지만 적은 항목 7건: P01021 정격전류 60~400 (60은 p2, 400은 p3), P01260 프레임 18~2650 (18AF는 p6, 인용은 p13), P01260 과부하 0.1~800 (0.1은 p6, 인용 p13), P01045 적용 전동기 2.2~600·정격전류 7.5~1200 (최소값 p8, 인용 p9), P01188 iS7 전동기 0.75~ (p13, 인용 p14), P01183 H100 전동기 0.75~18.5 (p12, 인용 p13).
- 인용 페이지에 없는 값 2건: P01260 적용 규격 "IEC 60947" (p3은 목차, "UL 508"만 있음. IEC 60947은 p10), P01110 절연 "F종 (Epoxy Resin 몰드)" (p14에는 "F종"만, "Epoxy Resin"은 p3 특징 문구).
- 영향: 출처 링크(`#page=`)를 눌러 검수하는 사람이 값을 찾지 못함. 검수 전 배지가 붙어 있어 심각도는 중간.
- 제안: `page`를 여러 개 받을 수 있게(`pages: number[]`) 하거나, 대조표에 "p2~3"처럼 적고 링크는 첫 페이지로.

### M8. 두 기기에 속한 제품이면 "서로 다른 기기" 안내가 잘못 뜸
- 파일: `src/pages/ComparePage.tsx:287-288` (`e[0]?.id`만 비교)
- 재현: `/#/compare?type=product&ids=P01024,P01021`. 두 제품 모두 배선용차단기(MCCB)에 속하는데(P01024는 분전반용 차단기 + MCCB) "서로 다른 기기의 제품을 함께 비교하고 있습니다" 안내가 표시됨. 소속 기기 행도 "분전반용 차단기 외 1개 기기" vs "배선용차단기"로 보여 달라 보임.
- 제안: 모든 제품의 소속 기기 목록에 공통 원소가 있으면 mixed=false. 소속 기기 행 text도 공통 기기를 기준으로.
