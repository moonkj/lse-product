### M1. 약어 검색("VCB"·"ACB"·"MCCB")에서 Enter를 누르면 기기 대신 제품 페이지로 감 — 회귀

- 원인:
  - `productNameExact`는 제품명 토큰 중 하나만 질의와 같아도 정확 일치로 보고 점수 0을 준다. 예를 들어 "Susol VCB"의 토큰 "VCB"가 여기에 걸린다.
  - 기기의 Fuse 점수는 정확 일치여도 5.5e-7이라, 점수 0을 받은 제품들이 기기보다 앞에 온다.
  - `withEquipmentRow`는 기기 줄을 "정확 일치 무리" 바로 뒤에 넣는다. 그런데 이 무리가 제품 4~6개라서 기기 줄이 5~7위로 밀린다.

  - "ACB" 입력 시 결과는 Susol ACB, Metasol ACB, … 순이고 ACB 기기가 5위다. Enter를 누르면 `/product/P00206`으로 이동한다.
  - "VCB"·"MCCB"는 상위 4위 안에 기기 줄이 없다.
  - 직전 커밋의 Fuse 설정으로 같은 데이터를 돌려 보면 세 질의 모두 기기가 1위였다(`oldsearch.mjs`).
  - 영업 과업 T3("ACB" 입력 → Enter → 패널)와 검색 추천 칩 [VCB][ACB][MCCB]가 전부 다르게 동작한다.
- 제안 수정:
  - `productNameExact`의 토큰 일치는 **숫자가 들어간 모델 토큰**(GIPAM1000, TS250 등)에만 적용한다. 영문자만 있는 토큰(VCB, ACB, MCCB)은 기기 약어와 겹치므로 제외한다. 또는 질의가 기기 약어와 정확히 같으면 그 기기 줄에도 점수 0을 주어, 같은 점수일 때 기기가 먼저 오는 규칙으로 1위를 지킨다.
  - 회귀 테스트를 추가한다. "VCB"·"ACB"·"MCCB" + Enter에서 해당 기기 노드가 선택되어야 하고, "GIPAM 1000"은 제품 1위를 유지해야 한다.

### 처음 쓰는 사용자 (1280×800)
- 깨끗한 주소(`/`)로 첫 방문하면 시작 카드가 보인다. 공유 링크(`#/?node=…`)로 들어오면 안 보인다.
- 링크별 결과:

| 누른 것 | 이동·포커스 | 닫힘 저장 |
|---|---|---|
| "기기를 눌러 보세요" | `/?node=n-vcb`로 이동, 포커스는 BODY로 사라짐(R1) | 저장됨 |
| "공백 표" | /gap h1 포커스 | 저장됨 |
| × | 계통도로 포커스 | 저장됨 |

- LA 패널 판정 표기: 배지 "패널 구성품(타사 조달)", 섹션 "구성품 판정", 확신도 "판정 확정", 공백 표 "판정 확정". "공백" 단어가 없어 B7이 해소됐다.
- localStorage 접근이 예외를 던지는 환경: 오류 화면 없음. 시작 카드 닫기·발표 보기는 메모리 상태로만 동작한다(try/catch 정상).

### 다크 모드
- 계통도, Gap 모드, 제품, 비교 화면을 훑어봄. 색 깨짐이나 대비 문제는 눈에 띄지 않았고 axe color-contrast 위반 0. 제품 h1의 프로그램 포커스 테두리만 보인다(S6).
